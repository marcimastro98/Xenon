显示 1% 和 0.1% 低帧的 FPS 叠加层

Xenon 的游戏性能磁贴显示你正在玩的游戏的帧率、1% 和 0.1% 低帧、帧时间和最近帧的曲线，同时显示 CPU 和 GPU 负载以及 GPU 温度。它可以放在游戏上方、第二块屏幕上或你的手机上。免费，无需账户。

最后更新：2026年10月31日

1% 和 0.1% 低帧说明了什么

平均帧率会掩盖那些体验很差的时刻。所以 Xenon 还会取最慢的 1% 帧，把它们的平均值换算成帧率，这就是1% 低帧。0.1% 低帧的算法相同，取的是每一千帧里最慢的那一帧。

上图中游戏平均 143 FPS，1% 低帧是 112，0.1% 低帧是 96。三个数字很接近，所以游戏感觉流畅。如果平均值很高而低帧远低于它，即使 FPS 数字看起来没问题，游戏也会卡顿。

帧时间是一帧所用的时间，单位是毫秒：7.1 ms 大约相当于每秒 140 帧。曲线上每一帧是一个点，卡顿会显示为尖峰。低帧要在测量了足够多的帧之后才会出现，所以游戏刚开始的几秒只显示平均值。

游戏上方、第二块屏幕或手机上

在 Windows 的 Xenon 应用里，对 Bit 说“在游戏上显示我的 FPS”，磁贴就会出现在游戏上方。点击磁贴旁边的位置会落到游戏里，磁贴也从不抢走焦点。按 Ctrl+Shift+F9 隐藏游戏上方的小组件，再按一次恢复显示。

同一个磁贴也能放在第二台显示器、CORSAIR Xeneon Edge 这样的触摸屏，或已与电脑配对的手机上，这样游戏上方什么都不用盖。它每秒更新四次，并且只在游戏运行、磁贴显示在屏幕上时更新。

每一项都可以在设置 → 性能 → 游戏性能中关闭：1% 低帧、0.1% 低帧、帧时间、曲线，以及 CPU 和 GPU 那一行。

Xenon 绘制自己的窗口，从不进入游戏进程。所以它无法显示在独占全屏的游戏上方。游戏以这种方式运行时，磁贴会告诉你；在游戏的显示设置里切换为无边框或窗口化全屏，叠加层就会回来。

我的游戏为什么卡？

按 Deck 按键为什么卡顿?，或者问 Bit 同样的问题。Xenon 会查看最近几秒的帧时间、显卡和处理器负载、最忙的核心、显存和内存以及温度，然后给出一个原因和一个下一步。

例如“显存已满：降低纹理质量或分辨率”、“显卡满载”、“锁定在 60 FPS”（开启垂直同步或帧率限制时这是正常的），或者在没有任何部件达到极限时给出“加载卡顿”。它在你的电脑上用固定规则判断，不用 AI 模型，也不发送任何数据。游戏卡顿时，磁贴会在曲线下方用一行字显示原因。

对比你的游戏并记录基准测试

Xenon 会记住你玩超过两分钟的每一局游戏：平均 FPS、1% 和 0.1% 低帧、游玩时长、CPU 和 GPU 负载以及最高温度。两局之间，磁贴会显示上一局，例如“比之前高 12 FPS”。设置 → 性能 → 玩过的游戏列出最近十局，每一局都和同一游戏的上一次对比，所以驱动更新或补丁的效果自然会显现出来。

问 Bit“更新驱动后有改善吗？”，它会根据这些记录回答。最新的 100 局保存在你的电脑上，并包含在备份里。

需要精确测量时，按 Deck 按键基准测试：它会记录每一帧的时间，在 文档 → Xenon → Benchmark 中保存一个 CSV 文件，列名与 PresentMon 相同。再按一次、游戏关闭或满 30 分钟时它会停止，并告诉你平均 FPS 和 1% 低帧。

与 MSI Afterburner 和 RivaTuner 对比

Afterburner 搭配 RivaTuner 是在游戏内部绘制叠加层，所以能显示在独占全屏上方。Xenon 留在游戏外部，并补上这些工具留给你自己去做的事：对比过去的游戏，游戏卡顿时给出原因，以及在第二块屏幕或手机上显示同样的数字。

Xenon 不超频、不降压、不设置风扇曲线、不限制帧率，也不改驱动设置。如果你用 Afterburner 做这些事，继续用它就好。

常见问题

FPS 叠加层会被反作弊封号吗？

Xenon 从不向游戏注入代码，也从不挂钩游戏进程。它在上方绘制自己的窗口，并用 PresentMon 从系统读取帧时间，所以游戏内部没有任何东西会被反作弊标记。

需要 NVIDIA 显卡吗？

不需要。在 Windows 上，帧率来自 PresentMon，它从系统而不是从显卡驱动读取帧，所以磁贴不依赖 NVIDIA、AMD 或 Intel 的软件。

为什么叠加层没有显示在游戏上方？

游戏很可能处于独占全屏，这种模式下其他窗口都无法显示在它上方。请在游戏的显示设置里切换为无边框或窗口化全屏。出现这种情况时，磁贴和一条只弹出一次的消息会告诉你。

FPS 叠加层免费吗？

免费。游戏性能磁贴、玩过的游戏、基准测试和卡顿原因都包含在免费应用里，无需账户。支持者每月获得的是目录里的新内容，而不是额外功能。
