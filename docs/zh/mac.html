macOS 上的 Xenon测试版

Xenon 是一款免费的触控仪表盘，用于电脑旁边的那块屏幕。在 Mac 上，它运行的是和 Windows 上相同的仪表盘。本页列出目前在 Mac 上哪些功能可用、哪些不可用，以及如何安装和卸载。

最后更新：2026年9月27日

适合谁 下载 首次启动 哪些功能可用 Xeneon Edge 权限 卸载

适合谁

本页写给手边有一块闲置屏幕的 Mac 用户：

  • CORSAIR Xeneon Edge。Xenon 最初就是围绕它 2560×720 的形状设计的。
  • 闲置的显示器。Xenon 应用会在你选择的屏幕上打开。
  • 平板或手机。它通过你的 Wi-Fi 在自带的浏览器中显示同一个仪表盘，设备上无需安装任何东西。手机和平板访问同样是测试版。参见配对手机或平板。

小组件、目录、主题和各项集成与 Windows 上相同。有差别的是读取和控制 Mac 本身的那部分，下表逐行列出。

macOS 支持目前是测试版。它有单元测试覆盖，但实际使用远少于 Windows 版本。

下载和系统要求

macOS测试版Xenon-macOS-universal.dmgmacOS 11 或更高版本。一个文件同时支持 Apple 芯片和 Intel。
  • macOS 11 或更高版本，Apple 芯片或 Intel 均可。.dmg 是通用版本，所以两者只需下载同一个文件。
  • Node.js 18.15 或更高版本。如果缺少它而电脑上装有 Homebrew，设置程序会用 Homebrew 安装它。否则它会停下来，请你从 nodejs.org 安装。

其余都是可选的。每个工具增加一项功能，安装程序会列出你缺少的那些：

  • brew install vladkens/tap/macmon：用于读取温度和 GPU 负载，仅在 Xenon Helper 读不到时需要。
  • brew install switchaudio-osx：用于切换输出设备。
  • brew install ffmpeg：用于语音输入和语音回复。

首次启动

打开未经公证的应用

Xenon 目前还没有经过 Apple 公证。公证需要付费的 Apple 开发者会员资格，而这个项目没有，所以第一次打开 Xenon 时，macOS 会提示无法检查它。

  1. 打开 .dmg，把 Xenon 拖到应用程序，然后打开它。
  2. 在 macOS 15 及更高版本上，如果 macOS 拒绝打开，请打开系统设置，然后进入隐私与安全性。
  3. 滚动到底部，点击 Xenon 旁边的仍要打开。

在 macOS 11 到 14 上，你也可以右键点按应用，选择打开，然后再点一次打开。Apple 在 macOS 15 中取消了这个方法。无论用哪种方式，每个版本只需要做一次。

设置仪表盘引擎

.dmg 无法运行安装程序，所以这一步在首次启动时完成。Xenon 发现背后还没有仪表盘，会打开一个终端窗口，你可以查看，也可以随时停止。在这个窗口中，它会：

  1. 下载最新版本及其签名的校验和列表；
  2. 在解压任何内容之前，用项目的签名密钥验证下载的文件；
  3. 安装到 ~/Library/Application Support/Xenon；
  4. 添加 Xenon Helper（一个小型配套程序，负责应用切换器、温度和搜索），以及读取正在播放内容的桥接；
  5. 注册一个登录项，让 Xenon 在你登录时打开。

完成后，安装程序会关闭并重新打开应用，仪表盘随即出现。在这台 Mac 的任何浏览器中，也可以通过 http://127.0.0.1:3030/ 打开它。

仪表盘引擎作为 Xenon 应用的子进程运行。因此只要给 Xenon 一次完全磁盘访问权限就能覆盖它，而不必授权给 Node.js，那样的话 Mac 上的其他所有脚本都会共享这项权限。

更新方式和 Windows 上一样：先下载并验证新版本，如果新版本无法启动，就恢复之前的版本。

不想用应用窗口？从发布页面下载源代码 zip，解压后双击 INSTALL.command。仪表盘完全一样，但没有应用的话，macOS 保护的那些文件夹就无法访问。

在 Mac 上哪些功能可用

你的 Mac 做不到的功能会被隐藏，而不是先提供、再失败：无法工作的 Deck 按键不会出现在编辑器中，没有数据来源的磁贴会直接说明。

功能在 Mac 上
仪表盘、磁贴、主题、目录、小组件 SDK可用，与 Windows 上相同。
Xenon 应用、登录时启动、自动更新可用。
CPU、内存、磁盘、网络可用。
CPU 和 GPU 温度、GPU 负载可用，通过 Xenon Helper 读取，无需管理员密码。读不到时改用 macmon，仍然读不到则显示“--”。
风扇转速Mac 上不可用。
系统音量、麦克风静音可用。
切换输出设备安装 switchaudio-osx 后可用。
分应用音量混音器不可用。混音器只显示设备。
正在播放和媒体键可用，通过安装程序添加的桥接。
打开的应用、应用切换器、游戏模式可用，通过 Xenon Helper。
Deck 按键：打开应用、文件或网站，运行脚本，锁定可用。
发送键盘快捷键的 Deck 按键在辅助功能中允许 Xenon Helper 后可用。
全局搜索快捷键可用，通过 Xenon Helper。
文件搜索、磁盘地图和清理可用，通过 Xenon Helper。搜索按文件名匹配。要包含你的用户文件夹，需要完全磁盘访问权限。
从仪表盘输入文字和移动窗口Mac 上不可用。
Xenon AI 聊天和操作，云端和本地可用。
语音输入和 AI 查看屏幕可用。语音需要 ffmpeg。
“Hey Xenon”语音唤醒装有 ffmpeg 和免费的本地 Whisper 时可用。Whisper 可以在“设置”>“Xenon AI”中通过 Homebrew 安装。
网络灯光：WLED、Hue、Nanoleaf、OpenRGB可用。
CORSAIR iCUE 灯光仅限 Windows。
直播、Spotify、Discord、Home Assistant、Claude Code可用。
游戏内帧率计数器Mac 上不可用。
在仪表盘上显示桌面通知不可用。macOS 不允许任何应用读取其他应用的通知。
来电卡片仅限 Discord 通话。
内嵌浏览器磁贴装有 Edge、Chrome、Chromium 或 Brave 时可用。
把手机或平板用作第二块屏幕可用。手机访问在所有系统上都是测试版。
从家外访问、向手机推送通知自行安装 Tailscale 后可用。
虚拟第二屏幕、远程控制电脑仅限 Windows。

如果某个磁贴是空的，请在安装文件夹中运行 npm run doctor。它会列出哪些功能正常、哪些是你的硬件没有提供的、哪些出了问题，而且不会改动任何东西。

在 Mac 上使用 Xeneon Edge

Xenon 第一次打开时，会列出它能看到的屏幕。选择 Edge，仪表盘就会移到那里。之后可以在设置 > 显示器中更改。

触控的工作方式与 Windows 上不同。macOS 本身不支持 USB 触摸屏，所以需要借助 Touchscreen Gestures 这类应用，把每次触摸转换成鼠标点击，把长按转换成右键点击。Xenon 会在右键点击时执行 Deck 按键的“长按”动作，所以在这种设置下“长按”也能用。

有三项功能仍然只在 Windows 上提供：不影响游戏的触控（点按 Edge 时游戏保持焦点）、CORSAIR iCUE 灯光，以及虚拟第二屏幕。

macOS 权限

没有这些权限，仪表盘也能运行。每一项权限开启一个特定的功能。

  • 完全磁盘访问权限，授予 Xenon。让搜索和磁盘空间小组件能看到你的用户文件夹、废纸篓以及 ~/Library/Caches 的大部分内容。没有这项权限时，Xenon 不会进入你的用户文件夹，而不是逐个请求访问桌面、文稿和下载；它会显示一条通知，附带一个直达相应设置面板的按钮。
  • 辅助功能，授予 Xenon Helper。让 Deck 按键能向最前面的应用发送键盘快捷键。在你允许之前，这类 Deck 按键不会出现在编辑器中。Xenon 在启动时检查这项权限，所以允许之后请退出并重新打开 Xenon。
  • 屏幕录制。AI 截图查看你的屏幕时需要。没有它，截图里只有桌面图片。
  • 麦克风。语音输入和“Hey Xenon”语音唤醒需要。没有它，Xenon 找不到麦克风。
  • 自动化。仅在缺少 Xenon Helper 时需要：这时应用切换器会改用脚本，macOS 会针对每个应用询问一次。

给 Xenon 完全磁盘访问权限的方法：

  1. 打开系统设置 > 隐私与安全性 > 完全磁盘访问权限。
  2. 点击 +，在“应用程序”中选择 Xenon，并确认它的开关已打开。
  3. 退出 Xenon 再重新打开。这项权限在启动时读取。

从 4.11.3 版起，Xenon 使用自己的证书签名，这个证书在各个版本之间保持不变，所以授权在更新后依然有效。如果 Xenon 在列表中，但权限明显没有生效，请用减号按钮移除它，再重新添加。

卸载

  1. 在访达中选择前往 > 前往文件夹，然后输入 ~/Library/Application Support/Xenon。
  2. 双击 UNINSTALL.command。
  3. 它会列出将要移除的所有内容，然后等待。输入 REMOVE 继续。

它会移除“应用程序”中的应用、登录项、本地服务器、你的数据和安装文件夹，然后关闭自己的终端窗口。

如果想保留设置、布局和笔记，请在终端中运行它所启动的脚本 UNINSTALL.sh，并加上 --keep-data：

cd "$HOME/Library/Application Support/Xenon"
./UNINSTALL.sh --keep-data

如果改加 --dry-run，它只显示列表，不做任何改动。

把 Xenon 拖到废纸篓只会移除应用。仪表盘引擎、它的登录项和你的数据都会留下；卸载程序会把它们一并移除。

常见问题

Xenon 能在 Mac 上运行吗？

能，目前是测试版，需要 macOS 11 或更高版本。一个通用 .dmg 可以在 Apple 芯片和 Intel 上运行。仪表盘、小组件和各项集成与 Windows 上相同；少数系统功能不可用。

可以在 Mac 上使用 Xeneon Edge 吗？

可以。Xenon 第一次打开时会问你要使用哪块屏幕，你可以选择 Edge。macOS 本身不支持 USB 触摸屏，所以触控需要一个把触摸转换成点击的应用。iCUE 灯光和不影响游戏的触控仅限 Windows。

为什么 macOS 提示无法打开 Xenon？

因为这个应用还没有经过 Apple 公证。在 macOS 15 及更高版本上，打开“系统设置”>“隐私与安全性”，点击 Xenon 旁边的“仍要打开”。在 macOS 11 到 14 上，右键点按应用并选择“打开”。每个版本只需要做一次。

Xenon 在 Mac 上需要哪些权限？

仪表盘不需要任何权限就能运行。完全磁盘访问权限让搜索和磁盘空间小组件能看到你的用户文件夹和废纸篓。辅助功能让 Deck 按键能发送键盘快捷键。屏幕录制和麦克风用于 AI 查看屏幕和语音。

如何在 Mac 上卸载 Xenon？

双击 ~/Library/Application Support/Xenon 中的 UNINSTALL.command，并在提示时输入 REMOVE。它会移除应用、登录项、本地服务器、你的数据和安装文件夹。
