Xenon 与其他工具

很多人是在找桌面小组件、传感器面板、FPS 计数器、录屏软件或 Stream Deck 时发现 Xenon 的，而其中某一项他们已经在用别的工具。本页说明每个工具最擅长什么，以及什么时候另一个更合适。

Rainmeter

Rainmeter 是一款免费开源的程序，在 Windows 桌面上绘制皮肤。它很轻量，社区积累了多年的皮肤，只要你愿意编辑文本文件，皮肤几乎可以显示任何东西。

Xenon 也能把小组件放在桌面上，还能放在副屏、触摸屏、平板或手机上，用手指操作。小组件通过菜单添加和设置，同样的布局也能在 macOS 和 Linux（测试版）上运行。

如果 Windows 桌面上已经有你喜欢的皮肤，继续用 Rainmeter。如果想把小组件放到另一块屏幕、用手触控，或者不想碰文本文件，试试 Xenon。

AIDA64 SensorPanel

AIDA64 是一款付费软件，用于系统信息、诊断和基准测试。它的 SensorPanel 把读数画在你自己设计的面板上，能驱动许多为机箱出售的小型 USB 屏幕，RemoteSensor 还能在手机浏览器里显示读数。

Xenon 是免费的，传感器面板只是众多小组件之一：CPU、GPU、风扇、功耗和游戏中的真实帧率，与音乐、日历和 Deck 按键并排显示。它需要能显示网页的屏幕，所以不支持只通过数据线接收图片的小型 USB 屏幕。

如果用的是那种小型 USB 屏幕，或需要它的测试和诊断，继续用 AIDA64。如果你的面板是闲置显示器、平板或手机，试试 Xenon。所有读数见传感器面板指南。

Wallpaper Engine

Wallpaper Engine 是一款价格不高的 Steam 动态壁纸应用，拥有庞大的创意工坊场景库，还有免费的 Android 应用可以把壁纸带到手机上。

Xenon 也有动态背景和 Ambient 场景，但它的本职是小组件：读数、音乐、日历、Deck 按键和助手。两者可以在同一台电脑上运行。

壁纸本身，继续用 Wallpaper Engine。放在它上面或另一块屏幕上的东西，加上 Xenon。

MSI Afterburner

MSI Afterburner 搭配 RivaTuner，是超频、风扇曲线和从游戏内部绘制 FPS 叠加层的经典免费工具，正因为从内部绘制，它能显示在独占全屏之上。

Xenon 在游戏外部运行。它把帧率、1% 和 0.1% 低帧以及帧时间显示在副屏、手机或游戏上方的窗口里，对比以往的游戏，并在游戏卡顿时指出可能的原因。它不超频、不降压，也不设置风扇曲线。

超频和风扇曲线，继续用 Afterburner。想在另一块屏幕上看数据并保留游戏记录，加上 Xenon。详情见FPS 叠加层指南。

NVIDIA App

NVIDIA App 是 GeForce 显卡的免费配套软件。它的叠加层可以录制游戏、保留即时回放、截图，并在游戏上方显示 FPS 等数据，录制使用显卡上的编码器。Radeon 显卡上，AMD Software 的功能大致相同。

Xenon 使用系统自带的捕获和视频编码器录制，因此任何显卡都能用。它的即时回放可在磁盘上保留 15 秒到 60 分钟，在你标记的时刻前后自动保存片段，并把所有内容放进同一个图库，剪辑只需一秒。数据可以放在另一块屏幕上，而不是盖在游戏上。

更新驱动和调整游戏设置，继续用 NVIDIA App。想在任何显卡上用回放、把片段和截图放在一个图库里、把数据放到副屏上，试试 Xenon。详情见录屏指南。

Xbox Game Bar

Xbox Game Bar 是 Windows 自带的。在游戏中按 Win+G，可以录制、保存刚才的片段、截图或打开小组件，其中一个用于查看性能。

Xenon 做同样的事，但不遮挡游戏：小组件放在副屏、手机或桌面上，用快捷键、轻点 Deck 或让 Bit 帮你保存回放。它还有片段图库、标记、游戏记录，以及随时间变化的 FPS 低帧。

偶尔快速截取一下就够的话，继续用 Game Bar。想把数据和控制放到另一块屏幕，或保留游戏记录，试试 Xenon。

OBS Studio

OBS Studio 是免费开源的直播和场景录制标准工具：摄像头、叠加层、多个来源和音频混音器，支持 Windows、macOS 和 Linux。

Xenon 不做直播。它录制整个屏幕或单个窗口，麦克风单独一条音轨，保留即时回放并保存截图，无需事先设置。它的 Deck 按键还能控制 OBS：切换场景、开始和停止直播或录制、静音某个来源。

直播和用场景搭建的录制，继续用 OBS。快速录屏和回放，以及用触摸屏或手机控制 OBS，加上 Xenon。OBS 按键见Deck 指南。

Stream Deck

Elgato 的 Stream Deck 是一系列桌面设备，按键是一块块小屏幕，插件库很大。Stream Deck Mobile 应用也能把手机变成按键：6 键免费，更多需要 Pro 订阅。

Xenon 的 Deck 是放在你已有屏幕上的触摸按键网格，比如触摸屏、闲置显示器、平板或手机，和其他小组件并排。按键可以打开应用、发送快捷键、切换 OBS 场景、让 Discord 静音、运行宏，并显示所控制对象的状态。它是免费的。

想要不看也能按的实体按键，继续用 Stream Deck。想在已有的屏幕上免费使用，试试 Xenon 的 Deck。所有按键类型见Deck 指南。

Touch Portal

Touch Portal 把手机或平板变成 Windows 或 Mac 电脑的宏按钮页面。免费版涵盖基本功能，插件需要付费的 Pro 版。

Xenon 的 Deck 也能在手机或平板上运行，在浏览器里打开即可，无需安装（测试版），同样的按键也能在桌面或触摸屏上使用。按键旁边，同一块屏幕还能显示传感器、音乐和日历。

如果依赖它的某个插件，继续用 Touch Portal。想把按键和小组件免费放在一起，试试 Xenon。

一起使用

用 Xenon 不需要卸载任何东西。它自己读取传感器，所以既不需要 AIDA64 也不需要 HWiNFO，并能与 Afterburner、Rainmeter、Wallpaper Engine、OBS 或 NVIDIA App 同时运行。

保留你喜欢的工具，把它们够不到的屏幕交给 Xenon：闲置的显示器、旧平板、你的手机，或键盘旁的触摸屏。

常见问题

Xenon 能替代 Rainmeter 吗？

作为小组件，可以。它能在桌面上显示系统读数、音乐、天气、日历等，也能放在副屏、平板或手机上。它不能加载 Rainmeter 皮肤。

Xenon 的 Deck 能替代 Stream Deck 吗？

在你已有的屏幕上可以：触摸屏、闲置显示器、平板或手机。按键可以打开应用、发送快捷键、切换 OBS 场景和运行宏。它没有实体按键。

Xenon 能替代 OBS 吗？

录屏和即时回放可以。直播不行：Xenon 不做直播，但它的 Deck 按键可以切换 OBS 场景、开始或停止直播。

Xenon 免费吗？

免费。Xenon 个人使用免费，无需账号。支持者为每月推出的内容等额外福利付费，但本页对比的所有功能都在免费版里。

Xenon 能在手机上显示电脑传感器吗？

可以，测试版。在自己的 Wi-Fi 上把手机与电脑配对，手机浏览器就会显示仪表板，包括传感器。手机上不用安装任何东西。

Xenon 支持小型 USB 传感器屏幕吗？

不支持只通过 USB 数据线接收图片的那种。Xenon 需要能显示网页的屏幕：显示器、像 CORSAIR Xeneon Edge 这样的触摸屏、平板或手机。
