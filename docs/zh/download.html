首次设置 Windows 和 macOS 的警告 验证下载 其他安装方式

这个版本的全部文件（包括校验和）都在发布页面上。

首次设置

Windows：运行安装程序。它会安装应用，应用会自动打开，发现还没有仪表盘引擎时，会显示 Complete setup（完成设置）。点一次：会打开一个窗口，安装 Node.js、传感器读取程序，以及在你登录时启动 Xenon 的任务，每一步都会显示出来。在运行任何东西之前，下载的内容都会先用项目的签名密钥验证。整个过程需要几分钟，只需一次。

macOS 和 Linux：打开你下载的应用。首次启动时，它会提出在终端窗口中设置仪表盘，并在解压前验证下载的文件。在 Linux 上，安装包有意不替你完成这一步，因为它要创建的所有东西都属于某一个用户账号，而安装包是以 root 身份为整台电脑安装的。

接着，Xenon 会问你要在哪块屏幕上使用它。闲置的显示器、平板、手机或 CORSAIR Xeneon Edge 都可以；手机指南介绍了如何在大约三十秒内配对手机或平板。

Windows 和 macOS 的警告

从 4.11.9 版起，Windows 安装程序已经签名，所以 Windows 会显示经过验证的发布者。不过 SmartScreen 仍可能在一段时间内发出警告，因为 Microsoft 是随时间逐步给予信誉的：点击更多信息，再点仍要运行。Defender 还会根据程序的行为作出判断，而不只看是谁签的名，所以仍有可能被检测到。常见问题解释了每种警告以及如何找回文件；如果你想确切了解安装了什么，这个页面列出了 Xenon 运行的每个进程。

macOS：Mac 版是测试版。从 5.0 起它经过了 Apple 公证，所以第一次启动时，macOS 只会询问一次是否打开从互联网下载的应用：点击打开。如果 macOS 提示无法检查 Xenon，说明这份副本早于 5.0，请下载最新的 .dmg。

验证下载

每个版本都附带一个用项目的 Ed25519 密钥签名的 SHA256SUMS 文件。比较你下载的文件的哈希值：

# Windows, PowerShell
Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256

# macOS
shasum -a 256 Xenon-macOS-universal.dmg

# Linux
sha256sum Xenon-Linux-x86_64.AppImage

如果它和该版本 SHA256SUMS 中对应那个文件的一行一致，这个文件就和 GitHub Actions 在那个标签上从公开源代码构建出来的文件逐字节相同。在 Windows 上，你也可以右键点击安装程序，选择属性，打开数字签名选项卡查看发布者。

其他安装方式

从源代码安装：从发布页面下载源代码 zip，解压后，在 Windows 上运行 INSTALL.bat，在 macOS 上运行 INSTALL.command，在 Linux 上运行 ./INSTALL.sh。结果和安装程序一样，适合想先读一读会运行什么的人。

Microsoft Store：Xenon 也已上架 Microsoft Store，适用于 Windows 10 和 11。它安装的是同一个已签名的 Windows 安装程序，之后和其他安装方式一样，Xenon 会自动更新到最新版本。

winget：软件包清单已经写好，正在等一个能在 Microsoft 那边顺利通过扫描的版本；在正式上架之前，请使用上面的安装程序。上架那天，这个页面会写上 winget install xenon。

更新：Xenon 每次启动时都会检查有没有新版本，并自动更新。你不需要为此回到这里。

Xenon 是什么

一个免费的仪表盘，运行在你的电脑上，可以显示在任何闲置的屏幕上：系统状态、媒体和麦克风控制、类似 Stream Deck 的按键网格、灯光控制，还有可以对话的 AI。无需账号，你的设置、文件和传感器读数都保存在你的电脑上。主页上可以看到它的样子。

xenon

任何屏幕都能用的免费电脑小组件。支持 Windows，macOS 和 Linux 为 Beta 版。

Bit 住在 Vitals 小组件里，对你的坐姿很有意见。
