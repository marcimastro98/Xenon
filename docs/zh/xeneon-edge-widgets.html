Xeneon Edge 小组件：iCUE 提供什么，Xenon 增加什么

Edge 是一块好屏幕，但小组件目录不大。Xenon 是一款围绕它的确切形状设计的免费仪表盘：页面由你亲手排布，控制按钮直接作用于电脑，触控绝不会抢走游戏的焦点，而且有没有 iCUE 都能运行。

最后更新：2026年9月26日

iCUE 提供什么 Xenon 增加什么 放到 Edge 上 试用前需要了解的事 常见问题

Edge 开箱即有的功能

CORSAIR Xeneon Edge 是一块 14.5 英寸、2560×720 的触控长条屏，可以装在桌面支架上，也可以装进机箱里原本放三把 120 mm 风扇的位置。开箱时它就是一台普通的副显示器，iCUE 则把它变成一面小组件墙：传感器读数、时钟、媒体控制、网页，以及其他人导出并分享的小组件。CORSAIR 还发布了 WidgetBuilder 工具包，供想自己编写小组件的人使用。

这是一个不错的起点，对很多用户来说已经够用了。用户论坛里反复出现的需求，正是 iCUE 没有解决的那些：可以亲手重新排布的布局，能在电脑上真正做点什么、而不只是显示一个数字的控制，不会抢走游戏焦点的触控，以及完全不运行 iCUE 也能使用这块长条屏的办法。

Xenon 增加什么

Xenon 是一款免费仪表盘，最初围绕 Edge 那种又矮又宽的确切形状设计，后来才扩展到任何屏幕。它在你的电脑上作为一个小型本地服务运行，并以两种方式之一出现在 Edge 上：作为独立的全屏原生应用，完全不需要 iCUE；或者，如果你更想把一切集中在一处，也可以作为 iFrame 面板放在 iCUE 里。

  • 拖放式页面。由可调整大小的磁贴组成的网格，最多八页，布局可以保存，也可以用一段代码分享。
  • 作用于电脑的控制。静音麦克风、切换音频输出、跳过曲目、分别调节各应用的音量，还有一组类似 Stream Deck 的按键网格，用于应用、OBS、快捷键和宏。
  • 不影响游戏的触控。在原生应用中，点按 Edge 绝不会把鼠标从游戏中移走，也不会抢走游戏的焦点。只有真正的原生窗口才能向 Windows 提出这个要求。
  • Xenon AI。说出你想在页面上放什么，它就会把页面搭好。可以使用 Google Gemini，也可以通过 Ollama 使用免费的本地模型。
  • 传感器和历史记录。CPU、GPU、内存、磁盘、网络、游戏内的真实帧率，另有 24 小时到 30 天的历史记录。温度读取使用的是已签名的组件（PawnIO），从不使用 WinRing0。
  • 灯光。根据 CPU 温度、计时器或专辑封面驱动 iCUE 的 LED，同时控制网络中的 Govee、LIFX、WLED、Hue 和 Nanoleaf 灯具。
  • 社区目录。其他用户分享的主题、小组件包和整套页面布局，用一段代码即可安装。

仪表盘运行在你的电脑上，不需要账号。设置、文件和传感器读数都保留在电脑上。应用会检查更新、读取目录、每天获取一个公告文件，并发送匿名的版本统计（在“设置”中用一个开关即可关闭）；其他内容只有在你开启相应功能时才会联网，比如天气或 AI 服务。

放到 Edge 上

  1. 下载 Xenon-Setup-x64.exe 并运行。它会安装原生应用。
  2. 应用打开后，发现还没有仪表盘引擎，会显示 Complete setup（完成设置）。点一次即可。这会在一个你可以查看的窗口中安装 Node.js、传感器读取程序和登录时启动的任务。
  3. Xenon 第一次打开时会问你要在哪块屏幕上使用它。选择 Edge。之后无论显示设置发生变化还是电脑进入睡眠，它都会固定在那里。
  4. 如果你更喜欢 iCUE：在 iCUE 中添加一个指向 http://127.0.0.1:3030/ 的网页小组件，Xenon 就会填满这个面板。

试用前需要了解的事

有两点需要说明。第一，Windows 安装程序已经签名，所以 Windows 会显示经过验证的发布者，但 SmartScreen 仍可能在一段时间内发出警告，因为 Microsoft 是随时间逐步给予信誉的：点击更多信息，再点仍要运行。常见问题介绍了如何自己验证文件。第二，Xenon 以 Windows 为主。macOS 和 Linux 版本已经推出，目前是测试版，而 Edge 专属的部分（保留的触控手势、虚拟第二屏幕、iCUE 灯光）只支持 Windows。

它是免费的，没有付费版。如果你最后每天都在用，可以成为支持者，解锁几款额外的主题和小组件，这就是全部的商业模式。

常见问题

Xenon 会取代 iCUE 吗？

不会。iCUE 仍然负责驱动你的 CORSAIR 硬件及其灯光。Xenon 与它并行运行，可以是独立的窗口，也可以放在 iCUE 的一个面板里，还能通过自己的桥接把灯光效果发送给 iCUE。你可以在不打开 iCUE 的情况下在 Edge 上运行 Xenon，但负责配置设备的仍然是 iCUE。

使用 Xenon 一定要有 Edge 吗？

不需要。Edge 是它最初面向的屏幕，但任何闲置的显示器、旧平板、连接同一 Wi-Fi 的手机或触摸屏，用起来都一样。参见把旧平板或手机用作电脑仪表盘。

可以同时使用 iCUE 小组件和 Xenon 吗？

可以。在 iCUE 中，Edge 被分成若干面板；Xenon 以网页小组件的形式占用一个面板，其余面板保持原样。如果你愿意，它也可以占满整块长条屏。

Xenon 免费吗？

免费。个人使用免费，源代码以非商业许可证公开在 GitHub 上，没有试用期，也没有任何功能被锁在某个档位之后。支持者会得到几款额外的主题作为感谢。
