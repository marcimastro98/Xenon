由 Xenon 驱动的 AIO 水泵屏幕

CORSAIR iCUE LINK 或 NZXT Kraken 水泵上的圆形或方形屏幕，可以显示 Xenon 的内容并自动切换：玩游戏时显示温度和 FPS，听音乐时显示歌曲，其余时间显示时钟或你自己的图片，有提醒时显示提醒。

下载 Windows 版 在浏览器中试用

自动切换

打开 Xenon → 屏幕，点一下水泵。显示内容里每个时刻一行：玩游戏时、听音乐时、其余时间。两行同时适用时，上面那行优先，菜单会说明水泵上现在显示什么以及原因。

点添加可以加入更多时刻：直播时、录制时、夜里、电脑忙碌或空闲时、特定时段。每个表盘最多显示四项电脑读数：温度、负载、内存、显存、功耗、FPS 和频率。

在提醒里可以选择哪些内容会盖在表盘上、显示多久：通知、来电、结束的计时器、Discord 消息、过热的电脑。也可以不显示消息正文。五个示例（玩家、音乐、动画、指针时钟、监控）点一下就能填好所有行。

Xenon、仪表，或你自己的样式

免费的默认样式 Xenon 把每个表盘画在一滴柔和的色彩上，最热的读数会让它变成琥珀色或红色，电脑越忙它动得越快。仪表画成仪表盘：带指针的表盘、标出歌曲分钟的表盘、带指针的时钟、日期和天气。

为水泵屏幕制作的商店小组件可以作为一个表盘，也可以作为整个样式。你也可以在 Xenon Maker 里自己做一个，或者对 Bit 说：“把水泵屏幕做成汽车仪表盘的样子”。

每一行都有自己的外观：随各部件负载变化的实时颜色、你的主题、图片里的颜色或任意颜色、更大的数字、°C 或 °F，以及几个你自己的字。

你自己的图片或 GIF

使用自己的图片或 GIF 可以把最大 20 MB 的 PNG、JPG、WebP、GIF 或 WebM 放到水泵上。外观里可以旋转屏幕、调节亮度，并在夜里调暗。设置备份会保留你的图片。

灯环

在 CORSAIR 水泵上，屏幕周围的 LED 灯环可以跟随屏幕内容：你的 GIF、图片或歌曲封面的颜色，主题色，你自选的两种颜色，或者保持熄灭。打开整台电脑同样的颜色，风扇、键盘和其他灯光也会换成同样的颜色。

灯效分四组：平静、动感、音乐，以及你的电脑。在“你的电脑”这一组里，灯环会按读数填满、随温度变暖、显示时钟、按风扇的真实转速旋转，或跟随今天的天色和天气。

常见问题

CORSAIR 水泵屏幕需要 iCUE 吗？

iCUE LINK AIO LCD 不需要：关闭 iCUE 时，Xenon 直接通过 USB 在上面绘制，支持 Windows，Linux 为测试版。iCUE 打开时，iCUE 里的 Xenon 水泵小组件也能做到同样的事。

免费吗？

是的。水泵屏幕、Xenon 和仪表两种样式以及你自己的图片都免费，也不需要账户。

Mac 或 Linux 能用吗？

iCUE LINK AIO LCD 在 Linux 上可作为测试版使用，需关闭 OpenLinkHub。其他水泵需要 Windows，Mac 上没有水泵屏幕功能。
