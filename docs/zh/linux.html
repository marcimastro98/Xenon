Linux 上的 Xenon

Xenon 是一款适用于任何闲置屏幕的免费仪表盘。它在 Linux 上是测试版：仪表盘和 Windows 上的一样，本页列出仍有差别的地方以及它需要的软件包。

最后更新：2026年9月26日 · 所有链接都指向最新版本

下载 首次启动 哪些功能可用 X11 和 Wayland

下载

AppImageXenon-Linux-x86_64.AppImage任何 x86_64 桌面系统。执行 chmod +x 后运行即可。 Debian, UbuntuXenon-Linux-x86_64.deb安装应用；仪表盘在首次启动时按用户分别设置。 Fedora, openSUSEXenon-Linux-x86_64.rpm与 .deb 相同，适用于基于 RPM 的发行版。

Linux 支持目前是测试版。仪表盘、小组件、目录和各项集成与 Windows 上完全相同。仍有差别的是读取和控制电脑本身的那部分，列在下表中。已在 GNOME 和 KDE 上测试。

首次启动

打开应用。首次启动时，它会提出在终端窗口中设置仪表盘：下载引擎，在解压前验证下载的文件，并注册一个 systemd --user 服务，让 Xenon 在你登录时启动。如果没有用户级服务管理器，它会改用 XDG 自启动项，并告诉你这一点，包括这种备用方式不会在 Xenon 崩溃后重新启动它。

.deb 和 .rpm 在安装时不做这一步，这是有意为之：设置过程创建的所有东西都属于某一个用户账号，而软件包是以 root 身份为整台电脑安装的。

安装程序还会列出你缺少的可选工具。在 Debian 和 Ubuntu 上：

sudo apt install nodejs npm unzip           # required
sudo apt install wireplumber                # volume, microphone and the per-app mixer
sudo apt install wmctrl xdotool x11-utils   # the open-applications widget (X11 sessions)
sudo apt install ffmpeg                     # voice input and spoken replies

如果你的桌面环境根本没有终端模拟器，应用就无法向你显示安装程序：请从发布页面下载源代码 zip，解压后运行 ./INSTALL.sh。

功能状态
仪表盘、磁贴、主题、目录、小组件 SDK可用，与 Windows 完全相同。
原生全屏应用、登录时启动、自动更新可用。

正在播放和媒体键可用，通过 MPRIS。

Xenon AI、聊天、操作、“Hey Xenon”语音唤醒可用，云端和本地都支持。
网络灯光：WLED、Hue、Nanoleaf、OpenRGB可用。

README 中的平台对照表是这份列表的权威版本，每个带条件的行都附有脚注。

X11 和 Wayland

仪表盘的大部分功能在两者上表现相同。有差别的是那些需要看到其他窗口的部分：“打开的应用”小组件、应用切换器和 AI 查看屏幕的功能使用 X11 工具（wmctrl、xdotool），所以在 Wayland 会话中，Xenon 会把它们隐藏起来，而不是先提供、再失败。如果你需要这些功能，请登录 X11 会话。

报告问题

Linux 仍是测试版，因为上表还有空缺。要报告问题，请提交一份缺陷报告，写明你的发行版、桌面环境和会话类型。如果想先问问，可以到 Discord 留言。
