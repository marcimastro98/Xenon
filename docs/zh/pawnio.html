PawnIO

如果你在驱动列表、安装提示或反作弊消息里看到了 PawnIO，这一页会说明它是什么、哪些应用在用它，以及 Xenon 用它做什么。

PawnIO 是什么

PawnIO 是开发者 namazso 为 Windows 编写的已签名内核驱动。读取 CPU 温度、主板的风扇芯片或内存传感器，需要与普通程序无权访问的硬件寄存器通信，所以监控应用需要一个小驱动替它完成这件事。

PawnIO 的不同之处在于它放行的东西很少。它不会把端口和寄存器的直接访问权交给任何程序，而是运行用 Pawn 语言编写的小模块，每个模块只开放它被编写来完成的操作，并且只加载用维护者密钥签名的模块。它的源代码公开在 pawnio.eu。

PawnIO 与 WinRing0

多年来，大多数硬件监控软件都使用 WinRing0，这是一个旧驱动，会让电脑上的任何程序直接访问硬件端口和寄存器。问题就在这里：恶意程序也能走同一扇门。Microsoft Defender 现在会把它识别为 HackTool:Win32/Winring0 并隔离，这就是许多风扇和传感器应用突然开始显示警告的原因。

LibreHardwareMonitor、Fan Control、OpenRGB 等都已改用 PawnIO。Xenon 从未附带过 WinRing0。

Xenon 为何安装 PawnIO

在 Windows 上，Xenon 通过 LibreHardwareMonitor 读取 CPU 和磁盘温度，而 LibreHardwareMonitor 需要 PawnIO 才能访问传感器。当你按下安装传感器时，Xenon 通过微软的包管理器 winget 获取 PawnIO，包名为 namazso.PawnIO，所以文件来自它的开发者，而不是我们。

安装驱动需要管理员确认。拒绝的话 Xenon 仍可使用，只是没有温度。Xenon 本身从不以管理员身份运行：由一个小型服务读取传感器并把读数交给它。如果电脑上已有旧版 PawnIO，请用 winget upgrade namazso.PawnIO 更新，因为旧版本会让部分 CPU 读数为空。

macOS 和 Linux 上没有 PawnIO：在 Mac 上 Xenon 通过 macmon 读取温度，在 Linux 上则使用内核自带的传感器。

PawnIO 与反作弊

PawnIO 不在游戏内部，也从不读取游戏内存。即便如此，FACEIT 的反作弊曾拦截 2.1.0 之前的 PawnIO 版本。如果它提到 PawnIO.sys，请用 winget upgrade namazso.PawnIO 更新驱动。并非所有反作弊都测试过：如果有哪个报错，请在 Discord 上告诉我们。

如何删除 PawnIO

卸载 Xenon 时，删除 PawnIO 之前会先询问，默认保留，因为电脑上的其他监控应用可能依赖它。要自己删除，请运行 winget uninstall namazso.PawnIO。通过它读取温度的应用在重新安装之前将不再显示温度。

问题

PawnIO 是病毒吗？

不是。它是知名开发者签名的驱动，源代码公开，LibreHardwareMonitor 和 Fan Control 等应用都会安装它。和所有内核驱动一样，它对系统有很深的访问权限，所以它只运行已签名的模块。

我需要 PawnIO 吗？

只有在使用它的应用里查看温度时才需要。Xenon 没有它也能用，只是缺少温度读数。

PawnIO 是谁做的？

独立开发者 namazso。它不是 Xenon、CORSAIR 或微软做的。
