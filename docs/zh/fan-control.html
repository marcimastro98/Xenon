不用曲线的风扇控制

Airflow 是 Xenon 中控制电脑风扇的功能。无需画曲线：选一个模式，再在最安静和最凉爽之间选一档，Xenon 会了解你的电脑，在温度允许的范围内让风扇尽量安静。

三步，几分钟

打开 Xenon → 风扇。Airflow 在你打开之前一直关闭。先进行几分钟的风扇检测，找出哪个控制对应哪个风扇，以及每个风扇最低能转多慢。检测期间风扇会比较吵，你也可以随时停止。

然后 Xenon 会观察，想观察多久都行：它不碰风扇，只显示它会怎么做，以及电脑大约会安静多少。满意了，再交给它控制。

风扇页面会先按位置列出它找到的东西，方便你对照机箱核实：主板有几个风扇接口、其中几个接着在转的风扇，显卡有几个风扇控制，以及有没有 iCUE LINK 集线器。

先选模式，再选安静还是凉爽

选择自动、安静、均衡、凉爽或交给电脑，再在“安静还是凉爽”里从最安静到最凉爽的五档中选一档。自动会按电脑正在做的事来选：空闲时安静，游戏开始时做好准备。

每次变化都会说明原因，显示在 Xenon 菜单和风扇小组件上：处理器在工作、游戏开始了、某个部件太热。当风扇快到能听见时，会弹出一次提示说明原因，能找到时还会写出是哪个程序。

Bit、Deck 按键和配对的手机也能切换模式：让 Bit 把风扇调安静一点，或者问它风扇为什么变快了。

为什么不用风扇曲线

风扇曲线把一个温度对应一个转速，所以风扇总是在热量到来之后才反应，还会追着每个短暂的峰值跑。Xenon 读的是负载，它比温度先上升，所以能更早、更平缓地调整风扇。

它会放过短暂的峰值，让同款风扇保持同样转速，避免互相嗡嗡作响；遇到见过的游戏启动时提前准备；通话时或夜里还能保持安静。用水冷时，它会对照散热器吸入的空气，跟随升温缓慢的冷却液。

各系统上能控制什么

系统Xenon 能控制的风扇
Windows主板上的风扇接口（通过 Xenon Sensors 服务）；NVIDIA 显卡（显卡凉的时候风扇照样会自己停转）；在 iCUE 关闭时，CORSAIR iCUE LINK 集线器及其风扇和水泵
Windows（测试版）AMD 显卡，以及传感器库支持的 USB 散热器：NZXT Kraken 及其风扇集线器、MSI CoreLiquid、ARCTIC、Razer
Linux（测试版）内核能控制的任何风扇芯片、AMD 显卡和带内核驱动的散热器，运行一条 Xenon 给出的命令后即可使用；iCUE LINK 集线器也支持。NVIDIA 显卡只读取
Mac 和笔记本不支持：它们自己控制风扇

Xenon 从未在真实硬件上试过的型号会标为测试版，只有在风扇检测确认 Xenon 放手时风扇会回到电脑自己的设置之后，才会去控制它。任何风扇都可以留给电脑自己控制。

安全第一

某个部件过热时，所有风扇都会全速运转，直到降温。温度读数中断、本该转的风扇停了、或 Xenon 5 秒没有响应，这些风扇都会交还给电脑自己的设置；退出 Xenon、更新、睡眠和关机时也一样。

水泵从不停转，也不会低于一半转速。健康标签页会留意风扇磨损和灰尘；换了新的处理器或显卡，会自动重新学习这个部件。

与 iCUE、NZXT CAM 或 Fan Control 一起用时

每个风扇只应由一个程序控制。如果 iCUE、NZXT CAM、Fan Control 或 MSI Afterburner 在控制同样的风扇，请在 Xenon 里把这些风扇留给电脑，或者关掉那个程序。Xenon 只在 iCUE 关闭时控制 iCUE LINK 集线器，iCUE 一接管它就放手。

在 Windows 上，主板风扇通过 LibreHardwareMonitor 和 PawnIO 来控制，PawnIO 是 Fan Control 也在用的已签名驱动：PawnIO 是什么，Xenon 为什么要安装它。

常见问题

Airflow 免费吗？

是的。风扇控制是 Xenon 的一部分，Xenon 免费，也不需要账户。

笔记本或 Mac 能用吗？

不能。笔记本和 Mac 自己控制风扇，所以 Xenon 不去碰它们。

Xenon 能在没有 iCUE 的情况下控制 iCUE LINK 风扇吗？

可以。在 Windows 上可用，在 Linux 上为测试版，前提是关闭 iCUE：在风扇页面点使用 LINK 集线器，或在风扇的选项里打开控制 iCUE LINK 集线器。集线器上的风扇和水泵会一起加入，灯光也由 Xenon 自己点亮。关掉后，集线器会立刻回到它自己保存的设置。

如果我不喜欢 Xenon 的做法怎么办？

选择交给电脑，或关闭让 Xenon 控制风扇，风扇就会回到电脑自己的设置。也可以只把某一个风扇留给电脑。
