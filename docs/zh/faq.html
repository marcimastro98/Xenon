关于 Xenon

Xenon 是什么？

一款免费的仪表盘，放在电脑旁边的屏幕上。它显示系统信息（CPU、GPU、温度、网络）、正在播放的音乐、日历、天气和笔记，还有 Deck：点一下就能打开应用、控制音乐或在电脑上执行快捷操作的按键。你可以用小组件和主题自由搭配。支持 Windows，macOS 和 Linux 为测试版。

需要 Xeneon Edge 或 CORSAIR 电脑吗？

不需要。Xenon 是围绕 CORSAIR Xeneon Edge 设计的，但它能在任何电脑上运行，不需要 CORSAIR 的硬件或软件。只有当你想把仪表盘放进 iCUE 小组件，或要控制 CORSAIR 的 RGB 设备时，才用得到 iCUE。

可以用哪块屏幕？

只要电脑能在上面显示窗口的屏幕都可以：一台闲置显示器、一块触摸屏，或主屏幕上的一个窗口。应用第一次运行时会问你要在哪块屏幕上打开。平板或手机也可以，通过你自己的 Wi-Fi 连接：显示的是你真正的仪表盘，布局、小组件和主题都一样，按键也真的在电脑上执行。具体做法见手机指南和平板指南。

能在 Mac 和 Linux 上用吗？

可以，目前为测试版：除了 Windows 10 和 11，还支持 macOS 11 或更高版本（Apple Silicon 和 Intel 共用一个下载）以及 64 位 Linux。三个系统上的仪表盘、小组件和商店都一样。macOS 和 Linux 上还缺少一些传感器和系统操作，没有数据的磁贴会直接说明，而不是一直加载。各系统能用什么，见 Mac 和 Linux 页面。

在 Mac 上首次启动：应用尚未经过公证，所以 macOS 会阻止第一次启动。在 macOS 15 及更高版本中，打开系统设置 → 隐私与安全性，滚动到底部，点击仍要打开。在 macOS 11 到 14 中，右键点击应用，选择打开，再点一次打开。每个版本只需一次。

免费吗？支持者能得到什么？

应用免费，没有广告，也不需要账号。在 Buy Me a Coffee 上的支持者可以获得目录里的每月新品、Lyrics 和 Developer cleanup 两个小组件、Discord 身份组，以及 Hall of Supporters 上的位置。价格为每月 5 USD 或每年 50 USD，也可以一次性支付 5 USD 起，每 5 USD 算一个月。兑换码通过邮件发送，在设置 → 支持 Xenon 中输入。每种方案每月还附带 300 火花，也就是 Xenon 的点数。

支持者通行证每台电脑可免费试用 7 天，仅一次：它会解锁支持者专属内容和 Lyrics。限量内容，以及部分刚发布几周的新内容，仅限支持者。支持结束后，Lyrics 和 Developer cleanup 仍然保持解锁。支持满一年，还会根据你的配色或照片为你制作一个专属主题，并署上你的名字发布。

火花是什么？

火花是 Xenon 的点数，1 火花等于 1 美分。在不使用自己 API 密钥时使用助手，以及购买商店里以火花出售的内容，都会用到它。每个月的支持都包含 300 火花，每月初重置。购买更多火花不需要成为支持者：它们在 Buy Me a Coffee 的附加项目中，500 火花 5 USD，1050 火花 10 USD，2200 火花 20 USD，购买的火花永不过期。如果你不是支持者，第一次购买时会通过邮件收到一个火花代码（XC-…），把它填在和支持者代码相同的输入框里。

用火花购买的内容永久归你，包含更新，最多可在 3 台电脑上使用，重新安装不再收费。限量版从不以火花出售。

使用

会拖慢游戏吗？

它的设计就是不拖慢。游戏运行时，游戏模式会淡出动态背景并暂停动画效果，最耗资源的磁贴（浏览器和第二屏幕的画面流）也会停下，直到你玩完。这类实时磁贴和 Home Assistant 只在显示在屏幕上时才保持连接。

在 Windows 上，游戏中触摸应用里的仪表盘是安全的：光标会立刻回到游戏所在的显示器，点击也不会抢走游戏的焦点。

怎么添加小组件和主题？

在仪表盘上点 + 即可添加内置磁贴。想要更多，打开设置 → 商店：社区制作的主题、背景、小组件、氛围场景和合集，应用前都会先预览，一点即可安装。也可以在本站的目录里浏览同样的内容。

能显示温度和游戏帧率吗？

可以。在 Windows 上，安装程序会设置温度读取（需要允许一次管理员提示），PresentMon 能显示正在运行的游戏的真实帧率，全屏游戏也可以；如果没装，在设置 → 游戏模式里一键安装。在 macOS 上，温度和 GPU 负载来自 macmon（brew install vladkens/tap/macmon）。在 Linux 上，游戏帧率需要 MangoHud，并通过它启动游戏。

支持 Spotify、Home Assistant 和 RGB 灯光吗？

支持，每一项都是可选的，连接之前都是关闭的。

  • Spotify：正在播放的内容会显示在媒体磁贴里。在设置中关联账号后，可以拖动进度、收藏、随机播放和播放列表，也能在 Deck 上操作（控制播放需要 Spotify Premium）。
  • Home Assistant：在设置 → 智能家居中填入地址和长期访问令牌进行连接，然后就能用磁贴或 Deck 按键控制灯光、传感器和场景。
  • RGB：CORSAIR 设备通过 iCUE 控制，WLED、OpenRGB、Philips Hue、Nanoleaf、Govee、LIFX 和 Yeelight 通过局域网控制，在 Windows 上还能通过 USB 控制技嘉和 AORUS 主板。
能保存布局或搬到另一台电脑吗？

可以。设置 → 备份 → 导出备份 会把布局、Deck、日历、任务、计时器、笔记、设置和自定义背景保存到一个文件里。在另一台电脑上用导入备份就能全部恢复。API 密钥和密码永远不会写进文件，所以各项集成会请你重新连接；社区小组件会列出来，方便你用它们的代码重新安装。

出现问题时

Windows 说 Xenon 是病毒，安全吗？

这是误报。Windows 安装程序从 4.11.9 版起就带有签名，但微软对新文件的信任需要时间积累，所以刚发布的版本仍可能被 Defender、SmartScreen 或浏览器警告。你可以自己检查文件：每个版本都附带签名的 SHA256SUMS 列表，下载页面上有用来比对的那条命令。也可以从 Microsoft Store 安装 Xenon。

  • 被 Defender 删除了：打开Windows 安全中心 → 病毒和威胁防护 → 保护历史记录，选中 Xenon 的条目，选择还原。然后把 %LOCALAPPDATA%\Xenon 和 %LOCALAPPDATA%\Programs\Xenon 加到排除项里。
  • 浏览器拦截了下载：按 Ctrl+J 打开下载列表，选择保留。
  • 无法启动，也没有任何提示：在 Windows 11 上通常是Windows 安全中心 → 应用和浏览器控制里的智能应用控制。先在开启状态下试试最新版本：一旦关闭，不重置电脑就无法再打开。

只有对从官方 Releases 页面下载并核对过哈希的文件，才可以忽略警告。

Xenon 自己关闭了

打开托盘菜单，选择 Open crash log。如果最后一行是 PANIC，说明是应用自身出错：把这一行贴到 Discord 或错误报告里，它会指出确切位置。如果最后一行是 launched，后面什么都没有，说明是外部程序关掉了它，几乎总是杀毒软件：在保护历史记录里找到那个时间点的条目，还原它，并添加上一个问题中的两个排除项。

看不到 CPU 温度

在 Windows 上，重新运行安装程序并允许管理员提示：读取温度需要 LibreHardwareMonitor 和 PawnIO，它们包含驱动级组件，这就是提示的用途。拒绝的话其他功能照常可用，只是没有温度。在 macOS 上，安装 macmon。有些笔记本和主板根本不提供传感器，这时磁贴会直接说明，而不是显示编造的数字。

怎么更新或卸载？

Xenon 会自动更新：有新版本时仪表盘会提示你，点一下就下载，安装前先校验签名，出了问题会自动恢复到上一个版本。你的设置、布局和笔记都会保留。

要卸载，在 Windows 上运行 UNINSTALL.bat，在 macOS 上运行 UNINSTALL.command，在 Linux 上运行 ./UNINSTALL.sh。它会删除应用、开机启动项和你的数据；想保留设置、布局和笔记，Windows 上加 -KeepData，其他系统加 --keep-data。

隐私与帮助

会把我的数据发到别处吗？需要账号吗？

你的设置、笔记、任务、日程、Deck 和文件索引都留在你的电脑上。应用里没有分析 SDK、没有崩溃自动上报，也没有行为追踪。它只在少数情况下联网：检查更新，以及你自己开启的服务，比如天气或 Spotify。隐私页面列出了它可能发出的每一个请求以及发送的内容。

没有 Xenon 账号。你唯一需要输入的是支持者兑换码，各项集成使用它们自己的登录。

去哪里求助？

到 Discord 上提问最快，反复出现的问题会加到这个页面上。能复现的错误，请开一个 GitHub issue，写明你的系统、做了什么以及发生了什么。

个人使用免费，包括在你工作用的电脑上。出售 Xenon 或把它放进商业产品，需要事先获得书面许可：给我发邮件。
