关于 Xenon

Xenon 是什么？

一款免费应用，把电脑的小组件放到任何屏幕上：温度和负载、FPS、音乐、日历、天气和笔记，可以放在桌面、游戏上方、闲置显示器、平板或手机上。它还有 Deck（在电脑上执行操作的触控按键）、带即时回放的屏幕录制、可以对话的助手 Bit，以及主题和小组件商店。它在 Windows 上运行，macOS 和 Linux 为测试版。

需要 Xeneon Edge 或 CORSAIR 电脑吗？

不需要。Xenon 起步于 CORSAIR Xeneon Edge，但它能在任何电脑上运行，不需要 CORSAIR 的硬件或软件。在 Edge 上，有没有 iCUE 都能用：只有想在 iCUE 小组件里显示 Xenon，或控制 CORSAIR RGB 设备时才需要 iCUE。详情见 Xeneon Edge 指南。

可以用哪块屏幕？

你现有的屏幕就行。只有一台显示器时，小组件放在桌面或游戏上方，每个的位置由你决定。闲置显示器或触摸屏可以放下整页小组件：应用首次运行时会询问使用哪块屏幕。平板或手机也可以，目前为测试版，通过你自己的 Wi-Fi 连接：显示相同的布局、小组件和主题，按键真的在电脑上执行。做法见单屏指南、手机指南和平板指南。

能在 Mac 和 Linux 上用吗？

可以，目前为测试版：macOS 11 或更高版本（Apple Silicon 和 Intel 同一个下载）和 64 位 Linux，此外还有 Windows 10 和 11。小组件和商店在三个系统上都一样。macOS 和 Linux 上还缺少一些传感器和系统操作，系统上没有数据的小组件会直接说明，而不是一直加载。Mac 和 Linux 页面列出了可用的功能。

在 Mac 上首次启动：从 5.0 起，应用经过了 Apple 公证，所以 macOS 只会询问一次是否打开从互联网下载的应用，点击打开即可。如果 macOS 提示无法检查 Xenon，说明这份副本早于 5.0，请下载最新的 .dmg。

价格与支持者

免费吗？支持者能得到什么？

应用免费，没有广告，也不需要账号。在 Buy Me a Coffee 上的支持者可以获得目录里的每月新内容、“歌词”和“开发者清理”两个小组件、Maker 导出、Discord 身份组，以及 Hall of Supporters 上的位置。价格为每月 5 USD 或每年 50 USD，也可以一次性支付：5 USD 一个月，25 USD 五个月，50 USD 十二个月。低于 5 USD 的付款只算打赏：不解锁任何内容，也没有火花。兑换码通过邮件发送，在设置 → 支持 Xenon 中输入。每种方案每月还附带 300 火花，也就是 Xenon 的点数。未用完的不会结转。

支持结束后，你解锁的内容及其更新、购买的火花都会保留，“歌词”和“开发者清理”仍然保持解锁。Maker 导出和每月火花不再提供。支持满一年，还会根据你的配色或照片为你制作一个专属主题，并署上你的名字发布。

可以先试用支持者通行证吗？

可以：用你的邮箱地址申请，代码会通过邮件发送。每台电脑可免费试用 7 天，仅一次，无需银行卡，它会解锁支持者内容和“歌词”。火花和“开发者清理”不包含在试用中，新内容通常在上线 30 天后加入试用，限量内容需要单独的代码。试用结束后，试用过的内容会从电脑上移除，之前的主题会恢复，小组件仍在原位。

火花是什么？

火花是 Xenon 的点数，1 火花等于 1 美分。在不使用自己 API 密钥时使用 Bit，以及购买商店里以火花出售的内容，都会用到它。每个月的支持都包含 300 火花，优先使用，每月初重置，不会结转。购买更多火花不需要成为支持者：从 Xenon 5.0.0 起，套餐在商店的“火花”中，500 火花 5 USD，1050 火花 10 USD，2200 火花 20 USD，购买的火花永不过期。如果你不是支持者，第一次购买时会通过邮件收到一个火花代码（XC-…），把它填在和支持者代码相同的输入框里。

用火花购买的内容最多可在 3 台电脑上使用，包含发布的所有更新，重新安装不再收费。限量版从不以火花出售。

可以退款吗？

卖家是 Xenon，款项由 Buy Me a Coffee 收取。付款后 14 天内，你可以申请退还会员付款或火花套餐：发邮件至 support@xenon-app.com，退款会通过 Buy Me a Coffee 完成。退款后，套餐和用这些火花购买的内容都会被移除。已在 Bit 上花掉的火花会从余额中扣除，在下一个套餐之前余额可能低于零。

用火花购买的商店内容会立即交付。购买前你需要勾选方框提出这一要求，交付开始后撤回权即告结束。

使用

会拖慢游戏吗？

它的设计目标就是不拖慢游戏。游戏运行时，游戏模式会淡出动态背景并暂停动画效果，最重的小组件（Browser 和 Second screen 的串流）会停止，直到你结束游戏。磁盘扫描等 Xenon 自身的后台任务也会暂缓。这类实时小组件和 Home Assistant 只有在屏幕上显示时才保持连接。

在 Windows 上，游戏中触碰另一块屏幕上的 Xenon 是安全的：光标会立刻回到游戏所在的显示器，触碰也不会抢走游戏的焦点。

反作弊会标记它或让我被封号吗？

Xenon 从不向游戏注入代码，也从不挂钩游戏进程。它在上方绘制自己的窗口，通过 PresentMon 从系统读取帧时间，所以游戏内部没有任何东西可供反作弊标记。

唯一工作在驱动层的部分是读取温度的 PawnIO，它也在游戏之外运行。FACEIT 的反作弊曾拦截 2.1.0 之前的 PawnIO 版本：如果它提到 PawnIO.sys，请运行 winget upgrade namazso.PawnIO。并非所有反作弊都测试过，如果有哪个报错，请在 Discord 上说明。

能显示温度和游戏帧率吗？

可以。在 Windows 上，“风扇”或“能耗”小组件中的安装传感器会设置温度读取（需要确认一次管理员提示），PresentMon 提供运行中游戏的真实帧率，包括全屏游戏；如果缺少，设置 → 性能 → 游戏模式可以安装它。FPS 叠加层在无边框全屏或窗口模式的游戏上方显示。macOS 上的温度和 GPU 负载来自 macmon（brew install vladkens/tap/macmon）。Linux 上的游戏内 FPS 需要 MangoHud，并通过它启动游戏。

可以录制我的游戏吗？

可以。即时回放会保留最近几分钟，让你在精彩时刻发生后再保存；录制功能可以录整个屏幕或一个窗口。它还能截图和读取屏幕上的文字。所有内容都保存在你的电脑上，不上传任何东西，也不需要账号。在 Windows 上免费，macOS 和 Linux 为测试版。做法见录屏指南。

Bit 是什么？我需要 API 密钥吗？

Bit 是 Xenon 内置的助手。你可以打字，或说“Hey Bit”，它会回答、在电脑上执行操作，并和你一起做小组件。开始时不需要密钥：新安装在发送第一条消息时获得 30 试用火花，仅限 Bit 使用，有效期 7 天，无需银行卡和邮箱。之后你可以购买火花，或使用自己的 Gemini、OpenAI 或 Anthropic 密钥、通过 Ollama 或 OpenAI 兼容服务器运行的本地模型，或用你自己的订阅使用 Claude Code 和 Codex。

它能代替 Stream Deck 吗？

它能在你已有的屏幕上做类似的事：Xeneon Edge、闲置显示器、平板或手机都行。一个按键可以打开应用、发送快捷键、切换 OBS 场景、静音 Discord 或运行 Streamer.bot 动作，还可以亮起来显示所控制对象的状态。它不使用 Stream Deck 硬件或其插件。所有动作见 Deck 指南。

怎么添加小组件和主题？

按页面上的 + 添加内置小组件。要把小组件放到桌面或游戏上方，按 Alt+Shift+X 打开 Xenon 菜单，或让 Bit 帮你。想要更多，打开设置 → 商店：主题、背景、小组件、环境场景和合集，应用前都能预览，一键安装。同样的内容也可以在本站的目录中浏览。

我能自己做小组件或主题吗？

可以，不用写代码。测试版 Maker 在浏览器里制作小组件和主题，Bit 可以在那里或在应用里和你一起做。Maker 的所有功能都可以免费试用；保留项目和安装你的作品仅限支持者。如果你写代码，创作指南介绍了 Widget SDK。

支持 Spotify、Home Assistant 和 RGB 灯光吗？

可以，每一项都是可选的，连接之前保持关闭。

  • Spotify：你播放的内容会显示在“播放”小组件中。在设置中关联账号后，可以拖动进度、点赞、随机播放和使用歌单，也能在 Deck 上操作（播放控制需要 Spotify Premium）。
  • Home Assistant：在设置 → 智能家居中用你的地址和长期访问令牌连接，然后从小组件或 Deck 按键控制灯光、传感器和场景。
  • RGB：通过 iCUE 连接 CORSAIR 设备，通过网络连接 WLED、OpenRGB、Philips Hue、Nanoleaf、Govee、LIFX 和 Yeelight，在 Windows 上通过 USB 连接 GIGABYTE 和 AORUS 主板。
能保存布局或搬到另一台电脑吗？

可以。设置 → 通用 → 备份 → 导出备份会把布局、Deck、日历、任务、计时器、笔记、设置、Bit 的记忆和自定义背景保存到一个文件。在另一台电脑上，导入备份会恢复全部内容。密码、令牌和 API 密钥绝不会写入文件，所以集成需要重新连接；社区小组件会列出来，方便用代码重新安装。文件中包含私密日历链接和 Deck webhook，请妥善保管。

出现问题时

Windows 说 Xenon 是病毒，安全吗？

这是误报。Windows 安装程序从 4.11.9 版起就带有签名，但微软对新文件的信任需要时间积累，所以刚发布的版本仍可能被 Defender、SmartScreen 或浏览器警告。你可以自己检查文件：每个版本都附带签名的 SHA256SUMS 列表，下载页面上有用来比对的那条命令。也可以从 Microsoft Store 安装 Xenon。

  • 被 Defender 删除了：打开Windows 安全中心 → 病毒和威胁防护 → 保护历史记录，选中 Xenon 的条目，选择还原。然后把 %LOCALAPPDATA%\Xenon 和 %LOCALAPPDATA%\Programs\Xenon 加到排除项里。
  • 浏览器拦截了下载：按 Ctrl+J 打开下载列表，选择保留。
  • 无法启动，也没有任何提示：在 Windows 11 上通常是Windows 安全中心 → 应用和浏览器控制里的智能应用控制。先在开启状态下试试最新版本：已更新的 Windows 之后可以重新打开，较旧的 Windows 则要重置或重装电脑后才能打开。

只有对从官方 Releases 页面下载并核对过哈希的文件，才可以忽略警告。

Xenon 自己关闭了

打开托盘菜单，选择 Open crash log。如果最后一行是 PANIC，说明是应用自身出错：把这一行贴到 Discord 或错误报告里，它会指出确切位置。如果最后一行是 launched，后面什么都没有，说明是外部程序关掉了它，几乎总是杀毒软件：在保护历史记录里找到那个时间点的条目，还原它，并添加上一个问题中的两个排除项。

看不到 CPU 温度

在 Windows 上，在“风扇”或“能耗”小组件中，或在设置 → 性能中，按安装传感器并接受管理员提示：读取温度需要 LibreHardwareMonitor 和 PawnIO（包含驱动层组件），以及一个替 Xenon 读取它们的小型服务，这就是提示的用途。Xenon 本身仍以普通权限运行。拒绝的话其他功能都正常，只是没有温度。在 macOS 上，请安装 macmon。有些笔记本和主板完全不提供传感器，这时小组件会直接说明，而不是显示编造的数字。

怎么更新或卸载？

Xenon 会自动更新：有新版本时会询问你，点一下就下载，安装前先校验签名，出了问题会恢复上一个版本。你的设置、布局和笔记都会保留。

在 Windows 上卸载，打开设置 → 应用 → 已安装的应用，找到 Xenon 并点击卸载。在 macOS 上，双击 ~/Library/Application Support/Xenon 中的 UNINSTALL.command；在 Linux 上，在 Xenon 文件夹中运行 ./UNINSTALL.sh。两者都会删除应用、启动项和你的数据；要保留设置、布局和笔记，请运行 UNINSTALL.sh --keep-data。

隐私与帮助

会把我的数据发到别处吗？需要账号吗？

你的设置、笔记、任务、事件、Deck 和文件索引都留在电脑上，应用不记录你的操作。它有三个匿名计数器，没有任何标识符：随更新检查发送的版本、系统和安装的大致时长；从商店安装作品时在其安装数上加 1；以及每天一次统计每个功能运行和失败的次数。它们都不包含你搜索、输入或制作的内容。新安装时默认开启，你可以在设置 → 通用 → 更新中逐个关闭。

应用还会联网检查更新、获取一小段公告列表，以及使用你自己开启的服务，比如天气或 Spotify。你问 Bit 的内容会发送到你选择的 AI 服务；使用本地模型时不会离开电脑。隐私页面列出了它可能发出的每个请求及其内容。

Xenon 没有账号。只有在支持 Xenon、购买火花或申请试用（需要邮箱地址）时才需要输入代码，集成使用各自的登录。

去哪里求助？

到 Discord 上提问最快，反复出现的问题会加到这个页面上。能复现的错误，请开一个 GitHub issue，写明你的系统、做了什么以及发生了什么。

个人使用免费，包括在你工作用的电脑上。出售 Xenon 或将其放入商业产品需要事先获得书面许可：请写信至 support@xenon-app.com。
