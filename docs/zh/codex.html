在第二块屏幕上使用 OpenAI Codex

Xenon 的 Codex 磁贴显示你套餐的用量窗口、每日令牌、电脑上正在工作的会话以及它们的每个请求，并提供允许、拒绝和在 Codex 中回答。它放在电脑旁边的屏幕上：Xeneon Edge、显示器、平板或已配对的手机。

最后更新：2026年10月6日

通过 + 按钮在系统下添加磁贴。只要电脑上安装并登录了 Codex，套餐信息就会显示。会话和审批需要连接 Codex，在磁贴里就能完成。支持 Windows，macOS 和 Linux 为 Beta 版。

套餐用量

Codex 会报告你套餐的用量窗口：每个窗口用了多少、何时重置。Xenon 把每个窗口显示为一条进度条，带有到重置的倒计时，以及均匀使用时此刻应在的位置标记。数值在 70% 时变为琥珀色，90% 时变为红色。

每个窗口的时长由 Codex 提供，因此磁贴按实际情况标注：付费套餐通常是 5 小时和一周，Free 套餐是一个 30 天的窗口。

磁贴的用量一面显示今天、7 天、30 天和累计的令牌，并为最近 30 天每天显示一列。这些是 Codex 针对整个账户报告的数字，包含所有设备和应用，而不只是这台电脑。

会话与最近的对话

连接 Codex 后，每个会话一开始就会占一行：你让它做什么、模型，以及它在工作还是在等你。下方列出 Codex 保存的对话，以及它们的来源：ChatGPT 应用、编辑器或终端。

会话信息来自 Codex 的钩子。Codex 在 codex 命令中运行钩子；ChatGPT 应用和编辑器扩展是否也运行，取决于你的 Codex 版本。套餐和对话列表不依赖钩子，三者都涵盖。

回应请求

当 Codex 会话要运行命令或修改文件时，请求会显示在磁贴上，附带命令，或改动涉及的文件（删除会被标出），以及三个按钮：允许、拒绝和在 Codex 中回答，后者会立即把问题交回 Codex。卡片会说明请求的特别之处：网络、发布你的工作、项目之外的文件、超出会话的权限，或无法撤销的操作。

无法撤销的请求，例如 rm -rf 或删除文件的补丁，需要长按按钮才能允许，而不是点按。25 秒未回应的请求会占满整个屏幕，避免在其他页面上被忽略。

不会替你批准任何请求。请求在磁贴上等待时，Codex 不会显示它自己的提示，因此 90 秒后或 Xenon 关闭时，请求会交回 Codex，照常询问。在设置 → Codex中可以更改等待时间或关闭请求。

要在手机上回应，请将手机与 Xenon 配对（Beta）。手机会显示同样的仪表盘和同样的按钮。如何配对手机。

连接 Codex

  1. 通过 + 按钮在系统下添加 Codex 磁贴。
  2. 在磁贴上点按 Codex，然后点按连接。
  3. 打开 Codex，输入 /hooks 并信任 Xenon 的钩子。Codex 只有在你信任新钩子后才会运行它；Xenon 从不替你这样做，因为这是 Codex 自己的安全检查。
  4. 开始一个新会话。钩子作用于此步骤之后开始的会话，磁贴会显示 Codex 是否已信任这些钩子。

连接只修改一个文件：位于 ~/.codex 或 CODEX_HOME 所指文件夹中的 Codex hooks.json。它添加五个钩子，用 Node 运行 Xenon 的一个小脚本，该脚本向 127.0.0.1（你自己的电脑）上的 Xenon 报告。你自己的钩子保持原样和原有顺序，Xenon 不会改动 config.toml。

在第一次修改前，Xenon 会在旁边保存一份文件副本 hooks.json.xenon-backup。如果文件无法读取，Xenon 会保持原样并告诉你。

卸载 Xenon 会移除它添加的钩子并删除备份；你自己的钩子不受影响。若不卸载也想这样做，可在磁贴上点按断开连接，或在 Xenon 的安装文件夹中运行 node server/codex-link.js unlink。

数据去向

磁贴不使用任何 API 密钥，也从不读取你的登录信息。套餐信息来自 codex app-server，即 ChatGPT 应用和编辑器扩展与 Codex 通信所用的程序。Xenon 只在磁贴位于仪表盘上时启动自己的副本，只请求读取，并在不再需要几分钟后关闭它。

钩子带着 Xenon 创建的密钥向 127.0.0.1（你自己的电脑）报告。没有密钥的报告会被拒绝；密钥从 Xenon 自己的数据文件夹读取，因此不会出现在命令行中。会话状态只保存在内存中，Xenon 重启后清空。

你安装的小组件在获得允许后，可以通过 codex 数据流读取套餐数字：百分比、窗口时长、令牌数和正在工作的会话数。绝不包含文件夹、项目、对话、命令或你的邮箱。

常见问题

能在第二块屏幕上查看 Codex 的使用限额吗？

可以。只要安装并登录了 Codex，磁贴就会显示套餐的每个用量窗口、已用多少以及到重置的倒计时。这不需要连接 Codex。

它能配合 ChatGPT 桌面应用使用吗？

套餐、用量和对话列表涵盖 ChatGPT 应用、编辑器扩展和 codex 命令中的 Codex，因为它们共享同一账户和引擎。实时会话和审批需要 Codex 运行钩子，codex 命令会运行它们。

如果我不回应请求会怎样？

不会批准任何内容。90 秒后或 Xenon 关闭时，请求会交回 Codex，照常询问你。

为什么必须在 Codex 中信任钩子？

Codex 只有在你信任了那个钩子之后才会运行它。这是 Codex 自己的安全检查，因此 Xenon 从不替你这样做。如果 Xenon 或 Node 换了文件夹，钩子会变化，Codex 会请你再次信任，磁贴会提示你。

磁贴能配合 API 密钥使用吗？

会话和审批可以。套餐窗口只存在于 ChatGPT 套餐中，因此使用 API 密钥时磁贴没有可显示的窗口。
