把手机当作第二块屏幕测试版

想用 Xenon，你需要一块可以整天开着的屏幕：一台闲置显示器、一台旧平板，或者一台 Xeneon Edge。真正把大多数人挡在门外的是这一点，不是功能。可你口袋里已经有一块屏幕了。这篇文章就是教你怎么用它。

手机上出现的不是遥控器，也不是预览。它就是你的仪表盘，布局、组件、主题都一模一样。Deck 按键真的在电脑上执行。你按暂停，音乐就停。你改一个设置，一秒后电脑上也改好了。不需要账号，没有云端，没有要装的应用，也没有任何东西离开你家的网络。

这些是布局示意图，不是真实截图。真实的仪表盘上会有主人的日历、笔记和文件路径，而这个页面是公开的。

能做什么，不能做什么

配对过的设备就算是你自己的设备。除了少数几件事，电脑上仪表盘能做的它都能做。那几件事的原因是同一个：必须有人坐在那台电脑前面。

  • ✓整个仪表盘：传感器、组件、页面和主题
  • ✓Deck 按键。它们在电脑上执行，不在手机上
  • ✓媒体、音量、麦克风静音和应用切换
  • ✓商店：组件、图标包、音效包和主题
  • ✓Xenon AI，以及会保存到电脑的设置
  • ✓双向发送照片和文件
  • ✗系统的授权弹窗。Windows、macOS 和 Linux 都只把它画在电脑自己的屏幕上，所以只能在电脑上回应
  • ✗更新 Xenon。更新会重启手机正连着的那个服务
  • ✗系统安装程序（helper、PresentMon、驱动）。每一个都会往硬盘里装东西
  • ✗添加或删除已配对的设备。这样一部手机既不能拉别的设备进来，也不能删掉那台能把它踢出去的设备

开始之前有一件事要知道。 配对过的设备在你删掉它之前，一直是通向你电脑的一条路。所以手机丢了或者转手了，记得把它删掉。设备列表就是干这个用的：可以只删一台，也可以一键删除全部。被删掉的设备当场就断开。

把照片和文件传过去

手机配对后，就可以往电脑发文件，也可以从电脑取文件。在手机上打开 Xenon，点“照片和视频”或“其他文件”，选好要发的内容，它们就会以原来的名字落在电脑的 Download/Xenon 里。反方向也一样：从资源管理器或访达把文件拖到磁贴上，再用手机下载。不经过任何别人的服务器。

在 iPhone 上，发送内容需要先打开 Xenon。iOS 不允许任何网站出现在它的分享按钮里，网页这边也没有绕过的办法。在 iPhone 上下载的文件会进入“文件”，而不是相册：长按照片，选择“添加到照片”。

两条路，选一条。

在家

用自家 Wi-Fi

大约 30 秒，不用装任何东西

  • 打开开关，扫个码，就好了
  • 只要在同一个 Wi-Fi 下就能用
  • 走普通 HTTP，所以装不了应用、用不了麦克风、收不到通知
任何地方

安全连接，在家在外都行

大约 5 分钟，一个按钮加网页上的一个开关

  • 全程加密，而且不用在路由器上开任何端口
  • 能像应用一样装到手机上，有自己的图标
  • 让 Xenon AI 可以用麦克风
  • 就算路由器换了地址，访问地址也不会变

这不是二选一。第二条路是在第一条旁边多开一扇门，不是替掉它。如果你只在家里用 Xenon，先用第一条就行。

在家，三十秒搞定

  1. 在电脑上打开 设置，然后 手机

    需要的全部都在 手机访问 这一个面板里。捷径：第一次打开 Xenon 时它会问你想把它放在哪块屏幕上，在那里选 我的手机或平板，就会直接带你到这个面板，并把这些步骤打开在里面。面板顶部的 分步指南 按钮随时可以再打开它们。

  2. 打开“允许其他设备访问”

    你不打开它就一直关着。关着的时候，Xenon 只回应这台电脑，别的一概不理。就算有人扫描你的网络，得到的回应和一个根本没有这个功能的版本完全一样，看不出这个功能存在。

    允许其他设备访问关着的时候，Xenon 只回应这台电脑。

  3. 按“添加设备”

    电脑上会出现一个二维码，下面还有八位字符的验证码。它是一张邀请函，不是密码。三分钟就过期，错几次就直接作废。

  4. 用手机摄像头扫一下

    仪表盘就在手机浏览器里打开了。设置到此结束。你没装任何东西，验证码也从没到过任何服务器，因为它藏在浏览器不会往外发的那一段地址里。

两台设备必须在同一个 Wi-Fi 下。如果路由器开了客户端隔离，或者你连的是访客网络，那么即使在同一个 Wi-Fi 下也互相看不见。

在任何地方，还能当应用用

在普通 HTTP 下，浏览器会扣住一整批能力，怎么设计都拿不回来：页面装不成应用，用不了麦克风，也收不到通知。这才是第二条路存在的真正原因，跟距离无关。

为此 Xenon 用了 Tailscale。你的电脑和手机加入一个只属于你的小型专用网络，仪表盘拿到一张真证书和一个永远不变的地址，而且路由器上一个端口都不用开。这个地址在公共 DNS 里根本不存在，外面没有任何东西可以被找到。

按一个按钮，剩下的交给 Xenon

在同一个面板里，安全访问，在外也能用 下面有一个按钮。它会装好 Tailscale，打开登录页面，等你登录完，然后自己把安全连接建起来。

安全访问，在外也能用走 Tailscale 加 HTTPS。可以装成应用，还能用麦克风和通知。
帮我设置

中间会停一次，这是故意的。 证书是整个专用网络的设置，要在 Tailscale 自己的网站上改。Xenon 也可以替你改，但那需要你先在同一个网站上生成一把密钥，步骤反而更多。所以 Xenon 就停在那里，把链接给你，等你弄完它自己会发现。窗口开着不用管。

  1. 按“帮我设置”

    系统会问你要不要允许安装 Tailscale。然后会打开一个浏览器标签让你登录。Google、Microsoft 或 GitHub 账号都行，你并不是在注册 Xenon 账号。

  2. 打开 HTTPS 证书

    这是唯一一步 Xenon 替不了你。它提示的时候，按它给出的按钮，会打开 login.tailscale.com/admin/dns。往下找到 HTTPS Certificates，按 Enable。任何套餐都免费。然后回到 Xenon，它已经自己往下走了。

  3. 用同一个账号在手机上装 Tailscale

    从 App Store 或 Google Play 装好，用刚才那个账号登录，再把开关打开。这一步最容易被漏掉，症状也很好认：手机会说根本打不开这个地址。这不是坏了。那个地址只存在于你自己的网络里，这也正是互联网上没人能碰到它的原因。

  4. 在新地址上重新配对手机

    按 添加设备 再扫一次。浏览器会把配对绑在当时那个地址上，所以在家里地址配过的手机，在安全地址上并没有配过。之后你只需要新地址：在家在外都能用。

  5. 把它加到主屏幕

    在 Safari 里点分享，选 添加到主屏幕。Android 上 Chrome 会主动提示安装。之后 Xenon 会用自己的图标全屏打开，没有地址栏。这里麦克风可以用，所以 Xenon AI 能通过手机听，而不是通过电脑。通知也可以用：在设置里进入手机，为这台设备打开通知，倒计时结束时就算应用关着也能通知到你。

遇到问题的时候

手机说打不开这个地址

几乎都是手机还没进到你的专用网络里。在手机上打开 Tailscale，确认开关真的是开着的，光装上应用不算。iPhone 上开着的时候状态栏会显示 VPN。再确认一下你用的是和电脑同一个账号，两个账号就是两个网络，互相看不见。

组件显示成一个白框加一堆纯文字

在 iPhone 和 iPad 上，4.11 之前每次都会这样：一条安全规则让组件加载不了自己的样式，而且只在 Safari 上发生，所以同一个组件在电脑上看着好好的。更新 Xenon 就没有了。如果更新后还有，说明页面跑的代码比电脑上的旧：通常是更新前就开着的标签页，被系统从内存里恢复出来而没有重新加载。下拉刷新往往不够，把标签页整个关掉，再重新打开地址。

之前好好的，现在手机变成没配对了

多半是路由器给电脑换了地址。配对是跟着当时那个地址走的，地址一变，手机看上去就成了没配对，得重新添加。两个办法：在路由器设置里给电脑固定一个地址，或者用上面那条安全的路，它的地址永远不变。

装好的应用又让我配对一次

在 iPhone 上，加到主屏幕的应用有自己独立的存储，和 Safari 分开，所以你在浏览器里做的配对不会跟过去。再生成一个码，从装好的应用里配一次。它会在设备列表里单独占一行，你可以给两个都改名以便区分。

Xenon 说 HTTPS 证书没有启用

这是整个专用网络的设置，不是这台电脑的。打开 login.tailscale.com/admin/dns，找到 HTTPS Certificates，按 Enable。几秒钟内 Xenon 就会发现。

平板上显示的是桌面版布局，我想要堆叠的那种

这是故意的。平板足够大，放得下真正的网格，而这本来就是用平板的意义；iPad 无论怎么拿都远超过切换的尺寸线。如果你在某台设备上更喜欢堆叠布局，可以自己选，Xenon 会只在那台设备上记住这个选择。它不会传到电脑上，也不会覆盖你保存好的布局。

它不做什么

没有 Xenon 账号，中间没有我们的服务器，仪表盘上的任何内容都不会被上传到任何地方。在自家 Wi-Fi 下这条连接是不加密的，所以面板里会提醒你在信任的网络里使用，而那条安全的路存在的意义就是解决这一点。Tailscale 是你自己选择加进来的第三方公司，适用它自己的隐私条款，而 Xenon 从它那里只取你自己这台机器的地址和证书。

Xenon 还会发送什么、不会发送什么，都写在隐私页面上。
