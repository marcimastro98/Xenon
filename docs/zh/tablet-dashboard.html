把旧平板或手机用作电脑的仪表盘

一台不再使用的平板或手机可以放在键盘旁边，显示温度、媒体、麦克风静音、音频切换和按键网格，内容由电脑通过你自己的 Wi-Fi 提供。平板上无需安装任何东西。

最后更新：2026年9月27日

你能得到什么

一台还能用却闲置着的平板或手机，立在键盘旁边，就能成为你的电脑缺少的那块屏幕：玩游戏时瞥一眼 CPU 和 GPU 温度，通话时点一下静音麦克风，跳过一首歌，把音频切到耳机，启动 OBS，或者查看原本需要按 Alt+Tab 切出去才能看的通知。

Xenon 就是这样的仪表盘。它是免费的，运行在 Windows 上（macOS 和 Linux 为测试版），平板上无需安装任何东西：仪表盘在它自带的浏览器中打开。

工作原理

Xenon 在电脑上作为一个小型本地服务运行，并在你自己的网络中提供仪表盘。平板或手机像打开网页一样打开它，所以 iPad、Android 平板、旧的 Fire 平板、iPhone 或任何带浏览器的手机都可以使用，设备上也没有需要保持更新的应用。配对通过电脑上显示的二维码完成；每台已配对的设备都会列出来，并且可以单独移除。在你的 Wi-Fi 下，平板直接与电脑通信，不经过云服务。不过 Xenon 本身的某些功能仍会联网，比如检查更新、目录和天气。

你看到的是真正的仪表盘，不是遥控器：和显示器上一样的磁贴、一样的主题、一样的页面，并按平板的形状重新排列。触控目标的大小适合手指操作。

设置方法

  1. 在电脑上下载 Xenon-Setup-x64.exe 并运行，应用提示时点击 Complete setup（完成设置）。这只需要做一次。
  2. 打开“设置”→ 远程控制 → 手机访问，开启允许其他设备访问，然后点击添加设备。电脑上会显示一个二维码。
  3. 用平板的相机对准这个二维码。仪表盘会在它的浏览器中打开。如果想全屏显示，可以把它添加到主屏幕。
  4. 如果电脑完全没有闲置的显示器，可以在首次启动时告诉 Xenon 不在电脑上显示任何内容：平板就成了唯一的屏幕。

手机指南里有同样的步骤和截图，还介绍了从家外访问仪表盘的可选方式。

局限

它不是第二台显示器。电脑不会把窗口放到平板上；你在平板上得到的是一个仪表盘，上面的控制会作用于电脑。如果你想要的是在小屏幕上真正多出一块桌面，Xenon 的第二屏幕磁贴可以在真实的显示器上做到（仅限 Windows），那是另一回事。在当前版本中，平板和手机访问也标记为测试版：它在家庭 Wi-Fi 上运行良好，但仍然比较新。

还有一点：Windows 安装程序已经签名，所以 Windows 会显示经过验证的发布者。SmartScreen 仍可能在一段时间内发出警告，因为 Microsoft 是随时间逐步给予信誉的：点击更多信息，再点仍要运行。常见问题解释了原因以及如何检查文件。

常见问题

平板需要安装应用吗？

不需要。任何浏览器都可以。把页面添加到主屏幕会得到一个全屏图标，但这是可选的。

旧的 iPad 或 Android 平板能用吗？

只要它的浏览器还能打开现代网页，就能用。浏览器已不再更新的非常旧的设备，渲染某些磁贴时可能会比较慢；仪表盘很轻量，但它毕竟是一个实时页面。

平板是通过互联网连接的吗？

在你自己的 Wi-Fi 下不是：电脑直接把页面提供给平板。从家外访问是另一项需要你主动开启的设置，手机指南中有说明。不过 Xenon 本身的某些功能仍会联网，比如检查更新、目录和天气。

可以用手机代替平板吗？

可以，方法一样。布局会针对竖屏手机重新排列。

它免费吗？

免费。没有付费版，无需账号，没有广告。源代码以非商业许可证托管在 GitHub 上。
