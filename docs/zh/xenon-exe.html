xenon.exe：它是什么，以及如何自己检查

如果你在电脑上发现了一个陌生的进程，并搜索了它的名字，那么最常见的正确答案放在最前面：它很可能不是来自 Xenon。

最后更新：2026年9月26日

简短回答 Xenon 实际运行的内容 如何检查你电脑上的文件 如果你从未安装过它 如果 Defender 报了它 如何卸载

简短回答

Xenon 不会安装名为 xenon.exe 的文件。如果任务管理器中显示的进程名正好是 xenon.exe，那几乎可以肯定是别的程序碰巧同名，下面的列表可以告诉你看到的是哪一种。

如果你看到的是 xenon-native.exe 或 xenon-helper.exe，那是我们的文件，本页其余部分会准确说明每个文件的作用。

Xenon 在 Windows 上实际运行的内容

它自己的文件有四个：

文件说明
Xenon-Setup-x64.exe安装程序。你只运行它一次；它不会作为进程留在系统中。
xenon-native.exe仪表盘窗口本身，一个小型原生外壳，在你选择的屏幕上绘制界面。系统托盘里看到的就是它。
xenon-helper.exe通往 Windows 中网页应用自己无法触及的那些部分的桥梁：音频设备和分应用音量、媒体键、通知、窗口列表、全局快捷键、磁盘扫描，以及蓝牙手机连接。它由引擎启动，并通过标准输入和输出应答引擎。
node.exe仪表盘引擎。Xenon 是一个本地网页应用，所以提供它的就是普通的 Node.js，监听 127.0.0.1:3030，这个地址只有本机能访问。如果你在“设置”中开启了手机访问，它还会在你的局域网中监听，好让你配对的手机和平板能连上它。

它们位于你的用户配置文件下的两个文件夹中，从不放在 Windows 系统目录里：%LOCALAPPDATA%\Xenon 和 %LOCALAPPDATA%\Programs\Xenon。一个按登录触发的计划任务会在你登录时以你自己的账户启动引擎。如果你在安装时接受了管理员提示，这个任务会以提升的权限运行，这样它才能读取温度；没有任何东西作为 Windows 服务安装。

此外还有 Xenon 为特定功能运行的工具，每个都来自各自的开发者，而不是本项目，并且只在需要它的功能开启时才运行：

  • LibreHardwareMonitor 和 PawnIO 通过 winget 安装，用于读取 CPU 和磁盘温度。PawnIO 是一个已签名的内核驱动，用来取代 WinRing0，后者是大多数旧式硬件监控软件被误报的根源。Xenon 从未附带过 WinRing0，将来也不会。
  • PresentMon 是 Intel 的帧时间工具，下载到 Xenon 自己的文件夹中，用于游戏内的真实帧率计数器。
  • FFmpeg 用于语音输入和语音回复；Ollama 只在你把助手切换到免费的本地服务时才需要。安装程序不会下载这两者；需要时你可以在“设置”中安装。
  • Sunshine 和 Tailscale，只在你开启远程控制电脑时才会用到。

如何检查你电脑上的实际文件

  1. 在任务管理器中右键点击该进程，选择打开文件所在的位置。如果它不在 %LOCALAPPDATA%\Xenon 或 %LOCALAPPDATA%\Programs\Xenon 下，就不是本项目的文件。
  2. 右键点击该文件，选择属性，打开数字签名选项卡。从 4.11.9 版起，Xenon-Setup-x64.exe、xenon-native.exe 和 xenon-helper.exe 都已签名，这个选项卡会显示发布者。旧版本的文件没有签名，所以对于这些文件，请用下一步的哈希值来核对。
  3. 把文件和我们发布的内容进行比较。每个版本都附带一个用项目密钥签名的 SHA256SUMS 文件，这对已签名的版本和旧版本同样适用： 
    Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256
    如果哈希值与该版本 SHA256SUMS 中对应的一行一致，这个文件就和 GitHub Actions 在那个标签上从公开源代码构建出来的文件逐字节相同。
  4. 把文件上传到 VirusTotal。少数几个引擎报警而其余都显示干净，通常说明是信誉问题，而不是恶意软件。如果几乎所有引擎都报警，那就是另一回事了。

如果你从未安装过 Xenon

那么你看到的东西不是来自本项目。请按上面的方法检查文件位置和发布者。本站的任何内容都不会删除我们没有安装的软件，这里也没有任何页面会让你下载一个“清理工具”来除掉它：这正是这类搜索之后常见的骗局形式。

如果是我们的文件，而 Defender 报了它

这种情况仍然可能发生。从 4.11.9 版起，安装程序已经签名，所以 Windows 会显示经过验证的发布者。SmartScreen 仍可能在一段时间内发出警告，因为 Microsoft 是随时间逐步给予信誉的：点击更多信息，再点仍要运行。Defender 还会根据程序的行为作出判断，而不只看是谁签的名，所以已签名的文件仍有可能被报。

常见问题解释了两种检测、警告的名称说明的是哪一种，以及如果你想继续使用，如何添加排除项。简单来说：以 !cl 结尾的名称是机器学习模型针对信誉作出的判断；普通的名称则是行为特征检测，针对的是一个带有下载代码脚本的安装程序，而这确实也符合你不希望遇到的那类东西的特征。两者单独来看都证明不了什么，所以才有上面的第 2 步和第 3 步。

如何彻底卸载

设置 → 应用 → 已安装的应用 → Xenon → 卸载；如果你是用传统方式安装的，也可以在解压出来的文件夹里运行 UNINSTALL.bat。它会删除两个文件夹、计划任务和托盘应用。通过 winget 安装的温度组件是独立的程序，需要在同一个应用列表中单独卸载。
