Xenon 다운로드

모든 플랫폼용 최신 릴리스를 GitHub에서 바로 받을 수 있습니다. 무료이고 계정도 필요 없으며, 설치한 뒤에는 스스로 업데이트됩니다.

마지막 업데이트: 2026년 9월 26일. 모든 링크는 최신 릴리스를 가리킵니다.

WindowsXenon-Setup-x64.exeWindows 10 또는 11, 64비트. 앱을 설치하고 로그인할 때 실행합니다. macOS베타Xenon-macOS-universal.dmgmacOS 11 이상. Apple 실리콘과 Intel을 파일 하나로 지원합니다. Linux베타Xenon-Linux-x86_64.AppImage모든 x86_64 데스크톱. .deb와 .rpm은 Linux 페이지에 있습니다.

Linux용 Xenon: .deb와 .rpm 패키지, 첫 실행 때 설정되는 것, 그리고 되는 것과 아직 안 되는 것을 정리한 표.

위의 파일은 모두 최신 릴리스이며 GitHub에서 바로 받습니다. 체크섬을 포함한 이번 릴리스의 모든 파일은 릴리스 페이지에 있습니다.

첫 설정

Windows: 설치 프로그램을 실행합니다. 앱이 설치되고 저절로 열린 뒤, 대시보드 엔진이 아직 없는 것을 확인하면 Complete setup(설정 완료) 버튼을 보여 줍니다. 한 번 누르면 창이 열리고 Node.js, 센서 판독기, 로그인할 때 Xenon을 시작하는 작업을 설치하면서 각 단계를 보여 줍니다. 무엇이든 실행하기 전에 다운로드한 파일을 프로젝트의 서명 키로 검증합니다. 몇 분이면 끝나고 한 번만 하면 됩니다.

macOS와 Linux: 다운로드한 앱을 엽니다. 처음 실행할 때 터미널 창에서 대시보드를 설정하겠다고 제안하며, 압축을 풀기 전에 다운로드를 검증합니다. Linux에서 패키지가 이 작업을 대신 하지 않는 것은 의도한 것입니다. 만들어지는 것은 모두 한 사용자 계정에 속하는데, 패키지는 root 권한으로 컴퓨터 전체에 설치되기 때문입니다.

그다음 Xenon이 어느 화면에서 쓸지 묻습니다. 남는 모니터, 태블릿, 휴대폰, CORSAIR Xeneon Edge 모두 됩니다. 휴대폰이나 태블릿을 30초 정도 만에 페어링하는 방법은 휴대폰 가이드에서 설명합니다.

Windows와 macOS의 경고

버전 4.11.9부터 Windows 설치 프로그램은 서명되어 있어 Windows에 확인된 게시자가 표시됩니다. 그래도 Microsoft가 평판을 시간을 두고 부여하기 때문에 한동안 SmartScreen이 경고할 수 있습니다. 추가 정보를 누른 다음 실행을 누르세요. Defender는 누가 서명했는지뿐 아니라 프로그램이 무엇을 하는지도 판단하므로 탐지될 가능성은 여전히 있습니다. FAQ에서 경고 종류별로 설명하고 파일을 되찾는 방법도 안내합니다. 무엇이 설치되는지 정확히 알고 싶다면 Xenon이 실행하는 모든 프로세스를 정리한 페이지를 보세요.

macOS: Mac 버전은 베타이고 공증(notarize)을 받지 않았기 때문에 macOS가 첫 실행을 막습니다. 시스템 설정 → 개인정보 보호 및 보안을 열고 아래로 내려서 Xenon 옆의 그래도 열기를 클릭하세요. macOS 15 이상에서는 Control 키를 누른 채 클릭해서 여는 방법이 더 이상 통하지 않습니다.

다운로드 검증

모든 릴리스에는 프로젝트의 Ed25519 키로 서명한 SHA256SUMS 파일이 함께 올라갑니다. 다운로드한 파일의 해시를 비교하세요.

Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256        # Windows, PowerShell
shasum -a 256 Xenon-macOS-universal.dmg                       # macOS
sha256sum Xenon-Linux-x86_64.AppImage                          # Linux

릴리스의 SHA256SUMS에 있는 해당 파일의 줄과 일치하면, 그 파일은 GitHub Actions가 그 태그의 공개 소스에서 빌드한 파일과 바이트 단위까지 같습니다. Windows에서는 설치 프로그램을 오른쪽 클릭하고 속성을 선택한 뒤 디지털 서명 탭을 열어 게시자를 확인할 수도 있습니다.

다른 설치 방법

소스에서 설치: 릴리스에서 소스 코드 zip을 받아 압축을 풀고, Windows에서는 INSTALL.bat, macOS에서는 INSTALL.command, Linux에서는 ./INSTALL.sh를 실행합니다. 결과는 설치 프로그램과 같으며, 무엇이 실행되는지 직접 읽어 보고 싶은 분을 위한 방법입니다.

winget: 패키지 매니페스트는 작성되어 있고, Microsoft 쪽 검사를 깨끗하게 통과하는 릴리스를 기다리는 중입니다. 목록에 올라가기 전까지는 위의 설치 프로그램을 사용하세요. 올라가는 날 이 페이지에 winget install xenon이라고 적겠습니다.

업데이트: Xenon은 시작할 때 새 릴리스를 확인하고 스스로 업데이트합니다. 업데이트 때문에 이 페이지로 다시 올 필요는 없습니다.

Xenon이란

PC에서 실행되고 남는 화면 어디에나 띄울 수 있는 무료 대시보드입니다. 시스템 상태, 미디어와 마이크 제어, Stream Deck 스타일의 키 그리드, 조명, 말로 대화할 수 있는 AI를 제공합니다. 계정이 필요 없고, 설정, 파일, 센서 값은 PC에 저장됩니다. 홈페이지에서 직접 볼 수 있습니다.
