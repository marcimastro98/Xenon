Xenon 소개 사용하기 문제가 생겼을 때 개인정보와 도움말

Xenon 소개

Xenon은 무엇인가요?

PC 옆 화면을 위한 무료 대시보드입니다. 시스템(CPU, GPU, 온도, 네트워크), 재생 중인 음악, 캘린더, 날씨, 메모를 보여 주고, Deck도 있습니다. Deck은 눌러서 앱을 열고, 음악을 제어하고, PC에서 단축키를 실행하는 키입니다. 위젯과 테마로 원하는 대로 구성합니다. Windows에서 실행되며 macOS와 Linux는 베타입니다.

Xeneon Edge나 CORSAIR PC가 필요한가요?

아니요. Xenon은 CORSAIR Xeneon Edge를 기준으로 설계됐지만 어떤 PC에서도 실행되며 CORSAIR 하드웨어나 소프트웨어가 필요 없습니다. iCUE는 대시보드를 iCUE 위젯 안에 두고 싶을 때나 CORSAIR RGB 장치를 제어할 때만 필요합니다.

어떤 화면을 쓸 수 있나요?

PC가 창을 띄울 수 있는 화면이면 어디든 됩니다. 남는 모니터, 터치스크린, 메인 화면의 창도 됩니다. 앱은 처음 실행할 때 어느 화면에서 열지 묻습니다. 집 Wi-Fi를 통해 태블릿이나 휴대폰도 쓸 수 있습니다. 같은 레이아웃, 위젯, 테마의 실제 대시보드가 보이고, 키는 실제로 PC에서 동작합니다. 방법은 휴대폰 가이드와 태블릿 가이드에 있습니다.

Mac과 Linux에서도 되나요?

네, 베타로 지원합니다. Windows 10, 11과 함께 macOS 11 이상(Apple Silicon과 Intel 공용 다운로드 하나)과 64비트 Linux에서 실행됩니다. 대시보드, 위젯, 스토어는 세 곳 모두 같습니다. macOS와 Linux에서는 아직 일부 센서와 시스템 동작이 없으며, 데이터가 없는 타일은 계속 로딩하지 않고 그렇다고 알려 줍니다. 무엇이 되는지는 Mac 및 Linux 페이지에 있습니다.

Mac 첫 실행: 앱이 아직 공증을 받지 않아 macOS가 처음에 실행을 막습니다. macOS 15 이상에서는 시스템 설정 → 개인정보 보호 및 보안을 열고 맨 아래로 내려 그래도 열기를 클릭하세요. macOS 11~14에서는 앱을 오른쪽 클릭해 열기를 고른 뒤 다시 열기를 누르세요. 버전마다 한 번만 하면 됩니다.

무료인가요? 서포터는 무엇을 받나요?

앱은 무료이며 광고도 계정도 없습니다. Buy Me a Coffee 서포터는 카탈로그의 월간 드롭, Lyrics와 Developer cleanup 위젯, Discord 역할, Hall of Supporters 등재를 받습니다. 월 5 USD 또는 연 50 USD이며, 5 USD부터 일회성으로도 가능하고 5 USD마다 한 달로 계산됩니다. 코드는 이메일로 오며 설정 → Xenon 후원에 입력합니다. 모든 플랜에 매달 300 스파크(Xenon 크레딧)도 포함됩니다.

서포터 패스는 PC당 한 번, 7일 동안 무료로 체험할 수 있습니다. 서포터 드롭과 Lyrics가 열립니다. 한정 드롭과 공개 후 몇 주 동안의 일부 새 드롭은 서포터 전용입니다. Lyrics와 Developer cleanup은 후원이 끝나도 계속 열려 있습니다. 1년 후원 시에는 팔레트나 사진을 바탕으로 나만의 테마를 만들어 이름과 함께 공개해 드립니다.

스파크란 무엇인가요?

스파크는 Xenon의 크레딧이며, 1 스파크는 1 미국 센트입니다. 내 API 키 없이 어시스턴트를 쓸 때와, 스파크로 판매되는 Store 아이템에 쓸 수 있습니다. 후원 한 달마다 300 스파크가 포함되며 매달 초에 다시 채워집니다. 더 사는 데 서포터일 필요는 없습니다. Buy Me a Coffee 엑스트라에서 500 스파크는 5 USD, 1050은 10 USD, 2200은 20 USD이며, 구매한 스파크는 만료되지 않습니다. 서포터가 아니라면 첫 묶음과 함께 스파크 코드(XC-…)가 이메일로 옵니다. 서포터 코드와 같은 칸에 입력하면 됩니다.

스파크로 산 아이템은 업데이트를 포함해 영원히 내 것이며, 최대 3대의 PC에서 쓸 수 있고 다시 설치해도 비용이 들지 않습니다. 한정판은 스파크로 판매되지 않습니다.

사용하기

게임이 느려지나요?

느려지지 않도록 만들어졌습니다. 게임이 실행 중이면 게임 모드가 애니메이션 배경을 흐리게 하고 애니메이션 효과를 멈추며, 가장 무거운 타일인 브라우저와 보조 화면 스트림도 게임이 끝날 때까지 멈춥니다. 이런 실시간 타일과 Home Assistant는 화면에 보일 때만 연결됩니다.

Windows에서는 게임 중에 앱의 대시보드를 터치해도 괜찮습니다. 커서는 바로 게임 모니터로 돌아가고, 터치가 게임의 포커스를 가져가지 않습니다.

위젯과 테마는 어떻게 추가하나요?

대시보드에서 +를 누르면 기본 타일을 추가할 수 있습니다. 더 원하면 설정 → 스토어를 여세요. 커뮤니티가 만든 테마, 배경, 위젯, 앰비언트 장면, 팩이 있고, 적용하기 전에 항상 미리보기가 나오며 한 번 눌러 설치합니다. 같은 항목을 이 사이트의 카탈로그에서도 볼 수 있습니다.

온도와 게임 FPS를 보여 주나요?

네. Windows에서는 설치 프로그램이 온도 읽기를 설정하고(관리자 확인을 한 번 허용해야 합니다), PresentMon이 실행 중인 게임의 실제 프레임 수를 보여 줍니다. 전체 화면 게임도 됩니다. 없으면 설정 → 게임 모드에서 설치합니다. macOS에서는 온도와 GPU 부하를 macmon(brew install vladkens/tap/macmon)에서 가져옵니다. Linux에서 게임 FPS를 보려면 MangoHud가 필요하며 게임을 MangoHud로 실행해야 합니다.

Spotify, Home Assistant, RGB 조명과 연동되나요?

네, 모두 선택 사항이며 연결하기 전에는 꺼져 있습니다.

  • Spotify: 재생 중인 음악이 미디어 타일에 표시됩니다. 설정에서 계정을 연결하면 탐색, 좋아요, 셔플, 플레이리스트를 Deck에서도 쓸 수 있습니다(재생 제어에는 Spotify Premium이 필요합니다).
  • Home Assistant: 설정 → 스마트 홈에서 주소와 장기 액세스 토큰으로 연결한 뒤, 조명, 센서, 장면을 타일이나 Deck 키로 제어합니다.
  • RGB: CORSAIR 장치는 iCUE로, WLED, OpenRGB, Philips Hue, Nanoleaf, Govee, LIFX, Yeelight는 네트워크로, Windows에서는 GIGABYTE와 AORUS 메인보드를 USB로 제어합니다.
레이아웃을 저장하거나 다른 PC로 옮길 수 있나요?

네. 설정 → 백업 → 백업 내보내기로 레이아웃, Deck, 캘린더, 할 일, 타이머, 메모, 설정, 사용자 배경을 파일 하나에 저장합니다. 다른 PC에서 백업 가져오기를 하면 모두 되돌아옵니다. API 키와 비밀번호는 파일에 절대 들어가지 않으므로 연동은 다시 연결하라고 묻고, 커뮤니티 위젯은 목록으로 보여 줘서 코드로 다시 설치할 수 있습니다.

문제가 생겼을 때

Windows가 Xenon을 바이러스라고 해요. 안전한가요?

오탐입니다. Windows 설치 프로그램은 4.11.9 버전부터 서명되어 있지만, Microsoft는 새 파일에 대한 신뢰를 시간을 두고 쌓기 때문에 갓 나온 릴리스에는 Defender, SmartScreen, 브라우저가 경고할 수 있습니다. 파일은 직접 확인할 수 있습니다. 모든 릴리스에는 서명된 SHA256SUMS 목록이 있고, 비교하는 명령은 다운로드 페이지에 있습니다. Microsoft Store에서 설치할 수도 있습니다.

  • Defender가 삭제했을 때: Windows 보안 → 바이러스 및 위협 방지 → 보호 기록을 열고 Xenon 항목을 골라 복원을 누르세요. 그다음 %LOCALAPPDATA%\Xenon와 %LOCALAPPDATA%\Programs\Xenon를 제외에 추가하세요.
  • 브라우저가 다운로드를 막을 때: Ctrl+J로 다운로드 목록을 열고 유지를 고르세요.
  • 실행되지 않고 아무 알림도 없을 때: Windows 11에서는 보통 Windows 보안 → 앱 및 브라우저 컨트롤의 스마트 앱 컨트롤 때문입니다. 먼저 켠 상태로 최신 릴리스를 써 보세요. 한 번 끄면 PC를 초기화하지 않고는 다시 켤 수 없습니다.

경고는 공식 Releases 페이지에서 받고 해시를 확인한 파일에만 무시하세요.

Xenon이 저절로 꺼져요

트레이 메뉴를 열고 Open crash log를 고르세요. 마지막 줄이 PANIC이면 앱 자체의 오류입니다. 그 줄을 Discord나 버그 신고에 붙여 주세요. 정확한 위치가 나와 있습니다. 마지막 줄이 launched이고 그 뒤에 아무것도 없다면 외부의 무언가가 닫은 것이고, 거의 항상 백신 프로그램입니다. 보호 기록에서 그 시각의 항목을 찾아 복원하고, 위 질문의 제외 두 개를 추가하세요.

CPU 온도가 안 보여요

Windows에서는 설치 프로그램을 다시 실행하고 관리자 확인을 허용하세요. 온도를 읽으려면 드라이버 수준의 구성 요소가 있는 LibreHardwareMonitor와 PawnIO가 필요하며, 그래서 확인 창이 뜹니다. 거부해도 온도 외의 기능은 모두 작동합니다. macOS에서는 macmon을 설치하세요. 센서를 전혀 제공하지 않는 노트북과 메인보드도 있으며, 그런 경우 타일은 지어낸 숫자 대신 그렇다고 알려 줍니다.

업데이트나 제거는 어떻게 하나요?

Xenon은 스스로 업데이트합니다. 새 릴리스가 나오면 대시보드가 알려 주고, 한 번 누르면 내려받아 설치 전에 서명을 확인하며, 문제가 생기면 이전 버전으로 되돌립니다. 설정, 레이아웃, 메모는 그대로 남습니다.

제거하려면 Windows에서는 UNINSTALL.bat, macOS에서는 UNINSTALL.command, Linux에서는 ./UNINSTALL.sh를 실행하세요. 앱, 자동 시작, 데이터가 삭제됩니다. 설정, 레이아웃, 메모를 남기려면 Windows에서는 -KeepData, 그 밖에서는 --keep-data를 붙이세요.

개인정보와 도움말

내 데이터를 어딘가로 보내나요? 계정이 필요한가요?

설정, 메모, 할 일, 일정, Deck, 파일 색인은 PC에 그대로 남습니다. 앱에는 분석 SDK도, 충돌 자동 전송도, 행동 추적도 없습니다. 업데이트 확인과 날씨나 Spotify처럼 직접 켠 서비스를 위해서는 인터넷에 연결합니다. 어떤 요청을 보내고 무엇을 전송하는지는 개인정보 페이지에 모두 나와 있습니다.

Xenon 계정은 없습니다. 입력하는 것은 서포터 코드뿐이며, 각 연동은 해당 서비스의 로그인을 사용합니다.

도움은 어디서 받나요?

Discord에서 물어보는 것이 가장 빠르고, 자주 나오는 질문은 이 페이지에 추가됩니다. 재현할 수 있는 버그는 시스템, 한 작업, 일어난 일을 적어 GitHub 이슈를 열어 주세요.

개인 사용은 무료이며 업무용 PC에서도 됩니다. Xenon을 판매하거나 상업용 제품에 넣으려면 먼저 서면 허가가 필요합니다. 이메일로 문의하세요.
