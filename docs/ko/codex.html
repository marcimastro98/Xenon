두 번째 화면에서 쓰는 OpenAI Codex

Xenon의 Codex 타일은 요금제 사용량 구간, 일별 토큰, PC에서 작업 중인 세션과 그 요청을 허용, 거부, Codex에서 답하기와 함께 보여 줍니다. PC 옆 화면에 둡니다. Xeneon Edge, 모니터, 태블릿 또는 페어링한 휴대폰입니다.

최종 업데이트: 2026년 10월 6일

+ 버튼의 시스템에서 타일을 추가하세요. PC에 Codex가 설치되어 로그인되어 있으면 요금제는 바로 표시됩니다. 세션과 승인은 Codex를 연결해야 하며, 타일에서 바로 할 수 있습니다. Windows에서 동작하며 macOS와 Linux는 베타입니다.

요금제 사용량 세션 승인 연결하기 무엇이 어디로 가는지 자주 묻는 질문

요금제 사용량

Codex는 요금제의 사용량 구간을 알려 줍니다. 각 구간을 얼마나 썼는지와 언제 초기화되는지입니다. Xenon은 각 구간을 막대로 보여 주고, 초기화까지 남은 시간과 균등한 속도라면 지금 어디쯤이어야 하는지 표시합니다. 70%에서 호박색, 90%에서 빨간색으로 바뀝니다.

각 구간의 길이는 Codex가 알려 주므로 타일은 실제 길이대로 표시합니다. 유료 요금제는 보통 5시간과 1주, Free 요금제는 30일 구간 하나입니다.

타일의 사용량 면에는 오늘, 7일, 30일, 전체 토큰과 최근 30일의 일별 막대가 표시됩니다. Codex가 계정 전체에 대해 알려 주는 숫자로, 이 PC뿐 아니라 모든 기기와 앱을 포함합니다.

세션과 최근 대화

Codex를 연결하면 세션이 시작될 때마다 한 줄이 생깁니다. 요청한 내용, 모델, 작업 중인지 나를 기다리는지입니다. 그 아래에는 Codex가 보관하는 대화와 그 대화가 진행된 곳(ChatGPT 앱, 에디터, 터미널)이 나열됩니다.

세션은 Codex의 훅에서 옵니다. Codex는 codex 명령에서 훅을 실행하며, ChatGPT 앱과 에디터 확장에서도 실행되는지는 Codex 버전에 따라 다릅니다. 요금제와 대화 목록은 훅과 상관없이 세 곳 모두를 포함합니다.

요청에 답하기

Codex 세션이 명령 실행이나 파일 변경을 요청하면, 명령 또는 변경되는 파일(삭제는 표시됨)과 함께 허용, 거부, Codex에서 답하기 세 버튼이 타일에 나타납니다. 마지막 버튼은 질문을 바로 Codex로 돌려보냅니다. 카드에는 네트워크, 작업 게시, 프로젝트 밖의 파일, 세션보다 넓은 권한, 되돌릴 수 없는 일 등 무엇이 평소와 다른지 적혀 있습니다.

rm -rf나 파일을 삭제하는 패치처럼 되돌릴 수 없는 요청은 탭이 아니라 버튼을 길게 눌러야 허용됩니다. 25초 동안 답이 없는 요청은 화면 전체를 차지해 다른 페이지에서 놓치지 않게 합니다.

대신 승인되는 것은 없습니다. 요청이 타일에서 기다리는 동안 Codex는 자체 확인을 표시하지 않으므로, 90초가 지나거나 Xenon이 닫혀 있으면 요청은 Codex로 돌아가 평소처럼 묻습니다. 설정 → Codex에서 대기 시간을 바꾸거나 요청을 끌 수 있습니다.

휴대폰에서 답하려면 Xenon과 페어링하세요(베타). 휴대폰에 같은 대시보드와 같은 버튼이 표시됩니다. 휴대폰 페어링 방법.

Codex 연결하기

  1. + 버튼의 시스템에서 Codex 타일을 추가합니다.
  2. 타일에서 Codex를 탭한 다음 연결을 누릅니다.
  3. Codex를 열고 /hooks를 입력해 Xenon 훅을 신뢰합니다. Codex는 새 훅을 신뢰한 뒤에만 실행합니다. 이는 Codex 자체의 안전 확인이므로 Xenon이 대신하지 않습니다.
  4. 새 세션을 시작합니다. 훅은 이 단계 이후 시작한 세션에 적용되며, 타일에 Codex가 훅을 신뢰했는지 표시됩니다.

연결은 파일 하나만 수정합니다. ~/.codex 또는 CODEX_HOME이 가리키는 폴더의 Codex hooks.json입니다. Node로 Xenon의 작은 스크립트를 실행하는 훅 다섯 개를 추가하며, 이 스크립트는 127.0.0.1(내 PC)의 Xenon에 보고합니다. 기존 훅은 같은 순서로 그대로 두며, Xenon은 config.toml을 건드리지 않습니다.

처음 변경하기 전에 Xenon은 파일 사본을 hooks.json.xenon-backup으로 옆에 저장합니다. 파일을 읽을 수 없으면 Xenon은 그대로 두고 알려 줍니다.

Xenon을 제거하면 추가한 훅이 빠지고 백업도 삭제됩니다. 기존 훅은 그대로 둡니다. 제거하지 않고 같은 작업을 하려면 타일에서 연결 해제를 탭하거나 Xenon이 설치된 폴더에서 node server/codex-link.js unlink를 실행하세요.

무엇이 어디로 가는지

타일은 API 키를 쓰지 않으며 로그인 정보를 읽지 않습니다. 요금제는 ChatGPT 앱과 에디터 확장이 Codex와 통신할 때 쓰는 codex app-server에서 가져옵니다. Xenon은 타일이 대시보드에 있을 때만 자체 사본을 실행하고, 읽기만 요청하며, 필요 없어지고 몇 분 뒤 종료합니다.

훅은 Xenon이 만든 키와 함께 127.0.0.1(내 PC)에 보고합니다. 키가 없는 보고는 거부되며, 키는 Xenon의 데이터 폴더에서 읽으므로 명령줄에 나타나지 않습니다. 세션 상태는 메모리에만 있으며 Xenon을 다시 시작하면 비워집니다.

설치한 위젯은 허용하면 codex 스트림으로 요금제 숫자를 읽을 수 있습니다. 비율, 구간 길이, 토큰 수, 작업 중인 세션 수입니다. 폴더, 프로젝트, 대화, 명령, 이메일은 절대 포함되지 않습니다.

자주 묻는 질문

Codex 사용 한도를 두 번째 화면에서 볼 수 있나요?

네. Codex가 설치되어 로그인되어 있으면 타일에 요금제의 각 사용량 구간과 사용률, 초기화까지 남은 시간이 표시됩니다. 이를 위해 Codex를 연결할 필요는 없습니다.

ChatGPT 데스크톱 앱에서도 되나요?

요금제, 사용량, 대화 목록은 같은 계정과 엔진을 공유하므로 ChatGPT 앱, 에디터 확장, codex 명령의 Codex를 모두 포함합니다. 실시간 세션과 승인은 Codex가 훅을 실행해야 하며, codex 명령은 이를 실행합니다.

요청에 답하지 않으면 어떻게 되나요?

아무것도 승인되지 않습니다. 90초가 지나거나 Xenon이 닫혀 있으면 요청은 Codex로 돌아가 평소처럼 묻습니다.

왜 Codex에서 훅을 신뢰해야 하나요?

Codex는 바로 그 훅을 신뢰한 뒤에만 실행합니다. Codex 자체의 안전 확인이므로 Xenon이 대신하지 않습니다. Xenon이나 Node의 폴더가 바뀌면 훅도 바뀌어 Codex가 다시 신뢰를 요청하며, 타일이 알려 줍니다.

API 키로도 되나요?

세션과 승인은 됩니다. 요금제 구간은 ChatGPT 요금제에만 있으므로 API 키로는 표시할 것이 없습니다.

Xenon 다운로드

무료이며 계정이 필요 없습니다. Windows용 Xenon 다운로드 또는 다운로드 페이지에서 시스템을 고르세요. Claude Code도 쓰시나요? 터치스크린에서 쓰는 Claude Code를 보세요.
