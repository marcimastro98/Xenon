오래된 태블릿이나 휴대폰을 PC 대시보드로 쓰기

더 이상 쓰지 않는 태블릿이나 휴대폰을 키보드 옆에 두고 온도, 미디어, 마이크 음소거, 오디오 전환, 키 그리드를 띄울 수 있습니다. 화면은 PC가 내 Wi-Fi를 통해 보내 줍니다. 태블릿에는 아무것도 설치하지 않습니다.

마지막 업데이트: 2026년 9월 27일

할 수 있는 것 작동 방식 설정하기 한계 질문

할 수 있는 것

아직 작동하지만 쓰지 않고 있는 태블릿이나 휴대폰을 키보드 옆에 세워 두면, PC에 없던 화면이 됩니다. 게임을 하면서 CPU와 GPU 온도를 흘끗 확인하고, 통화 중에 탭해서 마이크를 음소거하고, 다음 곡으로 넘기고, 오디오를 헤드폰으로 바꾸고, OBS를 실행하고, 원래라면 Alt+Tab으로 넘어가서 봐야 하는 알림을 읽는 화면입니다.

Xenon이 바로 그 대시보드입니다. 무료이고, Windows에서 실행되며(macOS와 Linux는 베타), 태블릿에는 설치할 것이 없습니다. 대시보드는 태블릿에 이미 있는 브라우저에서 열립니다.

작동 방식

Xenon은 PC에서 작은 로컬 서비스로 실행되며, 내 네트워크에서 대시보드를 제공합니다. 태블릿이나 휴대폰은 이것을 웹 페이지처럼 엽니다. 그래서 iPad, Android 태블릿, 오래된 Fire 태블릿, iPhone, 브라우저가 있는 휴대폰이라면 무엇이든 쓸 수 있고, 기기에서 업데이트해야 할 앱도 없습니다. 페어링은 PC가 보여 주는 QR 코드로 합니다. 페어링한 기기는 목록에 나오며 하나씩 따로 삭제할 수 있습니다. 내 Wi-Fi에서는 태블릿이 클라우드 서비스를 거치지 않고 PC와 직접 통신합니다. 다만 Xenon 자체는 업데이트 확인, 카탈로그, 날씨 같은 일부 기능을 위해 여전히 온라인에 연결합니다.

보이는 것은 리모컨이 아니라 진짜 대시보드입니다. 모니터에서와 같은 타일, 같은 테마, 같은 페이지가 태블릿의 형태에 맞게 다시 배치됩니다. 터치 영역은 손가락에 맞는 크기입니다.

설정하기

  1. PC에서 Xenon-Setup-x64.exe를 내려받아 실행하고, 앱이 물어보면 Complete setup(설정 완료) 버튼을 누르세요. 한 번만 하면 됩니다.
  2. 설정 → 원격 제어 → 휴대폰에서 접속을 열고, 다른 기기의 접속 허용을 켠 다음 기기 추가를 누르세요. PC에 QR 코드가 나타납니다.
  3. 태블릿 카메라로 코드를 비추세요. 태블릿의 브라우저에서 대시보드가 열립니다. 전체 화면으로 쓰고 싶다면 홈 화면에 추가하세요.
  4. PC에 남는 모니터가 전혀 없다면, 처음 실행할 때 PC에는 아무것도 표시하지 않도록 Xenon에 알려 주세요. 그러면 태블릿이 유일한 화면이 됩니다.

휴대폰 가이드에 같은 단계가 스크린샷과 함께 있고, 집 밖에서 대시보드에 접속하는 선택 사항도 설명되어 있습니다.

한계

두 번째 모니터는 아닙니다. PC가 태블릿에 창을 띄우지는 않습니다. 태블릿에 나오는 것은 PC에서 동작하는 컨트롤이 있는 대시보드입니다. 작은 화면에 진짜 추가 데스크톱을 원한다면 Xenon의 두 번째 화면 타일이 실제 모니터에서 그 일을 하며(Windows 전용), 이것은 별개의 기능입니다. 태블릿과 휴대폰 접속은 현재 릴리스에서 베타로 표시되어 있습니다. 집 Wi-Fi에서는 잘 동작하지만 아직 새로운 기능입니다.

하나 더 알아 두세요. Windows 설치 프로그램은 서명되어 있어 Windows에 확인된 게시자가 표시됩니다. 그래도 Microsoft가 평판을 시간을 두고 부여하기 때문에 한동안 SmartScreen이 경고할 수 있습니다. 추가 정보를 누른 다음 실행을 누르세요. 이유와 파일 확인 방법은 FAQ에서 설명합니다.

질문

태블릿에 앱이 필요한가요?

아닙니다. 브라우저만 있으면 됩니다. 페이지를 홈 화면에 추가하면 전체 화면으로 열리는 아이콘이 생기지만, 필수는 아닙니다.

오래된 iPad나 Android 태블릿에서도 되나요?

브라우저가 아직 최신 웹 페이지를 연다면 됩니다. 브라우저 업데이트가 끊긴 아주 오래된 기기에서는 일부 타일이 느리게 그려질 수 있습니다. 대시보드는 가볍지만 실시간으로 바뀌는 페이지이기 때문입니다.

태블릿이 인터넷을 거쳐 연결되나요?

내 Wi-Fi에서는 아닙니다. PC가 태블릿에 페이지를 직접 보냅니다. 집 밖에서 접속하는 것은 따로 켜야 하는 별도의 설정이며, 휴대폰 가이드에서 설명합니다. 다만 Xenon 자체는 업데이트 확인, 카탈로그, 날씨 같은 일부 기능을 위해 여전히 온라인에 연결합니다.

태블릿 대신 휴대폰을 써도 되나요?

네, 방법은 같습니다. 레이아웃이 세로 방향 휴대폰 화면에 맞게 다시 배치됩니다.

무료인가요?

네. 유료 버전도, 계정도, 광고도 없습니다. 소스는 비상업적 라이선스로 GitHub에 있습니다.

Xenon 다운로드

설치 프로그램은 하나이고 계정은 필요 없으며, 설정은 PC에 저장됩니다. Windows용 Xenon을 다운로드하거나 macOS와 Linux 베타 빌드를 받으세요. 질문은 Discord에서 받습니다.
