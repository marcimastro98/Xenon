Linux용 Xenon

Xenon은 남는 화면 어디에나 띄울 수 있는 무료 대시보드입니다. Linux에서는 베타입니다. 대시보드는 Windows와 같으며, 이 페이지에는 아직 다른 점과 필요한 패키지를 정리했습니다.

마지막 업데이트: 2026년 9월 26일 · 모든 링크는 최신 릴리스를 가리킵니다

다운로드 첫 실행 되는 것 X11과 Wayland

다운로드

AppImageXenon-Linux-x86_64.AppImage모든 x86_64 데스크톱. chmod +x로 실행 권한을 준 뒤 실행하세요. Debian, UbuntuXenon-Linux-x86_64.deb앱을 설치합니다. 대시보드는 첫 실행 때 사용자별로 설정됩니다. Fedora, openSUSEXenon-Linux-x86_64.rpm.deb와 같으며, RPM 배포판용입니다.

Linux 지원은 베타입니다. 대시보드, 위젯, 카탈로그, 연동은 Windows와 똑같습니다. 아직 다른 것은 기기를 읽고 제어하는 부분이며, 아래 표에 정리했습니다. GNOME과 KDE에서 테스트했습니다.

첫 실행

앱을 여세요. 처음 실행하면 터미널 창에서 대시보드를 설정하겠다고 제안합니다. 엔진을 내려받고, 압축을 풀기 전에 다운로드를 검증하고, 로그인할 때 Xenon이 시작되도록 systemd --user 서비스를 등록합니다. 사용자 매니저가 없는 환경에서는 대신 XDG 자동 시작 항목을 쓰고 그렇다고 알려 줍니다. 이 대체 방식에서는 Xenon이 비정상 종료되어도 다시 시작되지 않는다는 점도 함께 알려 줍니다.

.deb와 .rpm이 설치할 때 이 작업을 하지 않는 것은 의도한 것입니다. 설정이 만드는 모든 것은 한 사용자 계정에 속하는데, 패키지는 root 권한으로 컴퓨터 전체에 설치되기 때문입니다.

설치 프로그램은 설치되어 있지 않은 선택 도구도 알려 줍니다. Debian과 Ubuntu에서는 다음과 같습니다.

sudo apt install nodejs npm unzip           # required
sudo apt install wireplumber                # volume, microphone and the per-app mixer
sudo apt install wmctrl xdotool x11-utils   # the open-applications widget (X11 sessions)
sudo apt install ffmpeg                     # voice input and spoken replies

데스크톱에 터미널 에뮬레이터가 전혀 없다면 앱이 설치 과정을 보여 줄 수 없습니다. 릴리스에서 소스 zip을 내려받아 압축을 풀고 ./INSTALL.sh를 실행하세요.

README의 플랫폼 표가 이 목록의 기준이 되는 버전이며, 조건이 있는 항목마다 각주가 달려 있습니다.

X11과 Wayland

대시보드 대부분은 둘 다에서 똑같이 동작합니다. 다른 부분은 다른 창을 볼 수 있어야 하는 기능들입니다. 열린 앱 위젯, 앱 전환기, AI의 화면 인식은 X11 도구(wmctrl, xdotool)를 쓰기 때문에, Wayland 세션에서는 Xenon이 이 기능들을 보여 줬다가 실패하는 대신 숨깁니다. 필요하다면 X11 세션으로 로그인하세요.

문제 신고

Linux가 베타인 것은 위 표에 아직 빈틈이 있기 때문입니다. 문제를 신고하려면 배포판, 데스크톱, 세션 종류를 적어 버그 리포트를 열어 주세요. 먼저 물어보고 싶다면 Discord에 글을 남겨 주세요.
