Utilisez une ancienne tablette ou un ancien téléphone comme dashboard pour votre PC

Une tablette ou un téléphone que vous n'utilisez plus peut être placé à côté du clavier pour afficher les températures, les médias, l'état du micro coupé, le basculement audio et une grille de touches, le tout servi par le PC via votre propre Wi-Fi. Rien à installer sur la tablette.

Dernière mise à jour : 27 septembre 2026

Ce que vous obtenez Comment ça marche Mise en place Limites Questions

Ce que vous obtenez

Une tablette ou un téléphone qui fonctionne encore mais reste inutilisé peut, posé à côté du clavier, devenir l'écran dont votre PC manque : celui sur lequel vous jetez un œil pour la CPU et la température GPU pendant qu'un jeu tourne, pour couper le micro d'un appel, passer une piste, basculer l'audio sur les écouteurs, lancer OBS, ou lire les notifications pour lesquelles vous devriez normalement utiliser Alt+Tab.

Xenon est ce dashboard. Il est gratuit, il fonctionne sur Windows (macOS et Linux en beta), et la tablette n'a besoin d'aucun logiciel installé : le dashboard s'ouvre dans le navigateur qu'elle possède déjà.

Comment ça marche

Xenon fonctionne comme un petit service local sur le PC et sert le dashboard sur votre propre réseau. La tablette ou le téléphone l'ouvre comme une page web, de sorte qu'un iPad, une tablette Android, une ancienne tablette Fire, un iPhone ou n'importe quel téléphone avec un navigateur fonctionnent tous, et il n'y a pas d'application à maintenir à jour sur l'appareil. L'appairage est un code QR affiché par le PC ; chaque appareil appairé est répertorié et peut être supprimé individuellement. Sur votre Wi-Fi, la tablette communique directement avec le PC, et non via un service cloud. Xenon lui-même passe toujours en ligne pour certaines fonctionnalités, telles que les vérifications de mise à jour, le catalogue et la météo.

Ce que vous voyez est le véritable dashboard, et non un affichage distant : les mêmes tuiles, le même thème et les mêmes pages que sur un moniteur, réagencés pour la forme de la tablette. Les zones tactiles sont dimensionnées pour les doigts.

Configuration

  1. Sur le PC, téléchargez Xenon-Setup-x64.exe, exécutez-le et appuyez sur Terminer l'installation lorsque l'application vous le demande. Cela ne se produit qu'une seule fois.
  2. Ouvrez Paramètres → Télécommande → Accès au téléphone, activez Autoriser l'accès depuis d'autres appareils et appuyez sur Ajouter un appareil. L'ordinateur affiche un code QR.
  3. Pointez l'appareil photo de la tablette vers le code. Le dashboard s'ouvre dans son navigateur. Ajoutez-le à l'écran d'accueil si vous souhaitez l'afficher en plein écran.
  4. Si le PC ne dispose d'aucun moniteur supplémentaire, indiquez à Xenon lors du premier lancement d'afficher rien sur le PC : la tablette devient l'écran unique.

Le guide téléphone comporte les mêmes étapes avec des captures d'écran, ainsi que l'itinéraire facultatif pour accéder au dashboard depuis l'extérieur de la maison.

Limites

Ce n'est pas un second moniteur. Votre PC n'affichera pas une fenêtre sur la tablette ; vous y obtenez un dashboard, avec des commandes qui agissent sur le PC. Si ce que vous souhaitez est un véritable bureau supplémentaire sur un petit écran, la tuile Second screen de Xenon le fait sur un moniteur réel (Windows uniquement), ce qui est une chose différente. L'accès via tablette et téléphone est également marqué beta dans la version actuelle : il fonctionne bien sur un Wi-Fi domestique, mais il est encore jeune.

Une dernière remarque : l’installateur Windows est signé, Windows affiche donc un éditeur vérifié. SmartScreen peut encore afficher un avertissement pendant un certain temps, car Microsoft accorde la réputation au fil du temps : cliquez sur Plus d’informations, puis sur Exécuter quand même. Le FAQ explique pourquoi et comment vérifier le fichier.

Questions

La tablette a-t-elle besoin d'une application ?

Non. N'importe quel navigateur suffit. Ajouter la page à l'écran d'accueil vous donne une icône plein écran, mais c'est facultatif.

Fonctionne-t-il sur un ancien iPad ou une tablette Android ?

Si son navigateur ouvre encore des pages web modernes, oui. Les très anciens appareils dont le navigateur ne reçoit plus de mises à jour peuvent afficher certains éléments lentement ; le dashboard est léger, mais il s'agit d'une page dynamique.

La tablette se connecte-t-elle via Internet ?

Hors de votre Wi-Fi : l'ordinateur sert la page directement à la tablette. L'accès depuis l'extérieur de la maison est une configuration distincte, activable manuellement et décrite dans le guide du téléphone. Xenon se connecte toujours à Internet pour certaines fonctionnalités, telles que les vérifications de mises à jour, le catalogue et la météo.

Puis-je utiliser un téléphone au lieu d'une tablette ?

Oui, de la même manière. La mise en page s’adapte à un écran de téléphone en mode portrait.

Est-ce gratuit ?

Oui. Aucune version payante, aucun compte, aucune publicité. Le code source est disponible sur GitHub sous une licence non commerciale.

Télécharger Xenon

Un seul installateur et aucun compte ; vos paramètres sont enregistrés sur votre PC. Télécharger Xenon pour Windows, ou obtenir les versions macOS et Linux beta . Les questions sont à poser sur le Discord.
