Télécharger Xenon

La dernière version pour chaque plateforme, directement depuis GitHub. Gratuit, sans compte, et elle se met à jour automatiquement ensuite.

Dernière mise à jour : 26 septembre 2026. Chaque lien pointe vers la dernière version.

Configuration initiale

Windows. Lancez l’installateur. Il installe l’application, qui s’ouvre d’elle-même, ne trouve pas encore de moteur dashboard et propose Configuration complète. Cliquez dessus une fois : une fenêtre s’ouvre et installe Node.js, les lecteurs de capteurs et la tâche qui démarre Xenon lors de votre connexion, en vous affichant chaque étape. Le téléchargement est vérifié par rapport à la clé de signature du projet avant que quoi que ce soit ne s’exécute. Cela prend quelques minutes et n’a lieu qu’une seule fois.

macOS et Linux. Ouvrez l'application que vous avez téléchargée. Au premier lancement, elle propose de configurer le dashboard dans une fenêtre de terminal, en vérifiant le téléchargement avant de l'extraire. Sur Linux, le paquet ne le fait pas délibérément à votre place, car tout ce qu'il créerait appartient à un seul compte utilisateur et un paquet s'installe en tant que root pour toute la machine.

Ensuite, Xenon demande sur quel écran il doit être installé. Un moniteur supplémentaire, une tablette, votre téléphone ou un CORSAIR Xeneon Edge conviennent tous ; le guide pour téléphone explique comment associer un téléphone ou une tablette en environ trente secondes.

Avertissements Windows et macOS

Depuis la version 4.11.9, l’installateur Windows est signé, ce qui permet à Windows d’afficher un éditeur vérifié. SmartScreen peut toujours afficher un avertissement pendant un certain temps, car Microsoft accorde une réputation au fil du temps : cliquez sur Plus d’informations, puis sur Exécuter quand même. Defender évalue également ce qu’un programme fait, et pas seulement qui l’a signé, donc une détection peut toujours se produire. La FAQ explique chaque type d’avertissement et comment récupérer le fichier; cette page répertorie tous les processus que Xenon exécute, pour le lecteur qui souhaite savoir exactement ce qui est installé.

macOS. La version Mac est beta et non notarisée, macOS refuse donc le premier lancement. Ouvrez Réglages Système, Confidentialité et sécurité, faites défiler vers le bas et cliquez sur Ouvrir quand même à côté de Xenon. Sur macOS 15 et versions ultérieures, la méthode d’ouverture par clic avec le contrôle ne fonctionne plus.

Vérification du téléchargement

Chaque version est accompagnée d'un fichier SHA256SUMS signé avec la clé Ed25519 du projet. Comparez l'empreinte numérique de ce que vous avez téléchargé :

Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256        # Windows, PowerShell
shasum -a 256 Xenon-macOS-universal.dmg                       # macOS
sha256sum Xenon-Linux-x86_64.AppImage                          # Linux

S'il correspond à la ligne pour ce fichier dans le SHA256SUMS de la version, le fichier est identique, octet par octet, à celui que GitHub Actions a compilé à partir du code source public à ce tag. Sur Windows, vous pouvez également faire un clic droit sur l'installateur, choisir Propriétés et ouvrir l'onglet Signatures numériques pour voir l'éditeur.

Autres méthodes d'installation

À partir de la source. Téléchargez le zip du code source de la version, extrayez-le et exécutez INSTALL.bat sous Windows, INSTALL.command sous macOS ou ./INSTALL.sh sous Linux. Résultat identique à celui de l'installateur, pour ceux qui préfèrent lire ce qui s'exécute.

winget. Les manifestes de paquets sont rédigés et en attente d'une publication qui passe les contrôles sans avertissement chez Microsoft ; jusqu'à ce qu'il soit répertorié, l'installateur ci-dessus est la solution. Cette page indiquera winget install xenon le jour où cela changera.

Mise à jour en cours. Xenon vérifie la présence d'une nouvelle version au démarrage et se met à jour automatiquement. Vous n'avez jamais besoin de revenir ici.

Qu'est-ce que Xenon

Un dashboard gratuit qui fonctionne sur votre PC et s'affiche sur n'importe quel écran disponible : statistiques système, contrôles multimédias et micro, une grille de touches au style Deck Stream, éclairage, une IA avec laquelle vous pouvez discuter. Aucun compte requis, et vos paramètres, fichiers et lectures de capteurs sont conservés sur votre PC. La page d'accueil le montre.
