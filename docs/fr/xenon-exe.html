xenon.exe

Si vous avez trouvé un processus inconnu sur votre PC et que vous avez recherché son nom, la réponse la plus souvent vraie est la première : il ne provient probablement pas de Xenon.

Dernière mise à jour : 26 septembre 2026

La réponse courte Ce que Xenon exécute Comment vérifier ce que vous avez Si vous ne l'avez jamais installé Si Defender l'a signalé Comment le supprimer

La réponse courte

Xenon n'installe pas de fichier nommé xenon.exe. Si le Gestionnaire des tâches vous affiche un processus orthographié exactement xenon.exe, il s'agit presque certainement d'un autre élément qui partage simplement ce nom, et la liste ci-dessous indique lequel des deux vous consultez.

Si vous regardez plutôt xenon-native.exe ou xenon-helper.exe, ce sont les nôtres, et le reste de cette page explique exactement ce que fait chacune d'eux.

Ce qui s'exécute sur Windows avec Xenon

Quatre éléments qui lui sont propres :

FichierDescription
Xenon-Setup-x64.exeL’installateur. Vous l’exécutez une seule fois ; il ne reste pas sur le système en tant que processus.
xenon-native.exeLa fenêtre dashboard elle-même, un petit conteneur natif qui dessine l'interface sur l'écran que vous avez choisi. C'est celle que vous voyez dans la barre des tâches.
xenon-helper.exeLe pont vers les parties de Windows auxquelles une application Web ne peut pas accéder seule : périphériques audio et volume par application, touches multimédias, notifications, liste des fenêtres, raccourcis clavier globaux, analyse des disques et liaison Bluetooth avec le téléphone. Il est démarré par le moteur et lui répond via l’entrée et la sortie standard.
node.exeLe moteur dashboard. Xenon est une application web locale, de sorte que le service qui la sert est un simple Node.js à l’écoute sur 127.0.0.1:3030, une adresse accessible uniquement par cet ordinateur. Si vous activez l’accès au téléphone dans les Paramètres, il écoute également sur votre réseau local, ce qui permet aux téléphones et tablettes appairés d’y accéder.

Ils se trouvent dans deux dossiers sous votre profil utilisateur, jamais dans Windows lui-même : %LOCALAPPDATA%\Xenon et %LOCALAPPDATA%\Programs\Xenon. Une tâche planifiée par session démarre le moteur lorsque vous vous connectez, sous votre propre compte. Si vous avez accepté l'invite d'administrateur lors de l'installation, cette tâche s'exécute avec des privilèges élevés, ce qui lui permet de lire les températures ; rien n'est installé en tant que service Windows.

Il y a ensuite les outils que Xenon exécute pour des fonctionnalités spécifiques, chacun provenant de ses propres développeurs plutôt que de ce projet, et n'exécuté que lorsque la fonctionnalité qui en a besoin est activée :

  • LibreHardwareMonitor et PawnIO, installés via winget, lisent CPU et les températures des disques. PawnIO est un pilote de noyau signé, et le remplaçant de WinRing0, le pilote à l'origine de la plupart des faux positifs des anciens outils de surveillance du matériel. Xenon n'a jamais inclus WinRing0 et ne le fera jamais.
  • PresentMon, l'outil de mesure des frame-times d'Intel, téléchargé dans le dossier propre à Xenon, pour le véritable compteur de FPS en jeu.
  • FFmpeg pour la saisie vocale et les réponses orales, et Ollama uniquement si vous passez l'assistant au fournisseur local gratuit. L'installateur ne télécharge aucun des deux ; vous les configurez depuis les Paramètres lorsque vous en avez besoin.
  • Sunshine et Tailscale, uniquement si vous activez le contrôle à distance de l'ordinateur.

Comment vérifier ce que vous avez réellement

  1. Dans le Gestionnaire des tâches, cliquez avec le bouton droit sur le processus et choisissez Ouvrir l'emplacement du fichier. S'il ne se trouve pas sous %LOCALAPPDATA%\Xenon ou %LOCALAPPDATA%\Programs\Xenon, il ne s'agit pas de ce projet.
  2. Cliquez avec le bouton droit sur le fichier, choisissez Propriétés et ouvrez l'onglet Signatures numériques. Depuis la version 4.11.9, Xenon-Setup-x64.exe, xenon-native.exe et xenon-helper.exe sont signés, et cet onglet affiche l'éditeur. Les fichiers des versions antérieures ne comportent pas de signature ; pour ceux-ci, l'empreinte numérique à l'étape suivante constitue la vérification.
  3. Comparez le fichier avec celui que nous avons publié. Chaque version est accompagnée d'un fichier SHA256SUMS signé avec la clé du projet, et cela fonctionne de la même manière pour les versions signées et les versions antérieures : 
    Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256
    Si l’empreinte correspond à la ligne de cette version dans SHA256SUMS, le fichier est identique, octet par octet, à celui que GitHub Actions a généré à partir du code source publié à cette étiquette.
  4. Uploadez le fichier sur VirusTotal. Si quelques moteurs le signalent tandis que les autres ne détectent rien, cela indique généralement un problème de réputation plutôt qu'une présence de logiciel malveillant. Si la quasi-totalité des moteurs le signalent, c'est une autre histoire.

Si vous n'avez jamais installé Xenon

Par conséquent, ce que vous regardez ne provient pas de ce projet. Vérifiez l'emplacement du fichier et l'éditeur comme indiqué ci-dessus. Rien sur ce site ne supprimera un logiciel que nous n'avons pas installé, et aucune page ici ne vous demandera de télécharger un « nettoyeur » pour s'en débarrasser : c'est la forme habituelle de l'arnaque qui suit une recherche de ce type.

S'il est à nous et que Defender l'a signalé

Cela peut encore se produire. Depuis la version 4.11.9, l’installateur est signé, de sorte que Windows affiche un éditeur vérifié. SmartScreen peut toujours afficher un avertissement pendant un certain temps, car Microsoft accorde une réputation au fil du temps : cliquez sur Plus d’informations, puis sur Exécuter quand même. Defender évalue également ce qu’un programme fait, et pas seulement qui l’a signé, de sorte qu’un fichier signé peut toujours être signalé.

La FAQ explique les deux types de détection, celui que le nom de l'avertissement vous indique, et comment ajouter l'exclusion si vous souhaitez continuer à l'utiliser. En bref : un nom se terminant par !cl est le verdict de l'apprentissage automatique concernant la réputation ; un nom simple est une signature comportementale réagissant à un programme d'installation qui contient un script téléchargeant du code, ce qui est également une description exacte de quelque chose que vous ne voudriez pas. Aucun des deux n'est une preuve en soi, c'est pourquoi les étapes 2 et 3 ci-dessus existent.

Comment le supprimer complètement

Paramètres → Applications → Applications installées → Xenon → Désinstaller, ou exécutez UNINSTALL.bat depuis le dossier que vous avez extrait si vous avez installé la version classique. Cela supprime les deux dossiers, la tâche planifiée et l'application de la barre des tâches. Les composants de température installés via winget sont des programmes distincts et se désinstallent séparément, depuis la même liste d'applications.
