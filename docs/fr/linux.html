Xenon sur Linux

Xenon est un dashboard gratuit pour tout écran disponible. Sur Linux, il est en beta : le dashboard est identique à celui de Windows, et cette page liste les différences restantes ainsi que les paquets requis.

Dernière mise à jour : 26 septembre 2026 · chaque lien pointe vers la dernière version

La prise en charge de Linux est en beta. Le dashboard, les widgets, le catalogue et les intégrations sont identiques à ceux de Windows. Ce qui diffère encore, c'est la partie qui lit et pilote la machine, répertoriée dans le tableau ci-dessous. Elle est testée sur GNOME et KDE.

Premier lancement

Ouvrez l'application. Au premier lancement, il est proposé de configurer le dashboard dans un terminal : il télécharge le moteur, vérifie le téléchargement avant de l'extraire, et enregistre un service systemd --user afin que Xenon démarre lors de votre connexion. En l'absence de gestionnaire d'utilisateurs, il utilise à la place une entrée de démarrage automatique XDG et vous l'indique, en précisant que ce mode de secours ne redémarre pas Xenon après un plantage.

Les fichiers .deb et .rpm ne le font pas volontairement lors de l'installation : tout ce que la configuration crée appartient à un seul compte utilisateur, tandis qu'un paquet est installé en tant que root pour toute la machine.

L'installateur énumère également les outils facultatifs dont vous ne disposez pas. Sur Debian et Ubuntu :

sudo apt install nodejs npm unzip           # required
sudo apt install wireplumber                # volume, microphone and the per-app mixer
sudo apt install wmctrl xdotool x11-utils   # the open-applications widget (X11 sessions)
sudo apt install ffmpeg                     # voice input and spoken replies

Si votre bureau ne dispose d'aucun émulateur de terminal, l'application ne peut pas vous afficher l'installateur : téléchargez le zip source depuis la release, extrayez-le et exécutez ./INSTALL.sh.

X11 et Wayland

La plupart des fonctionnalités du dashboard fonctionnent de la même manière sur les deux. Les parties qui diffèrent sont celles qui doivent voir d'autres fenêtres : le widget des applications ouvertes, le sélecteur d'applications et la vision d'écran par l'IA utilisent les outils X11 (wmctrl, xdotool), de sorte qu'en session Wayland, Xenon les masque au lieu de les proposer puis d'échouer. Si vous en avez besoin, connectez-vous à une session X11.

Signaler un problème

Linux est en beta car le tableau ci-dessus comporte encore des lacunes. Pour en signaler une, ouvrez un signalement de bug auprès de votre distribution, en précisant votre bureau et votre type de session. Pour poser une question d'abord, écrivez sur le Discord.
