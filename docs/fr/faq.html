Avant l'installation

Ai-je besoin d'un CORSAIR Xeneon Edge ?

Non, Xenon a été conçu autour de cet écran, mais le Xeneon Edge est l'un des écrans sur lesquels il fonctionne, et non le produit. Un moniteur de rechange, une vieille tablette posée sur le bureau, un écran tactile, une fenêtre sur votre écran principal ou le téléphone dans votre poche fonctionnent tous de la même manière. Si vous n'avez aucun écran de rechange, utilisez votre téléphone : environ trente secondes sur votre Wi-Fi, et vous obtenez le véritable dashboard, et non un accès à distance.

Est-ce vraiment gratuit ?

Oui. Aucune version payante, aucun essai, aucun compte, aucune publicité et aucune fonctionnalité réservée à un niveau qui n'existe pas. La licence est personnalisée et non commerciale : gratuite pour un usage personnel, et vous pouvez lire, exécuter et modifier le code source. Ce qui nécessite une autorisation écrite, c'est la vente, l'intégration dans un produit commercial, la redistribution comme votre propre travail ou l'utilisation du nom Xenon pour autre chose.

Il y a un bouton café si vous souhaitez dire merci, et c'est vraiment tout.

Sur quels systèmes fonctionne-t-il ?

Windows 10 et 11 (64 bits), macOS 11 ou version ultérieure (un téléchargement universel pour Apple Silicon et Intel) et Linux (64 bits).

macOS et Linux sont en beta. Le dashboard, les widgets, le store et les intégrations sont identiques sur les trois plateformes ; ce qui diffère encore, c'est la couche qui lit la machine elle-même. Le tableau des plateformes indique exactement ce qui fonctionne où, fonction par fonction.

Ai-je besoin d'un PC CORSAIR ou d'iCUE ?

Non. Xenon fonctionne sur n'importe quel PC et ne nécessite aucun matériel ou logiciel CORSAIR. iCUE n'est important que pour deux éléments facultatifs : conserver le dashboard dans un widget iFrame iCUE si vous préférez, et piloter les périphériques CORSAIR RGB. Tout le reste est indépendant de celui-ci.

Lorsque Windows le qualifie de virus

La version courte

Depuis la version 4.11.9, l'installateur Windows est signé, ce qui permet à Windows d'afficher un éditeur vérifié. Des avertissements peuvent toutefois continuer à s'afficher pendant un certain temps, car Microsoft accorde une réputation au fil du temps et Defender évalue également le comportement du programme. Cela peut générer jusqu'à trois avertissements différents provenant de trois systèmes distincts, chacun nécessitant une réponse spécifique. Aucun d'entre eux ne constitue une détection réelle de logiciels malveillants, et vous n'avez pas besoin de me croire sur parole pour cela : chaque version est accompagnée d'empreintes numériques que vous pouvez vérifier vous-même.

Windows Defender a détecté Xenon et il a maintenant disparu

Il s'agit d'un faux positif, et c'est de loin le sujet le plus fréquent des messages que je reçois. Le nom de détection se termine généralement par !cl, ce qui signifie que le verdict provient du modèle d'apprentissage automatique dans le cloud de Defender, plutôt que d'une signature correspondant à un logiciel malveillant connu. Chaque version publiée est un nouveau fichier pour ce modèle, si bien que la détection peut apparaître et disparaître d'une version à l'autre.

Pour récupérer votre installation :

  1. Ouvrez Sécurité Windows → Protection contre les virus et menaces → Historique de protection, trouvez la Xenon entrée et choisissez Actions → Restaurer.
  2. Ajoutez une exclusion pour que cela ne se reproduise plus : Gérer les paramètres → Exclusions → Ajouter une exclusion → Dossier, et ajoutez %LOCALAPPDATA%\Xenon.
Mon navigateur refuse de le télécharger ou indique qu'il a détecté un virus

Même cause, mais un gardien différent : il s'agit de la vérification de réputation propre à votre navigateur, Google Safe Browsing dans Chrome et SmartScreen dans Xeneon Edge. Ouvrez votre liste de téléchargements avec Ctrl+J et choisissez Conserver, ou Conserver quand même, sur le fichier annulé. Si SmartScreen vous avertit ensuite lors de l'exécution de l'installation, cliquez sur Plus d'informations, puis sur Exécuter quand même.

Comment savoir que c'est sûr, plutôt que de simplement vous faire confiance ?

Vérifiez-le vous-même, et s'il vous plaît, faites-le. Chaque version publiée inclut un fichier SHA256SUMS signé avec la clé du projet. Dans PowerShell :

Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256

Comparez le résultat avec la ligne Xenon-Setup-x64.exe dans le fichier SHA256SUMS de cette version. S'ils correspondent, le fichier que vous avez est identique, octet par octet, à celui construit par GitHub Actions à partir du code source public à ce tag, et chaque ligne de ce code source est lisible sur GitHub. Vous pouvez également l'uploader sur VirusTotal : le fait que quelques moteurs le signalent tandis que les autres reviennent propres est ce à quoi ressemble un problème de réputation, et non ce à quoi ressemble un logiciel malveillant.

Vous pouvez également vérifier la signature : faites un clic droit sur le fichier, choisissez Propriétés et ouvrez l'onglet Signatures numériques, qui indique le nom de l'éditeur. Les versions à partir de 4.11.9 sont signées ; les plus anciennes ne le sont pas, donc pour celles-ci, l'empreinte est la vérification.

Ne contournez un avertissement que pour un fichier téléchargé depuis la page officielle des Versions publiées et dont vous avez vérifié l'empreinte. Convaincre quelqu'un d'ignorer un avertissement est exactement ce que font les logiciels malveillants réels, et l'empreinte est ce qui permet de distinguer ces deux situations.

Xenon ne démarre pas du tout, et Defender n'a jamais rien signalé

Sur Windows 11, il s'agit généralement de Contrôle intelligent des applications, qui est un système distinct de votre antivirus. Vérifiez Sécurité Windows → Contrôle des applications et du navigateur → Contrôle intelligent des applications.

Il bloque toute application qu'il ne fait pas déjà confiance, et il prend cette décision avant même que votre antivirus ne soit consulté. L'exclusion ci-dessus n'a donc aucun effet sur lui, et il n'y a aucun moyen d'autoriser une seule application tout en le laissant activé. Il ne s'active que lors d'une installation propre de Windows 11, c'est pourquoi il apparaît sur un PC nouvellement reconstruit et jamais sur un système mis à niveau. Il ne reste donc que deux paramètres : Évaluation, où Windows observe votre utilisation du PC et décide lui-même s'il doit rester activé, et Désactivé.

Lisez ceci avant de le modifier : désactiver le Contrôle intelligent des applications est une porte à sens unique. Windows ne vous permettra pas de le réactiver par la suite sans réinitialiser ou réinstaller le PC. C'est une conception de Microsoft et rien que Xenon ne puisse contourner. Depuis la version 4.11.9, les fichiers de Xenon sont signés, et Microsoft indique que le Contrôle intelligent des applications permet à une application correctement signée de s'exécuter lorsqu'il n'a pas de verdict propre, essayez donc d'abord la dernière version avec cette fonction activée. S'il bloque toujours Xenon et que vous préférez le laisser activé, la réponse honnête est que Xenon ne peut pas s'exécuter sur cet appareil.

Xenon se ferme tout seul pendant que je l’utilise

Ouvrez le menu depuis les icones cachées et choisissez Ouvrir le journal des plantages. Xenon écrit une ligne à chaque démarrage et une à chaque arrêt, et ces lignes permettent de distinguer les deux causes possibles.

La dernière ligne est un PANIC. L'application a planté d'elle-même, et la ligne indique le thread et la ligne de source exacte où l'échec s'est produit. Collez-la dans le Discord ou un signalement de bug : avec cette seule ligne, la correction est généralement rapide.

La dernière ligne est launched, sans rien après. Rien à l'intérieur de l'application n'a décidé de s'arrêter, donc quelque chose à l'extérieur a terminé le processus. Sur Windows, c'est presque toujours votre antivirus qui met xenon-native.exe en quarantaine pendant son exécution. Recherchez dans Sécurité Windows → Protection contre les virus et menaces → Historique de la protection une entrée horodatée au moment où la fenêtre a disparu, restaurez-la et ajoutez une exclusion de dossier pour %LOCALAPPDATA%\Xenon et %LOCALAPPDATA%\Programs\Xenon. Xenon se trouve dans les deux, et exclure uniquement le premier laisse la moitié qui tourne toute la journée exposée à la même détection.

Xenon est-il signé ?

Oui, sur Windows depuis la version 4.11.9 (20 septembre 2026). L'installateur, l'application qu'il contient et le helper portent une signature Authenticode, de sorte que Windows affiche un éditeur vérifié au lieu d'un éditeur inconnu.

Une signature prouve qui a publié un fichier et que personne ne l'a modifié depuis. Elle n'apporte pas de réputation dès le premier jour : SmartScreen l'accorde au fil du temps à mesure que les personnes téléchargent le fichier, et Defender évalue également ce qu'un programme fait. Ainsi, un avertissement peut toujours s'afficher pendant un certain temps, et une chose aide plus que toute autre. Si Defender signale votre téléchargement, signalez-le comme un faux positif sur microsoft.com/wdsi/filesubmission, en choisissant Client grand public puis Faux positif (malware). Cela prend deux minutes, les signalements des utilisateurs réels ont du poids, et la détection est généralement retirée pour tout le monde en quelques jours.

Sur macOS, la build est beta et non notarisée, ce qui est une étape distincte chez Apple ; la question sur macOS ci-dessous explique le premier lancement.

macOS et Linux

macOS indique que Xenon ne peut pas être ouvert car Apple ne peut pas le vérifier

Pour l'instant : l'application n'est pas notarisée, ce qui nécessite un abonnement payant au programme Apple Developer dont ce projet ne dispose pas.

Sur macOS 15 et versions ultérieures, ouvrez Réglages Système → Confidentialité et sécurité, faites défiler jusqu'en bas et cliquez sur Ouvrir quand même à côté de Xenon. Apple a supprimé l'ancien raccourci clic droit. Sur macOS 11 à 14, faites un clic droit sur l'application, choisissez Ouvrir, puis Ouvrir à nouveau. Dans les deux cas, cela ne se fait qu'une fois par version.

Sur macOS, le widget affiche une Corbeille de 0 o

La Corbeille et la plupart des ~/Library/Caches sont protégées par Accès complet au disque, une autorisation que macOS accorde par application. Sans elle, ces dossiers apparaissent vides plutôt que refusés, de sorte qu'aucune erreur n'est signalée et que la carte du disque sous-estime silencieusement les données.

Ouvrez Réglages Système → Confidentialité et sécurité → Accès complet au disque, appuyez sur +, choisissez Xenon dans Applications, assurez-vous que son interrupteur est activé, puis quittez Xenon et rouvrez-le.

Jusqu'à la version 4.11.3, cela devait être refait après chaque mise à jour, mais ce n'est plus le cas. macOS lie l'autorisation à la signature du code, et Xenon était auparavant signé de manière ad hoc, si bien que chaque version semblait être une application différente et que l'autorisation cessait silencieusement de s'appliquer. Xenon possède désormais son propre certificat, qui reste identique d'une version à l'autre, ce qui permet à l'autorisation de survivre aux mises à jour. La mise à jour 4.11.3 elle-même la réinitialise une dernière fois, car c'est la version où l'identité change. S'il est listé mais ne fonctionne manifestement pas, supprimez Xenon avec − et ajoutez-le à nouveau. Xenon détecte désormais cet état par lui-même et vous l'indique sur le dashboard.

Que dois-je installer sur macOS ?

Node.js est la seule exigence, et Xenon le signale s'il est manquant : brew install node. Les autres sont facultatifs et chacun active une fonctionnalité spécifique :

  • vladkens/tap/macmon pour la température et la charge GPU
  • switchaudio-osx pour le commutateur de l'appareil de sortie
  • ffmpeg pour la saisie vocale et les réponses orales

Xenon énumère ceux que vous n'avez pas au lieu d'échouer plus tard.

Comment l'installer sur Linux ?

Téléchargez le AppImage (rendez-le exécutable et lancez-le) ou le .deb. Au premier lancement, il vous propose de configurer le dashboard dans une fenêtre de terminal que vous pouvez lire et arrêter, en vérifiant le téléchargement par rapport à la clé du projet avant d'extraire quoi que ce soit.

Le paquet ne le fait pas intentionnellement pour vous : tout ce que l'installation crée appartient à un seul compte utilisateur, et un paquet s'installe en tant que root pour toute la machine. Si vous préférez vous passer complètement de l'application, téléchargez l'archive zip des sources depuis Releases et exécutez ./INSTALL.sh.

Vous avez besoin de nodejs npm unzip. Facultatif, chacun pour une fonctionnalité : wireplumber (volume, micro, mélangeur par application), wmctrl et x11-utils (le sélecteur d'applications), playerctl (titre de la lecture en cours instantanée), ffmpeg (voix). Exécutez npm run doctor et il vous dira ce qui manque et ce que chacun activerait.

Que signifie réellement beta pour macOS et Linux ?

Le dashboard est le même produit : mêmes widgets, même Store, mêmes thèmes, mêmes intégrations, même accès par téléphone. Ce qui diffère est la couche qui lit la machine, si bien que certains capteurs et actions système ne sont pas encore disponibles ou fonctionnent différemment.

Rien ne prétend fonctionner, ce qui est l'aspect le plus important. Une tuile sans source de données sur votre plateforme l'indique en une ligne au lieu de charger indéfiniment, et une touche du Deck que la plateforme ne peut pas exécuter est masqué plutôt qu'offert puis en échec.

Installation, démarrage, mise à jour

Que fait réellement l'installateur ?

Sur Windows, il installe l'application, installe le moteur dashboard sous %LOCALAPPDATA%\Xenon, installe Node.js si vous ne l'avez pas déjà, et enregistre une tâche pour que le dashboard démarre lorsque vous vous connectez. Il récupère également les éléments facultatifs : FFmpeg, LibreHardwareMonitor et PawnIO pour les températures, PresentMon pour le FPS réel en jeu.

Rien ne s'exécute en cachette. L'installation elle-même n'installe que l'application et l'ouvre ; la moitié dashboard est proposée par l'application par la suite et s'exécute dans une fenêtre de console que vous pouvez surveiller et interrompre. Une version antérieure le faisait silencieusement en arrière-plan, et c'est précisément cette procédé qui fait qu'un installateur non signé est mis en quarantaine, il a donc été supprimé.

Se lance-t-il avec mon PC et puis-je l'empêcher de le faire ?

Oui, il démarre lorsque vous vous connectez, de sorte que le dashboard est déjà actif lorsque vous vous asseyez. Il s'exécute dans votre propre session plutôt qu'en tant que service système, et c'est volontaire : en dehors de votre session, il n'y a pas de liste d'appareils audio, pas de liste de fenêtres, pas de micro et aucun moyen d'ouvrir une application, donc la moitié des fonctionnalités cesseraient de fonctionner silencieusement.

Pour supprimer Xenon, exécutez UNINSTALL.bat sur Windows, UNINSTALL.command sur macOS ou ./UNINSTALL.sh sur Linux.

Comment mettre à jour ?

Xenon se met à jour automatiquement. Lorsqu'une version est disponible, le dashboard affiche une invite ; un seul appui la télécharge, vérifie sa signature avant d'extraire quoi que ce soit, installe le moteur puis l'application, et restaure automatiquement la version précédente en cas d'échec. Vos paramètres, vos dispositions et vos notes sont toujours conservés, et les fichiers résiduels des anciennes versions sont nettoyés.

Comment le désinstaller ?

Exécutez UNINSTALL.bat sous Windows, UNINSTALL.command sous macOS ou ./UNINSTALL.sh sous Linux. Les trois demandent une confirmation, puis suppriment complètement Xenon : l'application, l'entrée de démarrage, le serveur local, vos données et le dossier d'installation. Ajoutez --keep-data (-KeepData sous Windows) pour conserver vos paramètres, dispositions et notes. La suppression du dossier de données efface tout ce que Xenon a stocké, y compris l'identifiant aléatoire utilisé pour qu'une note sur le store ne soit comptée qu'une seule fois.

Pourquoi demande-t-il des droits d'administrateur ?

Une seule fois, lors de l'installation, et pour deux raisons : la configuration de CPU et la lecture des températures du disque (LibreHardwareMonitor et PawnIO, qui nécessitent un composant au niveau pilote), ainsi que l'enregistrement de la tâche de démarrage. Si vous refusez, le reste fonctionne toujours, mais vous n'obtiendrez simplement aucune température. Xenon ne s'exécute plus avec des privilèges élevés par la suite.

Il est indiqué que le port 3030 est déjà utilisé

Presque toujours, il s'agit d'une autre copie du dashboard déjà en cours d'exécution, ce qui est généralement ce que vous souhaitez : ouvrez http://127.0.0.1:3030/ et il y sera. Si un autre élément de votre PC utilise ce port, modifiez-le dans server/server.js.

Utilisation de Xenon

Puis-je vraiment utiliser mon téléphone comme écran ?

Oui, et c’est votre dashboard plutôt qu’une télécommande : même disposition, mêmes widgets, même thème, et les touches du Deck fonctionnent vraiment sur le PC. Aucun compte, aucun cloud, rien à installer, et sur votre propre Wi-Fi, rien ne quitte votre réseau domestique. Cela prend environ trente secondes. Le guide téléphone couvre les deux méthodes, à la maison et depuis n’importe où.

Dois-je utiliser l'application ?

Non. L'application est une fenêtre autour du dashboard, et le dashboard est une page web locale : ouvrez http://127.0.0.1:3030/ dans n'importe quel navigateur, sur n'importe quel moniteur. L'application vaut la peine d'être installée sur un écran tactile car elle ajoute le support du tactile sécurisé pour les jeux et une icône de barre système. Dans iCUE, un widget iFrame pointant vers la même adresse fonctionne également.

Pour ce faire, ajoutez un Page web (HTML) widget dans iCUE et collez ceci à l'intérieur : <iframe src='http://127.0.0.1:3030/' width='100%' height='100%' frameborder='0'></iframe>

Ai-je besoin d'une clé API pour l'IA ?

Uniquement si vous souhaitez un fournisseur cloud, et une clé Gemini est gratuite à créer. Tout le reste dans Xenon fonctionne sans celle-ci.

Il existe également une option entièrement locale : Ollama pour le chat et Whisper pour la voix, configurée à la demande depuis les Paramètres, sans que rien ne quitte votre PC. Si vous choisissez un fournisseur cloud, vos invites sont envoyées à ce fournisseur selon ses conditions, et Xenon n'envoie jamais rien à un modèle que vous n'avez pas choisi.

Il n'y a pas de température CPU

Relancez l'installateur et acceptez la demande d'administrateur afin qu'il puisse installer LibreHardwareMonitor et PawnIO et enregistrer la tâche de démarrage avec privilèges élevés. Certains ordinateurs portables et cartes mères n'exposent aucun capteur du tout, auquel cas la tuile indique cela plutôt que d'afficher un nombre inventé.

Puis-je créer mes propres widgets et thèmes ?

Oui, et la plupart de ces éléments ne nécessitent aucun code. Les thèmes, les mises en page, les scènes d'ambiance et les profils Deck sont créés directement dans l'application et partagés sous forme de code que n'importe qui peut importer. Les Widgets sont de petits HTML, des CSS et des paquets JavaScript qui s'exécutent dans un bac à sable, avec un pont documenté pour les capteurs et les actions.

Le guide du créateur est le point de départ idéal, et le catalogue présente ce que d'autres ont déjà créé.

Contrôle-t-il l'éclairage RGB ?

Oui : CORSAIR appareils via iCUE, ainsi que WLED, OpenRGB, Philips Hue et Nanoleaf directement sur votre réseau. Il peut réagir aux températures ou à ce qui est en cours de lecture, ou simplement maintenir une couleur de votre choix. Cette fonction est facultative et reste désactivée jusqu'à ce que vous la configuriez.

Confidentialité et confiance

Xenon envoie-t-il mes données quelque part ?

Vos paramètres, notes, tâches, événements, decks, expressions de recherche et index de fichiers restent sur votre PC. Il n'y a pas d'analyse SDK, pas de rapporteur de plantage et pas de suivi comportemental dans l'application.

Ce n'est pas non plus entièrement hors ligne, et prétendre le contraire serait une version déshonnête : elle vérifie les mises à jour et contacte un service pour la météo ou une musique API lorsque vous activez ces fonctionnalités. La page confidentialité répertorie chaque appel que l'application peut effectuer, ce qui le déclenche et exactement ce qu'elle envoie, sans rien omettre.

Ai-je besoin d'un compte ?

Non. Il n'existe pas de compte Xenon, aucune connexion et aucun serveur de mon côté entre vous et votre propre dashboard. Les intégrations que vous configurez vous-même, comme Spotify ou Twitch, utilisent leurs propres identifiants et restent inactives jusqu'à ce que vous les configuriez.

Licence, coût et assistance

Puis-je l'utiliser au travail ou dans mon propre produit ?

L'usage personnel est gratuit, y compris sur le PC que vous utilisez pour travailler. La vente, l'intégration dans un produit commercial, la redistribution comme étant votre propre travail ou l'utilisation du nom Xenon pour autre chose nécessite une autorisation écrite préalable.

Si vous avez un cas précis en tête, demandez : envoyez-moi un e-mail ou parlez-en sur Discord. La réponse est souvent oui, sous certaines conditions.

Où puis-je obtenir de l'aide ?

Le Discord est le moyen le plus rapide, et c'est là que la plupart des problèmes sont réellement diagnostiqués. Pour un problème reproductible, un ticket GitHub indiquant votre système, ce que vous avez fait et ce qui s'est passé est la chose la plus utile que vous puissiez envoyer. Les deux sont lus par la même personne.

Comment puis-je soutenir le projet ?

Un café, si vous le souhaitez. Les soutiens obtiennent un rôle sur Discord et une place dans la Hall of Supporters.

Une année de soutien ajoute un élément supplémentaire : je crée un thème pour vous. Envoyez-moi une palette, une photo, un jeu, ou ce que vous voulez que votre dashboard évoque, et je le transforme en thème Xenon publié avec votre nom. Une demande par mois chacun. Il y a une file d'attente et je la traite dans l'ordre, donc je ne vous promets pas de date, seulement que la vôtre sera traitée et que vous aurez droit à un tour de modifications après la première version. Un thème signifie couleurs, fond, accents, police et l'agencement des widgets existants. Les nouveaux widgets et les nouvelles fonctionnalités sont une autre chose et ne font pas partie de cela.

Les demandes se font dans le canal #theme-requests sur le Discord : ouvrez un fil, dites ce que vous voulez et déposez votre palette ou photo dedans. Le fil est votre place dans la file d'attente, et j'y réponds.

Les contributions gratuites aident tout autant : une étoile sur GitHub, un rapport de bug détaillé, un widget ou un thème partagé dans le catalogue, ou dire à quelqu'un qui a un écran de libre que cela existe.

Toujours bloqué ?

Posez votre question sur le Discord. Les questions qui reviennent régulièrement sont ajoutées à cette page, donc poser une question est vraiment utile.
