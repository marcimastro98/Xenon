Xenon en Linux

Xenon es un panel gratuito para cualquier pantalla que tengas de sobra. En Linux está en beta: el panel es el mismo que en Windows, y esta página muestra lo que todavía cambia y los paquetes que necesita.

El soporte para Linux está en beta. El panel, los widgets, el catálogo y las integraciones son idénticos a Windows. Lo que todavía cambia es la parte que lee y controla el equipo, detallada en la tabla de abajo. Se prueba en GNOME y KDE.

Primer inicio

Abre la app. En el primer inicio te ofrece configurar el panel en una ventana de terminal: descarga el motor, verifica la descarga antes de extraerla y registra un servicio systemd --user para que Xenon arranque cuando inicias sesión. Donde no hay un gestor de servicios de usuario, usa en su lugar una entrada de inicio automático XDG y te lo avisa, incluido que esta alternativa no reinicia Xenon después de un fallo.

El .deb y el .rpm no hacen esto durante la instalación, a propósito: todo lo que crea la configuración pertenece a una sola cuenta de usuario, mientras que un paquete se instala como root para todo el equipo.

El instalador también te dice qué herramientas opcionales te faltan. En Debian y Ubuntu:

sudo apt install nodejs npm unzip           # required
sudo apt install wireplumber                # volume, microphone and the per-app mixer
sudo apt install wmctrl xdotool x11-utils   # the open-applications widget (X11 sessions)
sudo apt install ffmpeg                     # voice input and spoken replies

Si tu escritorio no tiene ningún emulador de terminal, la app no puede mostrarte el instalador: descarga el zip del código fuente desde la página de la versión, extráelo y ejecuta ./INSTALL.sh.

X11 y Wayland

Casi todo el panel funciona igual en los dos. Lo que cambia son las partes que tienen que ver otras ventanas: el widget Aplicaciones abiertas, el selector de apps y la visión de pantalla de la IA usan herramientas de X11 (wmctrl, xdotool), así que en una sesión Wayland Xenon las oculta en lugar de ofrecerlas y luego fallar. Si las necesitas, inicia una sesión X11.

Reportar un problema

Linux está en beta porque la tabla de arriba todavía tiene huecos. Para reportar uno, abre un reporte de error con tu distribución, tu escritorio y el tipo de sesión. Si antes quieres preguntar, escribe en el Discord.
