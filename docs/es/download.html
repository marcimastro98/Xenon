Descargar Xenon

La versión más reciente para cada plataforma, directamente desde GitHub. Gratis, sin cuenta, y a partir de aquí se actualiza sola.

Última actualización: 26 de septiembre de 2026. Todos los enlaces apuntan a la versión más reciente.

Cada archivo de arriba es la versión más reciente, directamente desde GitHub. Todos los archivos de esta versión, incluidas las sumas de verificación, están en la página de la versión.

Configuración inicial

Windows. Ejecuta el instalador. Instala la app, que se abre sola, detecta que todavía falta el motor del panel y te ofrece Complete setup (completar la configuración). Púlsalo una vez: se abre una ventana que instala Node.js, los lectores de sensores y la tarea programada que abre Xenon al iniciar sesión, y te muestra cada paso. Antes de ejecutar nada, la descarga se verifica con la clave de firma del proyecto. Tarda unos minutos y solo se hace una vez.

macOS y Linux. Abre la app que descargaste. En el primer inicio te ofrece configurar el panel en una ventana de terminal, y verifica la descarga antes de extraerla. En Linux el paquete no lo hace por ti, y es a propósito: todo lo que crearía pertenece a una sola cuenta de usuario, y un paquete se instala como root para toda la máquina.

Después, Xenon te pregunta en qué pantalla quieres usarlo. Sirve un monitor libre, una tablet, tu teléfono o un CORSAIR Xeneon Edge; la guía del teléfono explica cómo vincular un teléfono o una tablet en unos treinta segundos.

Avisos de Windows y macOS

Desde la versión 4.11.9 el instalador de Windows está firmado, así que Windows muestra un editor verificado. Aun así, SmartScreen puede avisarte durante un tiempo, porque Microsoft concede la reputación poco a poco: haz clic en Más información y luego en Ejecutar de todas formas. Defender además juzga lo que hace un programa, no solo quién lo firmó, así que todavía puede haber una detección. Las preguntas frecuentes explican cada tipo de aviso y cómo recuperar el archivo; esta página enumera cada proceso que ejecuta Xenon, por si quieres saber exactamente qué se instala.

macOS. La versión para Mac está en beta y no está notarizada, así que macOS bloquea el primer inicio. Abre Ajustes del Sistema, Privacidad y seguridad, desplázate hacia abajo y haz clic en Abrir igualmente junto a Xenon. En macOS 15 y posteriores ya no funciona el truco de Control-clic y Abrir.

Verificar la descarga

Cada versión incluye un archivo SHA256SUMS firmado con la clave Ed25519 del proyecto. Compara el hash de lo que descargaste:

Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256        # Windows, PowerShell
shasum -a 256 Xenon-macOS-universal.dmg                       # macOS
sha256sum Xenon-Linux-x86_64.AppImage                          # Linux

Si coincide con la línea de ese archivo en el SHA256SUMS de la versión, el archivo es idéntico, byte a byte, al que GitHub Actions compiló desde el código fuente público en esa etiqueta. En Windows también puedes hacer clic derecho en el instalador, elegir Propiedades y abrir la pestaña Firmas digitales para ver el editor.

Otras formas de instalar

Desde el código fuente. Descarga el zip del código fuente desde la versión, extráelo y ejecuta INSTALL.bat en Windows, INSTALL.command en macOS o ./INSTALL.sh en Linux. El resultado es el mismo que con el instalador, para quien prefiere leer lo que se ejecuta.

winget. Los manifiestos del paquete están escritos y esperan una versión que pase limpia el análisis de Microsoft; hasta que aparezca en la lista, usa el instalador de arriba. Esta página dirá winget install xenon el día que eso cambie.

Actualizaciones. Xenon busca una versión nueva al iniciarse y se actualiza solo. No necesitas volver aquí para eso.

Qué es Xenon

Un panel gratuito que se ejecuta en tu PC y aparece en cualquier pantalla libre: estadísticas del sistema, controles de música y micrófono, una cuadrícula de teclas al estilo Stream Deck, iluminación y una IA con la que puedes hablar. Sin cuenta, y tus ajustes, archivos y lecturas de sensores se guardan en tu PC. La página de inicio lo muestra.
