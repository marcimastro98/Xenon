PawnIO

If you found PawnIO among your drivers, in an installer prompt or in an anti-cheat message, this page says what it is, which apps use it and what Xenon does with it.

Last updated: 8 November 2026

On this page

What it is PawnIO and WinRing0 Why Xenon installs it Anti-cheat Removing it Questions

What PawnIO is

PawnIO is a signed kernel driver for Windows, made by the developer namazso. Reading a CPU's temperature, a motherboard's fan chip or a memory sensor means talking to hardware registers that ordinary programs are not allowed to touch, so a monitoring app needs a small driver to do it on its behalf.

What sets PawnIO apart is how little it lets through. Instead of handing any program raw access to ports and registers, it runs small modules written in the Pawn language, each one exposing only the operations it was written for, and it loads only modules signed with its maintainer's key. Its source is public at pawnio.eu.

PawnIO and WinRing0

For years most hardware monitors used WinRing0, an old driver that gives any program on the PC raw access to hardware ports and registers. That is the problem: a malicious program can use the same door. Microsoft Defender now detects it as HackTool:Win32/Winring0 and quarantines it, which is why many fan and sensor apps suddenly showed a warning.

LibreHardwareMonitor, Fan Control and OpenRGB, among others, have moved to PawnIO. Xenon has never shipped WinRing0.

Why Xenon installs PawnIO

On Windows, Xenon reads CPU and disk temperatures through LibreHardwareMonitor, and LibreHardwareMonitor needs PawnIO to reach the sensors. The Xenon installer gets PawnIO through winget, Microsoft's package manager, as the package namazso.PawnIO, so the file comes from its own developer and not from us.

Installing a driver needs an administrator prompt. Decline it and Xenon still works, just without temperatures. If an older PawnIO is already on the PC, the installer updates it, because older versions leave some CPU readings empty.

macOS and Linux have no PawnIO: there Xenon reads temperatures from macmon on a Mac and from the kernel's own sensors on Linux.

PawnIO and anti-cheat

PawnIO stays outside games and never reads their memory. Even so, FACEIT's anti-cheat blocked PawnIO versions before 2.1.0. If it names PawnIO.sys, update the driver with winget upgrade namazso.PawnIO or run the Xenon installer again. Not every anti-cheat has been tested: if one complains, say so on the Discord.

How to remove PawnIO

When you uninstall Xenon, it asks before removing PawnIO and keeps it by default, because other monitoring apps on the PC may rely on it. To remove it yourself, run winget uninstall namazso.PawnIO. Apps that read temperatures through it stop showing them until it is installed again.

Questions

Is PawnIO a virus?

No. It is a signed driver from a known developer, its source code is public, and apps like LibreHardwareMonitor and Fan Control install it. Like any kernel driver it has deep access to the system, which is why it only runs signed modules.

Do I need PawnIO?

Only for temperatures in an app that uses it. Xenon works without it; the temperature readings are the only part missing.

Who makes PawnIO?

namazso, an independent developer. It is not made by Xenon, CORSAIR or Microsoft.
