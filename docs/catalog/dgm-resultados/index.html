DGM Results

Widget for the Xenon dashboard, by DanielGarciaMorato

v0.5.4MediaAdded 2026-07-29

DGM Resultados is a responsive football results widget for Xenon. It displays live and recent scores, fixtures, competition details and match status in a clean bilingual interface, with clear loading, empty and unavailable-data states.

What's in it

Finalized the stable 0.5.4 release candidate and completed live QA, stability and export validation.

What a widget does

A widget is a tile that lives on your dashboard grid. It runs sandboxed, with no network access unless its manifest asks for named hosts and you approve them at install.

Copy the code in the catalogGet Xenon

Free. Copy the share code, then paste it into Xenon under Settings → Widgets & sharing → Import. Everything stays on your machine.

How to install it

  1. Open DGM Results in the catalog and press Copy code.
  2. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  3. Xenon shows you what the code contains before anything is applied. Confirm, and DGM Results is on your dashboard.
  4. Do not have Xenon yet? It is free and open source, for Windows, macOS and Linux.
