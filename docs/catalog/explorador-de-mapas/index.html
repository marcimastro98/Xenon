Map Explorer

Widget for the Xenon dashboard, by DanielGarciaMorato

v0.8.1MediaXenon 4.6.0+Added 2026-07-29

DGM Map Explorer is a responsive visual catalogue for opening external video game maps from Xenon. It includes built-in games, persistent custom entries, favorites and recent items, optional session-only images, and safe opening through Xenon Browser with a controlled system-browser fallback.

What's in it

Added persistent custom map entries, optional session-only images, Xenon Browser opening, improved visibility handling and a responsive custom-card layout.
