Aracne

Package for the Xenon dashboard, by xenon

v1.0.0StyleXenon 4.11.0+Added 2026-08-05

A night pack built on a real orb web, and a tile where the web IS the gauge: three wedges, one each for CPU, GPU and RAM, each woven out to its own load, with the spider sitting on the busiest. Plus a scene that hangs you from a line down an avenue, sun setting at the end of it.

What a package does

A package installs several pieces at once — typically a theme, a background and one or more widgets built to look like each other — so the whole dashboard changes in one paste.

Open in the catalog

A supporters' item — unlock it in the catalog, then paste the code into Xenon under Settings → Widgets & sharing → Import.

How to install it

  1. Open Aracne in the catalog and unlock it with your supporter code. One code unlocks it on up to three machines.
  2. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  3. Xenon shows you what the code contains before anything is applied. Confirm, and Aracne is on your dashboard.
  4. This one needs Xenon 4.11.0 or later. An older install refuses the code rather than importing half of it.
