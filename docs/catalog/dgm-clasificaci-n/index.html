DGM league table

Widget for the Xenon dashboard, by DanielGarciaMorato

v0.6.7MediaAdded 2026-07-29

DGM Clasificación is a responsive football standings widget for Xenon. It displays league tables with position, matches played, goal difference and points across supported competitions, with Spanish and English interfaces, multi-provider fallback and clear unavailable-data states.

What's in it

Improved initial loading and Xenon 4.9 compatibility, with safer credential restoration, visibility-aware fetching and a single coordinated startup load.
