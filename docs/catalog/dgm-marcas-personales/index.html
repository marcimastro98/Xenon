DGM Personal Exercise

Widget for the Xenon dashboard, by DanielGarciaMorato

v0.1.0FunAdded 2026-07-29

DGM Personal Records is an editable strength-tracking widget for Xenon. Record exercise names and personal bests in kilograms, update or remove entries and keep the data locally through Xenon’s official storage. It supports Spanish and English and makes no network requests.
