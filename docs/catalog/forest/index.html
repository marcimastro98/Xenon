What a theme does

A theme repaints the whole dashboard: accent, background, surfaces and text, on every screen the dashboard is open on. It changes nothing about which widgets you run.

Copy the code in the catalogGet Xenon

Free. Copy the share code, then paste it into Xenon under Settings → Widgets & sharing → Import. Everything stays on your machine.

How to install it

  1. Open Forest in the catalog and press Copy code.
  2. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  3. Xenon shows you what the code contains before anything is applied. Confirm, and Forest is on your dashboard.
  4. Do not have Xenon yet? It is free and open source, for Windows, macOS and Linux.
