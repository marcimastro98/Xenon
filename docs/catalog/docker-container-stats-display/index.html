What a widget does

A widget is a tile that lives on your dashboard grid. It runs sandboxed, with no network access unless its manifest asks for named hosts and you approve them at install.

Copy the code in the catalogGet Xenon

Free. Copy the share code, then paste it into Xenon under Settings → Widgets & sharing → Import. Everything stays on your machine.

How to install it

  1. Open Docker Container Stats Display in the catalog and press Copy code.
  2. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  3. Xenon shows you what the code contains before anything is applied. Confirm, and Docker Container Stats Display is on your dashboard.
  4. Do not have Xenon yet? It is free and open source, for Windows, macOS and Linux.
