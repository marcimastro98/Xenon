An early-2000s night-city desktop for Xenon. Opaque indigo panels clean up every native widget, the wallpaper drifts like a film exposure, and Ambient pairs a large clock with a live monthly calendar. Accent colours stay user-customizable.

What's in it

1.0.0: semantic dark theme, animated long-exposure city wallpaper and calendar Ambient scene.

What a package does

A package installs several pieces at once — typically a theme, a background and one or more widgets built to look like each other — so the whole dashboard changes in one paste.

How to install it

  1. Open Afterimage in the catalog and press Copy code.
  2. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  3. Xenon shows you what the code contains before anything is applied. Confirm, and Afterimage is on your dashboard.
  4. This one needs Xenon 4.6.0 or later. An older install refuses the code rather than importing half of it.
