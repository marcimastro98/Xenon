Ambra

Package for the Xenon dashboard, by xenon

v1.0.1StyleXenon 4.6.0+Added 2026-07-20

A warm, minimal pack: an amber theme on deep espresso with the animated 'Bruma d'Ambra' background, a redesigned weather widget (temperature-forward, with an essential hourly strip) and an Ambient screensaver showing clock and weather.

What a package does

A package installs several pieces at once — typically a theme, a background and one or more widgets built to look like each other — so the whole dashboard changes in one paste.

This one asks a little more of the machine than most — it is worth knowing before you load it onto a small screen.

Copy the code in the catalogGet Xenon

Free. Copy the share code, then paste it into Xenon under Settings → Widgets & sharing → Import. Everything stays on your machine.

How to install it

  1. Open Ambra in the catalog and press Copy code.
  2. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  3. Xenon shows you what the code contains before anything is applied. Confirm, and Ambra is on your dashboard.
  4. This one needs Xenon 4.6.0 or later. An older install refuses the code rather than importing half of it.
