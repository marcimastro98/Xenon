Lakeside

Theme for Xenon supporters, by Xenon

Become a supporterI have a code

Included for supporters, 5 USD a month. Unlock it in the catalog with your code, then paste it into Xenon under Settings → Widgets & sharing → Import. Or try it free for 7 days, once per PC, with no card.

A painted mountain lake that follows the real world: the season turns with the calendar and the sun and moon cross the sky at your actual sunrise and sunset. The matching Ambient scene ships as its own entry, Lakeside Scene.

What a theme does

A theme repaints all of Xenon: accent, background, surfaces and text, on every screen Xenon is open on. It changes nothing about which widgets you run.

Palette

#e0a05a#070c14#e9eff7

How to install it

  1. Become a supporter, 5 USD a month, and you get a personal code.
  2. Open Lakeside in the catalog and unlock it with your code. One code unlocks it on up to three machines.
  3. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  4. Xenon shows you what the code contains before anything is applied. Confirm, and Lakeside is in Xenon.
  5. This one needs Xenon 4.6.0 or later. An older install refuses the code rather than importing half of it.
