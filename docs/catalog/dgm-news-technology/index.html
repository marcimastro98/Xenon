DGM News Technology

Widget for the Xenon dashboard, by DanielGarciaMorato

v1.2.0MediaXenon 4.6.0+Added 2026-07-29

DGM News Technology delivers balanced technology headlines from Xataka, Hipertextual, Microsiervos, BBC Technology, The Guardian and Ars Technica. It offers Spanish and English interfaces, compact thumbnails, source rotation and clear loading, partial and error states.

What's in it

Updated the runtime for Xenon 4.9+, improving cold start, visibility-aware refresh, thumbnail loading, image toggling and retry behavior.

What a widget does

A widget is a tile that lives on your dashboard grid. It runs sandboxed, with no network access unless its manifest asks for named hosts and you approve them at install.

Copy the code in the catalogGet Xenon

Free. Copy the share code, then paste it into Xenon under Settings → Widgets & sharing → Import. Everything stays on your machine.

How to install it

  1. Open DGM News Technology in the catalog and press Copy code.
  2. In Xenon, open Settings → Widgets & sharing → Import and paste the code.
  3. Xenon shows you what the code contains before anything is applied. Confirm, and DGM News Technology is on your dashboard.
  4. This one needs Xenon 4.6.0 or later. An older install refuses the code rather than importing half of it.
