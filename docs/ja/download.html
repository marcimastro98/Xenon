Xenon のダウンロード

各プラットフォーム向けの最新リリースを GitHub から直接ダウンロードできます。無料でアカウントも不要。インストール後は自動で更新されます。

最終更新: 2026年9月26日。すべてのリンクは最新リリースを指しています。

初回セットアップ

Windows：インストーラーを実行します。アプリがインストールされて自動で開き、ダッシュボードのエンジンがまだないことを確認すると Complete setup（セットアップを完了）を表示します。これを一度押すとウィンドウが開き、Node.js、センサーの読み取り機能、サインイン時に Xenon を起動するタスクがインストールされます。各ステップはその場で表示されます。何かを実行する前に、ダウンロードはプロジェクトの署名鍵で検証されます。数分で終わり、必要なのは一度だけです。

macOS と Linux：ダウンロードしたアプリを開きます。初回起動時に、ターミナルのウィンドウでダッシュボードをセットアップするよう提案され、展開の前にダウンロードを検証します。Linux でパッケージがこれを代わりに行わないのは意図的です。作成されるものはすべて1つのユーザーアカウントに属しますが、パッケージは root としてマシン全体にインストールされるからです。

次に、Xenon をどの画面で使うかを選びます。余っているモニター、タブレット、スマートフォン、CORSAIR Xeneon Edge のどれでも使えます。スマートフォンやタブレットを約30秒でペアリングする方法はスマートフォンのガイドで説明しています。

Windows と macOS の警告

バージョン 4.11.9 から Windows のインストーラーには署名があり、Windows には確認済みの発行元が表示されます。それでも Microsoft は評価を時間をかけて付与するため、しばらくは SmartScreen が警告することがあります。詳細情報 をクリックし、実行 を押してください。また Defender は署名者だけでなくプログラムの動作も判断するため、検出される可能性は残ります。FAQ では警告の種類ごとに説明し、ファイルを取り戻す方法も載せています。何がインストールされるのかを正確に知りたい方には、Xenon が実行するすべてのプロセスを一覧にしたページがあります。

macOS：Mac 版はベータで、公証（notarize）されていないため、初回起動は macOS に拒否されます。システム設定 → プライバシーとセキュリティ を開き、下にスクロールして Xenon の横にある このまま開く をクリックしてください。macOS 15 以降では、Control キーを押しながらクリックして開く方法は使えなくなりました。

ダウンロードの検証

各リリースには、プロジェクトの Ed25519 鍵で署名された SHA256SUMS ファイルが含まれています。ダウンロードしたファイルのハッシュを比べてください。

Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256        # Windows, PowerShell
shasum -a 256 Xenon-macOS-universal.dmg                       # macOS
sha256sum Xenon-Linux-x86_64.AppImage                          # Linux

リリースの SHA256SUMS にあるそのファイルの行と一致すれば、そのファイルは GitHub Actions がそのタグの公開ソースからビルドしたものとバイト単位で同一です。Windows では、インストーラーを右クリックして プロパティ を選び、デジタル署名 タブを開くと発行元を確認できます。

その他のインストール方法

ソースから：リリースからソースコードの zip をダウンロードして展開し、Windows では INSTALL.bat、macOS では INSTALL.command、Linux では ./INSTALL.sh を実行します。結果はインストーラーと同じで、実行される内容を自分で読みたい方向けです。

winget：パッケージのマニフェストは用意できていて、Microsoft 側のスキャンを問題なく通過するリリースを待っている状態です。掲載されるまでは、上のインストーラーを使ってください。掲載された日には、このページに winget install xenon と書きます。

アップデート：Xenon は起動時に新しいリリースを確認し、自動で更新します。そのためにこのページへ戻ってくる必要はありません。

Xenon とは

PC で動き、余っている画面に表示できる無料のダッシュボードです。システム情報、メディアとマイクの操作、Stream Deck のようなキーのグリッド、ライティング、話しかけられる AI を備えています。アカウントは不要で、設定、ファイル、センサーの値は PC に保存されます。ホームページで実際の画面を見られます。
