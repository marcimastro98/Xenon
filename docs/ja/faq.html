Xenon について

Xenon とは?

PC のウィジェットをどの画面にも置ける無料アプリです。温度と負荷、FPS、音楽、カレンダー、天気、メモを、デスクトップ、ゲームの上、予備のモニター、タブレット、スマートフォンに表示できます。PC を操作するタッチキーの Deck、インスタントリプレイ付きの画面録画、話しかけられるアシスタントの Bit、テーマとウィジェットのストアも備えています。Windows で動作し、macOS と Linux はベータです。

Xeneon Edge や CORSAIR の PC は必要?

いいえ。Xenon は CORSAIR Xeneon Edge から始まりましたが、どの PC でも動き、CORSAIR のハードウェアやソフトウェアは不要です。Edge では iCUE があってもなくても使えます。iCUE が必要なのは、iCUE ウィジェットの中に Xenon を表示するときと、CORSAIR の RGB デバイスを操作するときだけです。詳しくはXeneon Edge ガイドをご覧ください。

どの画面で使える?

今お持ちの画面で使えます。モニターが 1 台なら、ウィジェットはデスクトップやゲームの上に置け、場所は一つずつ選べます。予備のモニターやタッチスクリーンには、ウィジェットのページをまるごと表示できます。最初の起動時に、どの画面を使うかをアプリが尋ねます。タブレットやスマートフォンも、ベータとして自宅の Wi-Fi 経由で使えます。同じレイアウト、ウィジェット、テーマが表示され、キーは実際に PC で動きます。やり方は1 画面ガイド、スマートフォンガイド、タブレットガイドで説明しています。

Mac や Linux でも使える?

はい、ベータです。macOS 11 以降（Apple Silicon と Intel で同じダウンロード）と 64 ビット Linux で動き、Windows 10 と 11 にも対応しています。ウィジェットとストアは 3 つとも同じです。macOS と Linux にはまだないセンサーやシステム操作があり、データのないウィジェットは読み込み続けずにその旨を表示します。動く機能は Mac と Linux のページにまとめています。

Mac での初回起動: アプリはまだ公証を受けていないため、macOS は初回の起動をブロックします。macOS 15 以降では システム設定 → プライバシーとセキュリティ を開き、下までスクロールして このまま開く をクリックします。macOS 11〜14 ではアプリを右クリックして 開く を選び、もう一度 開く を押します。バージョンごとに 1 回だけです。

料金とサポーター

無料? サポーターには何がある?

アプリは無料で、広告もアカウントもありません。Buy Me a Coffee のサポーターには、カタログの毎月の配布、「歌詞」と「開発者向けクリーンアップ」のウィジェット、Maker のエクスポート、Discord のロール、Hall of Supporters への掲載があります。料金は月 5 USD か年 50 USD、または一回払いで、5 USD で 1 か月、25 USD で 5 か月、50 USD で 12 か月です。5 USD 未満のお支払いは単なるチップ扱いで、何も解放されず、スパークも付きません。コードはメールで届き、設定 → Xenonを応援 に入力します。どのプランにも毎月 300 スパーク（Xenon のクレジット）が付きます。使わなかった分は繰り越されません。

サポートが終わっても、アンロックしたものとそのアップデート、購入したスパークは残り、「歌詞」と「開発者向けクリーンアップ」も使えます。Maker のエクスポートと毎月のスパークはなくなります。1 年間のサポートでは、あなたのパレットや写真からあなた専用のテーマを作り、あなたの名前で公開します。

サポーターパスを先に試せる?

はい。メールアドレスで申し込むと、コードがメールで届きます。PC ごとに 1 回、カードなしで 7 日間無料で、サポーターの配布と「歌詞」が開きます。スパークと「開発者向けクリーンアップ」は体験に含まれません。新しい配布は通常、公開から 30 日後に対象になり、限定の配布には専用のコードが必要です。体験が終わると、試したものは PC から外れ、前のテーマに戻り、ウィジェットは元の場所に残ります。

スパークとは?

スパークは Xenon のクレジットで、1 スパークは 1 米セントです。自分の API キーなしで Bit を使うときと、スパークで販売されているストアのアイテムに使えます。サポートの毎月に 300 スパークが含まれ、先に使われます。毎月初めにリセットされ、繰り越されません。追加の購入にサポーターである必要はありません。Xenon 5.0.0 からはストアの「スパーク」でパックを購入でき、500 スパークが 5 USD、1050 が 10 USD、2200 が 20 USD です。購入したスパークに期限はありません。サポーターでない場合は、最初のパックと一緒にスパークコード（XC-…）がメールで届きます。サポーターコードと同じ欄に入力してください。

スパークで購入したアイテムは最大 3 台の PC で使え、公開されるアップデートもすべて含まれます。再インストールに費用はかかりません。限定エディションがスパークで販売されることはありません。

返金はできる?

販売者は Xenon で、支払いは Buy Me a Coffee が受け取ります。支払いから 14 日以内なら、メンバーシップの支払いやスパークのパックを返金できます。support@xenon-app.com までご連絡ください。返金は Buy Me a Coffee で行います。返金するとパックと、そのスパークで購入したものがなくなります。Bit にすでに使ったスパークは残高から差し引かれるため、次のパックまで残高がマイナスになることがあります。

スパークで購入した Store のアイテムはすぐに提供されます。購入前にそれを求めるチェックボックスにチェックを入れ、提供が始まると撤回権はなくなります。

使い方

ゲームが重くならない?

遅くならないように作られています。ゲームの実行中はゲームモードがアニメーション背景を消してアニメーション効果を止め、特に重いウィジェット（Browser と Second screen の配信）は終わるまで停止します。ディスクのスキャンなど、Xenon 自身のバックグラウンド処理も待機します。これらや Home Assistant のようなライブのウィジェットは、画面に表示されている間だけ接続します。

Windows では、ゲーム中に別の画面の Xenon に触れても問題ありません。カーソルはすぐゲームのモニターに戻り、タップでゲームのフォーカスが外れることもありません。

アンチチートで BAN される?

Xenon はゲームにコードを注入せず、ゲームのプロセスをフックすることもありません。自分のウィンドウを上に描き、PresentMon でシステムからフレームタイムを読むだけなので、ゲームの中にアンチチートが検出するものはありません。

ドライバーレベルで動くのは温度を読む PawnIO だけで、これもゲームの外で動きます。FACEIT のアンチチートは 2.1.0 より前の PawnIO をブロックしていました。PawnIO.sys と表示されたら、winget upgrade namazso.PawnIO を実行するか、Xenon のインストーラーをもう一度実行してください。すべてのアンチチートを試したわけではないので、問題が出たら Discord で教えてください。

温度やゲームの FPS は表示できる?

はい。Windows ではインストーラーが温度の読み取りを設定し（管理者の確認が一度必要です）、PresentMon が実行中のゲームの実際のフレームレートを、フルスクリーンのタイトルも含めて取得します。ない場合は 設定 → パフォーマンス → ゲームモード からインストールできます。FPS オーバーレイはボーダーレスまたはウィンドウ表示のゲームの上に数値を表示します。macOS の温度と GPU 負荷は macmon（brew install vladkens/tap/macmon）から取得します。Linux のゲーム内 FPS には MangoHud が必要で、ゲームをそれ経由で起動します。

ゲームを録画できる?

はい。インスタントリプレイが直近の数分を保持するので、起きた後でその場面を保存できます。レコーダーは画面全体か 1 つのウィンドウを録画します。スクリーンショットや画面の文字の読み取りもできます。すべて PC に保存され、アップロードはなく、アカウントも不要です。Windows では無料で、macOS と Linux はベータです。やり方は録画ガイドをご覧ください。

Bit とは? API キーは必要?

Bit は Xenon の中のアシスタントです。文字で入力するか「Hey Bit」と話しかけると、質問に答え、PC を操作し、一緒にウィジェットを作ります。始めるのにキーは要りません。新しいインストールでは、最初のメッセージで体験用の 30 スパークが付きます。Bit 専用で 7 日間有効、カードもメールも不要です。その後はスパークを買うか、Gemini、OpenAI、Anthropic の自分のキー、Ollama や OpenAI 互換サーバーのローカルモデル、または自分のサブスクリプションの Claude Code と Codex を使えます。

Stream Deck の代わりになる?

お持ちの画面で同じような役割を果たします。Xeneon Edge、予備のモニター、タブレット、スマートフォンのどれでも使えます。キーでアプリを開く、ショートカットを送る、OBS のシーンを切り替える、Discord をミュートする、Streamer.bot のアクションを実行することができ、操作対象の状態に合わせて光らせることもできます。Stream Deck のハードウェアやプラグインは使いません。すべての操作は Deck ガイドに載っています。

ウィジェットやテーマを追加するには?

ページの + を押すと内蔵ウィジェットを追加できます。デスクトップやゲームの上に置くには、Alt+Shift+X で Xenon メニューを開くか、Bit に頼んでください。さらに増やすには 設定 → ストア を開きます。テーマ、背景、ウィジェット、アンビエントシーン、パックがあり、適用前にプレビューでき、ワンタップでインストールできます。同じものはこのサイトのカタログでも見られます。

自分のウィジェットやテーマを作れる?

はい、コードなしで作れます。ベータの Maker はブラウザーでウィジェットとテーマを作れ、Bit がそこでもアプリでも一緒に作ります。Maker はすべて無料で試せます。プロジェクトの保存と、作ったものの Xenon へのインストールはサポーター向けです。コードを書く場合は、制作ガイドで Widget SDK を説明しています。

Spotify、Home Assistant、RGB ライトに対応している?

はい。どれも任意で、接続するまでオフです。

  • Spotify: 再生中の曲は「再生」ウィジェットに表示されます。設定でアカウントをリンクすると、シーク、いいね、シャッフル、プレイリストが Deck からも使えます（再生の操作には Spotify Premium が必要です）。
  • Home Assistant: 設定 → スマートホーム でアドレスと長期アクセストークンを入れて接続すると、ウィジェットや Deck のキーからライト、センサー、シーンを操作できます。
  • RGB: iCUE 経由の CORSAIR デバイス、ネットワーク経由の WLED、OpenRGB、Philips Hue、Nanoleaf、Govee、LIFX、Yeelight、Windows では USB 経由の GIGABYTE と AORUS のマザーボードに対応します。
レイアウトを保存したり別の PC に移したりできる?

はい。設定 → 一般 → バックアップ → バックアップを書き出す で、レイアウト、Deck、カレンダー、タスク、タイマー、メモ、設定、Bit のメモリ、カスタム背景を 1 つのファイルに保存します。別の PC では バックアップを読み込む ですべて戻せます。パスワード、トークン、API キーはファイルに入らないので、連携はもう一度接続を求めます。コミュニティのウィジェットは一覧に出るので、コードから再インストールできます。非公開のカレンダーリンクと Deck の Webhook は含まれるため、ファイルは他人に渡さないでください。

困ったとき

Windows が Xenon をウイルス扱いする。安全?

誤検知です。Windows インストーラーはバージョン 4.11.9 から署名されていますが、Microsoft は新しいファイルへの信頼を時間をかけて積み上げるため、出たばかりのリリースには Defender、SmartScreen、ブラウザーが警告を出すことがあります。ファイルは自分で確認できます。各リリースには署名付きの SHA256SUMS リストがあり、照合するためのコマンドはダウンロードページにあります。Microsoft Store からもインストールできます。

  • Defender に削除された: Windows セキュリティ → ウイルスと脅威の防止 → 保護の履歴 を開き、Xenon の項目を選んで 復元 を選びます。そのあと %LOCALAPPDATA%\Xenon と %LOCALAPPDATA%\Programs\Xenon を 除外 に追加します。
  • ブラウザーがダウンロードを止める: Ctrl+J でダウンロード一覧を開き、保存 を選びます。
  • 起動せず、何の通知もない: Windows 11 では多くの場合、Windows セキュリティ → アプリとブラウザーの制御 にある Smart App Control が原因です。まずはオンのまま最新リリースを試してください。更新済みの Windows なら後でオンに戻せますが、古い Windows では PC をリセットするか再インストールするまでオフのままです。

警告を無視してよいのは、公式のReleases ページから入手し、ハッシュを確認したファイルだけです。

Xenon が勝手に閉じる

タスクトレイのメニューを開き、Open crash log を選びます。最後の行が PANIC なら、アプリ自体のエラーです。その行を Discord かバグ報告に貼ってください。正確な箇所がわかります。最後の行が launched でその後に何もなければ、外部の何かが閉じています。ほとんどはウイルス対策ソフトです。保護の履歴 でその時刻の項目を探して復元し、上の質問にある 2 つの除外を追加してください。

CPU の温度が表示されない

Windows では、インストーラーをもう一度実行して管理者の確認を許可してください。温度の読み取りには LibreHardwareMonitor と PawnIO が必要で、これらにはドライバーレベルの部分が含まれるため確認が出ます。拒否しても温度以外はすべて動きます。macOS では macmon をインストールしてください。センサーをまったく公開しないノート PC やマザーボードもあり、その場合ウィジェットは作り物の数値を出さず、その旨を表示します。

更新やアンインストールの方法は?

Xenon は自動で更新されます。新しいリリースが出ると確認があり、ワンタップでダウンロードし、インストール前に署名を検証し、失敗したら前のバージョンに戻します。設定、レイアウト、メモは残ります。

Windows でアンインストールするには、設定 → アプリ → インストールされているアプリ を開き、Xenon を探して アンインストール を押します。macOS では ~/Library/Application Support/Xenon の UNINSTALL.command をダブルクリックし、Linux では Xenon のフォルダーで ./UNINSTALL.sh を実行します。どちらもアプリ、スタートアップの項目、データを削除します。設定、レイアウト、メモを残すには UNINSTALL.sh --keep-data を実行してください。

プライバシーとサポート

データはどこかに送られる? アカウントは必要?

設定、メモ、タスク、予定、Deck、ファイルのインデックスは PC に残り、アプリは操作の記録を取りません。匿名のカウンターが 3 つあり、識別子はありません。アップデートの確認と一緒に送るバージョン、システム、インストールのおおよその古さ、ストアからインストールしたときに作品の数に足す 1、そして 1 日 1 回送る、各機能の実行回数と失敗回数です。どれも、検索、入力、制作の内容は含みません。新しいインストールでは最初からオンで、設定 → 一般 → アップデート でそれぞれオフにできます。

アプリは、アップデートの確認、短いお知らせの取得、天気や Spotify など自分で有効にしたサービスのためにもオンラインになります。Bit への質問は、選んだ AI サービスに送られます。ローカルモデルなら PC から出ません。送信先と内容はプライバシーのページにすべて載っています。

Xenon のアカウントはありません。コードを入力するのは、サポートするとき、スパークを買うとき、体験を申し込むとき（メールアドレスが必要です）だけで、連携はそれぞれのログインを使います。

どこで助けてもらえる?

Discord で質問するのがいちばん早く、よく出る質問はこのページに追加されます。再現できるバグは、システム、行ったこと、起きたことを書いて GitHub の Issue を開いてください。

個人利用は、仕事で使う PC でも無料です。Xenon を販売したり商用製品に組み込んだりするには、事前に書面での許可が必要です。support@xenon-app.com までご連絡ください。
