インストールの前に

CORSAIR Xeneon Edge は必要ですか

いいえ。Xenon はあの画面を念頭に作られましたが、Edge は動作する画面のひとつであって製品そのものではありません。余っているモニター、机に立てかけた古いタブレット、タッチスクリーン、メイン画面のウィンドウ、ポケットのスマホでも同じように動きます。空いている画面がまったくないなら スマホを使ってください。自宅の Wi-Fi で30秒ほど、しかも得られるのはリモコンではなく本物のダッシュボードです。

本当に無料ですか

はい。有料版も、体験版も、アカウントも、広告もなく、存在しない上位プランのために機能を出し惜しみすることもありません。ライセンスは独自の非商用ライセンスです。個人利用は無料で、ソースを読み、実行し、改変できます。書面での許可が必要なのは、販売すること、商用製品に組み込むこと、自分の作品として再配布すること、Xenon の名前を別の製品に使うことです。

お礼を伝えたいなら サポーター枠 があります。一か月 5、五か月 25、一年 50。カタログの追加テーマとウィジェット、Discord のロール、このサイトへの名前掲載が開きます。アプリ自体は何も出し惜しみしません。これは感謝のしるしであって、ライセンスではありません。

どの OS で動きますか

Windows 10 と 11（64ビット）、macOS 11 以降（Apple Silicon と Intel 共通のユニバーサル版がひとつ）、Linux（64ビット）です。

macOS と Linux はベータです。 ダッシュボード、ウィジェット、ストア、各種連携は三つとも同じで、まだ違うのはマシン自体を読み取る層です。プラットフォーム表に、どの機能がどこで動くかが正確に書いてあります。

CORSAIR の PC や iCUE は必要ですか

いいえ。Xenon はどの PC でも動き、CORSAIR のハードもソフトも必要ありません。iCUE が関係するのは任意の二つだけです。ダッシュボードを iCUE の iFrame ウィジェットの中に置きたい場合と、CORSAIR の RGB 機器を制御する場合です。それ以外はすべて無関係です。

Windows がウイルスだと言うとき

要点

バージョン 4.11.9 から Windows 用インストーラーには署名があり、Windows に確認済みの発行元が表示されます。それでもしばらくは警告が出ることがあります。Microsoft は評価を時間をかけて付与し、Defender はプログラムの動作も判断するためです。そのため三つの別々のシステムから最大三つの警告が出て、対処もそれぞれ違います。どれも本物のマルウェアを検出したわけではありませんし、私の言葉を信じる必要もありません。すべてのリリースには自分で確認できるハッシュが付いています。

Windows Defender が Xenon を検出して、消えてしまいました

誤検出です。そして私のところに届く相談で最も多いものでもあります。検出名はたいてい !cl で終わります。これは既知のマルウェアと定義ファイルが一致したのではなく、Defender のクラウド機械学習モデルが下した判定だという意味です。そのモデルにとって新しいリリースは毎回新しいファイルなので、バージョンによって出たり出なかったりします。

インストールを元に戻すには:

  1. Windows セキュリティ → ウイルスと脅威の防止 → 保護の履歴 を開き、Xenon の項目を探して 操作 → 復元 を選びます。
  2. 再発しないように除外を追加します。設定の管理 → 除外 → 除外の追加 → フォルダー で %LOCALAPPDATA%\Xenon を追加してください。
ブラウザーがダウンロードを拒否する、またはウイルスがあると言います

原因は同じで、止めている相手が違います。ブラウザー自身の評価チェックで、Chrome なら Google セーフ ブラウジング、Edge なら SmartScreen です。Ctrl+J でダウンロード一覧を開き、中止されたファイルで 保持する、または それでも保持する を選んでください。その後インストーラーの実行時に SmartScreen が警告したら、詳細情報 をクリックして 実行 を選びます。

ただ信じるのではなく、安全だとどう確かめますか

ご自身で確かめてください。ぜひそうしてほしいです。すべてのリリースには、プロジェクトの鍵で署名された SHA256SUMS ファイルが付いています。PowerShell で:

Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256

結果を、そのリリースの SHA256SUMS にある Xenon-Setup-x64.exe の行と比べてください。一致すれば、そのファイルは GitHub Actions がそのタグの公開ソースからビルドしたものとバイト単位で同一で、そのソースは1行残らず GitHub で読めます。VirusTotal にアップロードしても構いません。数個のエンジンだけが反応して残りがクリーンなら、それはマルウェアの姿ではなく評価不足の姿です。

署名も確認できます。ファイルを右クリックして プロパティ を選び、デジタル署名 タブを開くと発行元の名前が表示されます。4.11.9 以降のリリースには署名があり、それより前のリリースにはないので、その場合はハッシュで確認してください。

警告を無視してよいのは、公式の Releases ページ から入手し、ハッシュを確認したファイルだけです。 警告を無視させようとするのは本物のマルウェアがすることであり、その二つを見分けてくれるのがハッシュです。

Xenon がまったく起動せず、Defender は何も言っていません

Windows 11 ではたいてい スマート アプリ コントロール です。ウイルス対策とは別の仕組みです。Windows セキュリティ → アプリとブラウザーの制御 → スマート アプリ コントロール を確認してください。

まだ信頼していないアプリはすべてブロックし、その判断はウイルス対策が関与する前に行われます。ですから上の除外設定は効きませんし、オンのままアプリを1つだけ許可する方法もありません。Windows 11 をクリーンインストールしたときだけ自動で有効になるため、入れ直したばかりの PC には現れ、アップグレードした PC には現れません。選べるのは、Windows が使い方を見て有効のままにするか自分で判断する 評価 モードと、オフ の二つです。

変更する前に知っておいてください。スマート アプリ コントロールをオフにすると元に戻せません。 PC をリセットまたは再インストールしない限り、Windows は再び有効にさせてくれません。これは Microsoft の設計であり、Xenon 側で回避できるものではありません。バージョン 4.11.9 から Xenon 自身のファイルには署名があり、Microsoft によれば、スマート アプリ コントロールは自分で判定できないとき、有効な署名のあるアプリの実行を許可します。まずはオンのまま最新のリリースを試してください。それでも Xenon がブロックされ、オンのままにしたい場合、正直な答えは、その PC では Xenon を動かせない、です。

使っている途中で Xenon がひとりでに閉じます

トレイメニューから Open crash log を選んでください。Xenon は起動するたび、停止するたびに 1 行ずつ記録していて、考えられる 2 つの原因はその行で見分けられます。

最後の行が PANIC の場合。 アプリ自身が落ちたということで、その行にどのスレッドのどのソース行で落ちたかが書かれています。Discord か バグ報告にそのまま貼ってください。その 1 行があれば大抵すぐ直せます。

最後の行が launched で、その後に何もない場合。 アプリの側が止まると決めたわけではなく、外からプロセスが終了させられています。Windows ではほぼ必ず、実行中の xenon-native.exe をウイルス対策が隔離したケースです。Windows セキュリティ → ウイルスと脅威の防止 → 保護の履歴にウィンドウが消えた時刻と一致する項目がないか確認し、復元したうえで、%LOCALAPPDATA%\Xenon と %LOCALAPPDATA%\Programs\Xenon の両方をフォルダー除外に追加してください。Xenon はこの 2 か所に分かれており、前者だけを除外すると、一日中動いている側が同じ検出にさらされたままになります。

Xenon には署名がありますか

はい。Windows ではバージョン 4.11.9（2026年9月20日）から署名されています。インストーラー、その中のアプリ、ヘルパーのすべてに Authenticode 署名があり、Windows には「不明な発行元」ではなく確認済みの発行元が表示されます。

署名が証明するのは、誰がファイルを公開したか、そしてその後誰も変更していないかです。初日から評価をもたらすものではありません。SmartScreen はファイルがダウンロードされるにつれて時間をかけて評価を付与し、Defender はプログラムの動作も判断します。そのためしばらくは警告が出ることがあり、そのとき何よりも効くことが一つあります。Defender がダウンロードを検出したら、microsoft.com/wdsi/filesubmission で誤検出として報告してください。Home customer を選び、Incorrectly detected as malware を選ぶだけです。2分で終わり、実ユーザーからの報告は重みがあり、たいてい数日で全員から検出が取り下げられます。

macOS 版はベータで、まだ公証（notarize）されていません。これは Apple の別の手続きで、初回起動の方法は下の macOS の質問で説明しています。

macOS と Linux

macOS が「Apple が確認できないため開けません」と言います

今は想定どおりです。アプリは公証（notarize）されておらず、公証にはこのプロジェクトにはない有料の Apple Developer メンバーシップが必要です。

macOS 15 以降 では システム設定 → プライバシーとセキュリティ を開き、いちばん下までスクロールして Xenon の横の このまま開く を押してください。Apple は以前の右クリックの方法を廃止しました。macOS 11〜14 では、アプリを右クリックして 開く、もう一度 開く で大丈夫です。どちらもバージョンごとに1回だけです。

macOS でディスクウィジェットのゴミ箱が 0 B と表示されます

ゴミ箱と ~/Library/Caches の大半は フルディスクアクセス の内側にあり、macOS はこの権限をアプリごとに与えます。権限がないと、それらのフォルダーは拒否されたのではなく空に見えるため、エラーも出ないままディスクの内訳が少なく集計されます。

システム設定 → プライバシーとセキュリティ → フルディスクアクセス を開き、+ を押してアプリケーションから Xenon を選び、スイッチがオンになっていることを確認してから、Xenon を終了して開き直してください。

4.11.3 までは更新のたびにやり直す必要がありましたが、もう不要です。 macOS はこの権限をコード署名に結び付けます。以前の Xenon はアドホック署名だったため、リリースごとに別のアプリに見え、許可が静かに効かなくなっていました。いまの Xenon はリリースをまたいで同じ独自証明書で署名されるので、許可は更新後も残ります。ただし 4.11.3 への更新自体は識別情報が変わるリリースなので、最後に一度だけリセットされます。一覧にあるのに効いていないときは − で削除して追加し直してください。いまは Xenon 自身がこの状態に気づき、ダッシュボードで知らせます。

macOS には何をインストールすればいいですか

必須は Node.js だけで、なければ Xenon が教えてくれます: brew install node。あとは任意で、それぞれ一つの機能を有効にします。

  • vladkens/tap/macmon：温度と GPU 使用率
  • switchaudio-osx：出力デバイスの切り替え
  • ffmpeg：音声入力と読み上げ

Xenon は後で失敗する代わりに、足りないものを先に伝えます。

Linux ではどうインストールしますか

AppImage をダウンロードして実行権限を付けて起動するか、.deb を使ってください。初回起動時に、自分で読んで中断できるターミナルウィンドウでダッシュボードのセットアップを提案し、何かを展開する前にプロジェクトの鍵でダウンロードを検証します。

パッケージがそれを代わりにやらないのは意図的です。インストールが作るものはすべて一人のユーザーアカウントに属しますが、パッケージはマシン全体に対して root として入るからです。アプリ自体が不要なら、Releases からソースの zip を取得して ./INSTALL.sh を実行してください。

必要なのは nodejs npm unzip です。任意のものは機能ごとに wireplumber（音量、マイク、アプリ別ミキサー）、wmctrl と x11-utils（アプリスイッチャー）、playerctl（再生情報の即時更新）、ffmpeg（音声）です。npm run doctor を実行すると、何が足りず、それぞれ何を有効にするかを教えてくれます。

macOS と Linux のベータとは実際どういう意味ですか

ダッシュボードは同じ製品です。ウィジェットもストアもテーマも連携もスマホからのアクセスも同じです。違うのはマシンを読み取る層で、一部のセンサーやシステム操作がまだない、あるいは挙動が異なります。

大事なのは、動くふりをするものが何もないことです。そのプラットフォームにデータ源がないタイルは、いつまでも読み込むのではなく一行でそう伝え、そのプラットフォームで実行できない Deck キーは、提示してから失敗するのではなく最初から隠されます。

インストール、起動、更新

インストーラーは実際に何をしますか

Windows では、アプリをインストールし、ダッシュボードのエンジンを %LOCALAPPDATA%\Xenon の下に入れ、Node.js がなければ入れ、ログイン時にダッシュボードが起動するタスクを登録します。任意の部品も取得します。温度用の FFmpeg、LibreHardwareMonitor、PawnIO と、ゲーム中の実 FPS 用の PresentMon です。

隠れて動くものはありません。 セットアップ自体はアプリを入れて開くだけで、ダッシュボード側はその後アプリが提案し、見て中断できるコンソールウィンドウで実行されます。以前のバージョンはこれをバックグラウンドで黙って行っていましたが、それこそ未署名のインストーラーが隔離される典型的な形なので廃止しました。

PC の起動と一緒に立ち上がりますか。止められますか

はい、ログイン時に起動するので、席に着いたときにはダッシュボードがもう動いています。システムサービスではなくユーザーのセッション内で動くのは意図的で、セッションの外にはオーディオデバイス一覧もウィンドウ一覧もマイクもなく、アプリを開く手段もないため、機能の半分が静かに動かなくなるからです。

Xenon を削除するには、Windows なら UNINSTALL.bat、macOS なら UNINSTALL.command、Linux なら ./UNINSTALL.sh を実行してください。

どうやって更新しますか

Xenon は自分で更新します。新しいリリースが出るとダッシュボードに通知が出て、一度タップすればダウンロードし、何かを展開する前に署名を検証し、エンジン、続いてアプリの順に入れます。途中で失敗したら自動的に前のバージョンに戻します。設定、レイアウト、メモは常に保持され、古いバージョンの残骸は片付けられます。

アンインストールはどうしますか

Windows では UNINSTALL.bat、macOS では UNINSTALL.command、Linux では ./UNINSTALL.sh を実行します。三つとも一度確認したうえで、アプリ、自動起動、ローカルサーバー、データ、インストールフォルダーまで Xenon を完全に削除します。設定、レイアウト、メモを残したい場合は --keep-data（Windows では -KeepData）を付けてください。データフォルダーを削除すると、ストアの評価が一度だけ数えられるように使うランダムな id を含め、Xenon が保存したものはすべて消えます。

なぜ管理者権限を求めるのですか

インストール時に一度だけ、二つの理由でです。CPU とディスクの温度読み取りの準備（ドライバーレベルの部品が必要な LibreHardwareMonitor と PawnIO）と、起動タスクの登録です。断っても他はすべて動き、温度が出ないだけです。その後 Xenon が管理者権限で動くことはありません。

ポート 3030 はすでに使用中と表示されます

ほとんどの場合、ダッシュボードがすでに動いているというだけで、実はそれが望んでいた状態です。http://127.0.0.1:3030/ を開けばそこにあります。別のソフトがそのポートを使っているなら、server/server.js で変更してください。

Xenon を使う

本当にスマホを画面として使えますか

はい。しかもリモコンではなくあなたのダッシュボードです。レイアウトもウィジェットもテーマも同じで、Deck キーは実際に PC 上で実行されます。アカウントもクラウドもインストールも不要で、自宅の Wi-Fi なら何も家庭内ネットワークの外に出ません。30秒ほどで終わります。スマホ向けガイド に、自宅で使う方法と外から使う方法の両方があります。

アプリを使わないとだめですか

いいえ。アプリはダッシュボードを包むウィンドウで、ダッシュボード自体はローカルの Web ページです。どのブラウザーでも、どのモニターでも http://127.0.0.1:3030/ を開けば使えます。タッチスクリーンではゲーム中も安全なタッチとトレイアイコンが付くのでアプリが便利です。iCUE の中なら、同じアドレスを指す iFrame ウィジェットでも動きます。

その場合は iCUE で Web ページ（HTML）ウィジェットを追加し、次を貼り付けてください: <iframe src='http://127.0.0.1:3030/' width='100%' height='100%' frameborder='0'></iframe>

AI を使うのに API キーは必要ですか

クラウドのプロバイダーを使う場合だけで、Gemini のキーは無料で作れます。Xenon の他の機能はキーなしで動きます。

完全にローカルで動かす選択肢もあります。会話は Ollama、音声は Whisper を設定から必要に応じて導入でき、何も PC の外に出ません。クラウドのプロバイダーを選んだ場合、プロンプトはそのプロバイダーの規約のもとで送られ、Xenon が自分で選んでいないモデルに何かを送ることは決してありません。

CPU の温度が表示されません

インストーラーをもう一度実行し、管理者の確認を承認してください。そうすれば LibreHardwareMonitor と PawnIO を入れ、権限付きの起動タスクを登録できます。ノート PC やマザーボードによってはセンサーがまったく公開されておらず、その場合は作り話の数値を出す代わりに、タイルがそう表示します。

自分でウィジェットやテーマを作れますか

はい、しかも大半はコードなしでできます。テーマ、レイアウト、アンビエントシーン、Deck プロファイルはアプリの中で作り、誰でも取り込めるコードとして共有します。ウィジェットはサンドボックスで動く小さな HTML・CSS・JavaScript のパッケージで、センサーや操作のためのブリッジが文書化されています。

クリエイターガイド が出発点で、カタログ には他の人が作ったものがあります。

RGB ライティングも制御しますか

はい。CORSAIR 機器は iCUE 経由で、さらに WLED、OpenRGB、Philips Hue、Nanoleaf はネットワーク越しに直接制御します。温度や再生中の曲に反応させることも、選んだ色のまま留めることもできます。任意の機能で、設定するまではオフのままです。

プライバシーと信頼

Xenon は私のデータをどこかに送りますか

設定、メモ、タスク、予定、デッキ、検索した語句、ファイルの索引は PC に残ります。アプリの中に分析 SDK もクラッシュレポーターも行動追跡もありません。

とはいえ完全なオフラインでもなく、そう言い切るほうが不誠実です。更新を確認しますし、天気や音楽 API といった機能をオンにすればそのサービスに接続します。プライバシーのページ に、アプリが行いうる通信、そのきっかけ、送る内容が漏れなく書いてあります。

アカウントは必要ですか

いいえ。Xenon のアカウントもログインもなく、あなたと自分のダッシュボードの間に私のサーバーが入ることもありません。Spotify や Twitch のように自分で設定する連携は、それぞれの資格情報を使い、設定するまでは何もしません。

ライセンス、費用、サポート

仕事で、あるいは自分の製品の中で使えますか

個人利用は無料で、たまたま仕事に使っている PC でも構いません。販売すること、商用製品に組み込むこと、自分の作品として再配布すること、Xenon の名前を別のものに使うことには、事前の書面での許可が必要です。

考えている用途があれば聞いてください。メール でも Discord でも構いません。条件付きで「はい」になることは多いです。

どこで助けを求められますか

Discord がいちばん早く、実際に多くの問題はそこで切り分けられています。再現するものなら、環境と、何をして何が起きたかを書いた GitHub の issue がいちばん助かります。どちらも同じ一人が読んでいます。

プロジェクトを応援するには

気が向いたら コーヒー を。支援してくれた方には Discord のロールと Hall of Supporters の席があります。

一年分のご支援には、もうひとつあります。テーマをお作りします。パレット、写真、ゲームなど、ダッシュボードにこうあってほしいというものを送ってください。それを Xenon のテーマにして、あなたの名前を添えて公開します。リクエストはひとりにつき月にひとつまでです。順番待ちの列があり順に進めるので、日付は約束しません。約束するのは、順番が来たら必ず作ることと、最初のバージョンのあとに一度修正できることです。テーマとは、色、背景、アクセント、フォント、そして既存のウィジェットの配置のことです。新しいウィジェットや新機能は別の話で、含まれません。

リクエストは Discord の #theme-requests チャンネルで受け付けます。スレッドを立てて、どんなテーマがほしいかを書き、パレットや写真を貼ってください。そのスレッドが順番待ちの位置であり、返事もそこでします。

無料でできることも同じくらい助かります。GitHub のスター、具体的なバグ報告、カタログ で共有したウィジェットやテーマ、あるいは画面が余っている人にこれを教えてあげることなどです。
