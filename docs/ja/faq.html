Xenon について

Xenon とは?

PC の横の画面のための無料ダッシュボードです。システム (CPU、GPU、温度、ネットワーク)、再生中の曲、カレンダー、天気、メモを表示し、Deck も使えます。Deck はタップするだけでアプリを開いたり、音楽を操作したり、PC のショートカットを実行したりできるキーです。ウィジェットとテーマで自由に組み立てられます。Windows で動作し、macOS と Linux はベータです。

Xeneon Edge や CORSAIR の PC は必要?

いいえ。Xenon は CORSAIR Xeneon Edge を想定して作られましたが、どの PC でも動き、CORSAIR のハードもソフトも必要ありません。iCUE が関係するのは、ダッシュボードを iCUE のウィジェットの中に置きたいときと、CORSAIR の RGB デバイスを制御したいときだけです。

どの画面で使える?

PC がウィンドウを表示できる画面ならどれでも使えます。予備のモニター、タッチスクリーン、メイン画面のウィンドウなどです。アプリは初回起動時に、どの画面で開くかを尋ねます。自宅の Wi-Fi を使えばタブレットやスマホでも使えます。同じレイアウト、ウィジェット、テーマの本物のダッシュボードが表示され、キーは実際に PC で動作します。やり方はスマホのガイドとタブレットのガイドにあります。

Mac や Linux でも使える?

はい、ベータとして対応しています。Windows 10 と 11 に加えて、macOS 11 以降 (Apple Silicon と Intel 共通のダウンロード 1 つ) と 64 ビットの Linux で動きます。ダッシュボード、ウィジェット、ストアは 3 つとも同じです。macOS と Linux ではまだ一部のセンサーやシステム操作がなく、データのないタイルは読み込み続けずにその旨を表示します。何が使えるかは Mac と Linux のページにあります。

Mac での初回起動: アプリはまだ公証を受けていないため、macOS は初回の起動をブロックします。macOS 15 以降では システム設定 → プライバシーとセキュリティ を開き、下までスクロールして このまま開く をクリックします。macOS 11〜14 ではアプリを右クリックして 開く を選び、もう一度 開く を押します。バージョンごとに 1 回だけです。

無料? サポーターには何がある?

アプリは無料で、広告もアカウントもありません。Buy Me a Coffee のサポーターには、カタログの毎月のドロップ、Lyrics と Developer cleanup のウィジェット、Discord のロール、Hall of Supporters への掲載があります。料金は月 5 USD か年 50 USD、または 5 USD からの一回払いで、5 USD ごとに 1 か月分になります。コードはメールで届き、設定 → Xenonを応援 に入力します。どのプランにも毎月 300 スパーク（Xenon のクレジット）が付きます。

サポーターパスは PC ごとに 1 回、7 日間無料で試せます。サポーターのドロップと Lyrics が開きます。限定ドロップと、公開から数週間の一部の新しいドロップはサポーター専用です。Lyrics と Developer cleanup はサポート終了後も使えます。1 年間のサポートでは、あなたのパレットや写真からあなた専用のテーマを作り、あなたの名前で公開します。

スパークとは？

スパークは Xenon のクレジットで、1 スパークは 1 米セントです。自分の API キーなしでアシスタントを使うときと、スパークで販売されている Store のアイテムに使えます。サポートの毎月に 300 スパークが含まれ、毎月初めにリセットされます。追加の購入にサポーターである必要はありません。Buy Me a Coffee のエクストラで、500 スパークが 5 USD、1050 が 10 USD、2200 が 20 USD です。購入したスパークに期限はありません。サポーターでない場合は、最初のパックと一緒にスパークコード（XC-…）がメールで届きます。サポーターコードと同じ欄に入力してください。

スパークで購入したアイテムは、アップデートも含めてずっとあなたのもので、最大 3 台の PC で使えます。再インストールに費用はかかりません。限定エディションがスパークで販売されることはありません。

使い方

ゲームが重くならない?

重くならないように作られています。ゲームの実行中はゲームモードがアニメーション背景をフェードアウトしてアニメーション効果を止め、いちばん重いタイル (ブラウザーとセカンドスクリーンの配信) もゲームが終わるまで停止します。こうしたライブタイルや Home Assistant は、画面に表示されている間だけ接続されます。

Windows では、ゲーム中にアプリのダッシュボードをタッチしても大丈夫です。カーソルはすぐにゲームのモニターに戻り、タップでゲームのフォーカスが奪われることもありません。

ウィジェットやテーマを追加するには?

ダッシュボードの + をタップすると、内蔵のタイルを追加できます。さらに増やすには 設定 → ストア を開きます。コミュニティが作ったテーマ、背景、ウィジェット、アンビエントシーン、パックがあり、適用前に必ずプレビューが表示され、ワンタップでインストールできます。同じものをこのサイトのカタログでも見られます。

温度やゲームの FPS は表示できる?

はい。Windows ではインストーラーが温度の読み取りを設定し (管理者の確認を 1 回だけ許可します)、PresentMon が実行中のゲームの本当のフレームレートを表示します。フルスクリーンのゲームも対象です。入っていない場合は 設定 → ゲームモード からインストールできます。macOS では温度と GPU 負荷を macmon (brew install vladkens/tap/macmon) から読み取ります。Linux でゲームの FPS を見るには MangoHud が必要で、ゲームを MangoHud 経由で起動します。

Spotify、Home Assistant、RGB ライトに対応している?

はい。どれも任意で、接続するまではオフのままです。

  • Spotify: 再生中の曲はメディアタイルに表示されます。設定でアカウントを連携すると、シーク、お気に入り、シャッフル、プレイリストが使え、Deck からも操作できます (再生の操作には Spotify Premium が必要です)。
  • Home Assistant: 設定 → スマートホーム でアドレスと長期アクセストークンを入れて接続すると、照明、センサー、シーンをタイルや Deck のキーから操作できます。
  • RGB: CORSAIR デバイスは iCUE 経由で、WLED、OpenRGB、Philips Hue、Nanoleaf、Govee、LIFX、Yeelight はネットワーク経由で、Windows では GIGABYTE と AORUS のマザーボードを USB 経由で制御します。
レイアウトを保存したり別の PC に移したりできる?

はい。設定 → バックアップ → バックアップを書き出す で、レイアウト、Deck、カレンダー、タスク、タイマー、メモ、設定、カスタム背景を 1 つのファイルに保存できます。別の PC で バックアップを読み込む を使えば、すべて元に戻ります。API キーやパスワードはファイルに含まれないため、連携は再接続を求められます。コミュニティのウィジェットは一覧が表示されるので、コードから再インストールできます。

困ったとき

Windows が Xenon をウイルス扱いする。安全?

誤検知です。Windows インストーラーはバージョン 4.11.9 から署名されていますが、Microsoft は新しいファイルへの信頼を時間をかけて積み上げるため、出たばかりのリリースには Defender、SmartScreen、ブラウザーが警告を出すことがあります。ファイルは自分で確認できます。各リリースには署名付きの SHA256SUMS リストがあり、照合するためのコマンドはダウンロードページにあります。Microsoft Store からもインストールできます。

  • Defender に削除された: Windows セキュリティ → ウイルスと脅威の防止 → 保護の履歴 を開き、Xenon の項目を選んで 復元 を選びます。そのあと %LOCALAPPDATA%\Xenon と %LOCALAPPDATA%\Programs\Xenon を 除外 に追加します。
  • ブラウザーがダウンロードを止める: Ctrl+J でダウンロード一覧を開き、保存 を選びます。
  • 起動せず、何の通知もない: Windows 11 では多くの場合、Windows セキュリティ → アプリとブラウザーの制御 にある Smart App Control が原因です。まずはオンのまま最新リリースを試してください。一度オフにすると、PC をリセットしない限り Windows はオンに戻させてくれません。

警告を無視してよいのは、公式のReleases ページから入手し、ハッシュを確認したファイルだけです。

Xenon が勝手に閉じる

タスクトレイのメニューを開き、Open crash log を選びます。最後の行が PANIC なら、アプリ自体のエラーです。その行を Discord かバグ報告に貼ってください。正確な箇所がわかります。最後の行が launched でその後に何もなければ、外部の何かが閉じています。ほとんどはウイルス対策ソフトです。保護の履歴 でその時刻の項目を探して復元し、上の質問にある 2 つの除外を追加してください。

CPU の温度が表示されない

Windows ではインストーラーをもう一度実行し、管理者の確認を許可してください。温度の読み取りには LibreHardwareMonitor と PawnIO が必要で、これらにはドライバーレベルの部分があるため確認が出ます。拒否しても温度以外はすべて使えます。macOS では macmon をインストールしてください。センサーをまったく公開していないノート PC やマザーボードもあり、その場合タイルは架空の数字を出さずにその旨を表示します。

更新やアンインストールの方法は?

Xenon は自動で更新されます。新しいリリースが出るとダッシュボードが知らせ、ワンタップでダウンロードし、インストール前に署名を確認し、何か失敗すれば前のバージョンに戻します。設定、レイアウト、メモはそのまま残ります。

アンインストールするには、Windows では UNINSTALL.bat、macOS では UNINSTALL.command、Linux では ./UNINSTALL.sh を実行します。アプリ、自動起動、データが削除されます。設定、レイアウト、メモを残したいときは、Windows では -KeepData、それ以外では --keep-data を付けてください。

プライバシーとサポート

データはどこかに送られる? アカウントは必要?

設定、メモ、タスク、予定、Deck、ファイルのインデックスは PC の中に残ります。アプリには分析 SDK も、クラッシュの自動送信も、行動の追跡もありません。ネットに接続するのは、更新の確認と、天気や Spotify など自分でオンにしたサービスのときです。どんな通信を行い何を送るかは、すべてプライバシーページに載っています。

Xenon のアカウントはありません。入力するのはサポーターコードだけで、各連携はそれぞれのログインを使います。

どこで助けてもらえる?

Discord で質問するのがいちばん早く、よく出る質問はこのページに追加されます。再現できるバグは、システム、行ったこと、起きたことを書いて GitHub の Issue を開いてください。

個人での利用は無料で、仕事に使っている PC でもかまいません。Xenon を販売したり商用製品に組み込んだりするには、事前に書面での許可が必要です。メールでご連絡ください。
