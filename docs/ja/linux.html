Linux 版 Xenon

Xenon は、余っている画面のための無料ダッシュボードです。Linux 版はベータで、ダッシュボードは Windows 版と同じです。このページでは、まだ違う点と必要なパッケージを紹介します。

最終更新: 2026年9月26日 · すべてのリンクは最新リリースを指しています

ダウンロード 初回起動 動く機能 X11 と Wayland

ダウンロード

AppImageXenon-Linux-x86_64.AppImagex86_64 のデスクトップならどれでも動きます。chmod +x で実行権限を付けて起動します。 Debian, UbuntuXenon-Linux-x86_64.debアプリをインストールします。ダッシュボードは初回起動時に、ユーザーごとにセットアップされます。 Fedora, openSUSEXenon-Linux-x86_64.rpm.deb と同じ内容で、RPM 系のディストリビューション向けです。

Linux 対応は ベータ です。ダッシュボード、ウィジェット、カタログ、各種連携は Windows と同じです。まだ違うのはマシンを読み取って操作する部分で、下の表にまとめています。GNOME と KDE で動作を確認しています。

初回起動

アプリを開きます。初回起動時に、ターミナルのウィンドウでダッシュボードをセットアップするよう提案されます。エンジンをダウンロードし、展開する前にダウンロードを検証し、ログイン時に Xenon が起動するよう systemd --user サービスを登録します。ユーザーマネージャーがない環境では代わりに XDG 自動起動のエントリーを使い、そのことを知らせます。この代替手段ではクラッシュ後に Xenon が再起動しないことも伝えます。

.deb と .rpm がインストール時にこれを行わないのは意図的です。セットアップが作るものはすべて1つのユーザーアカウントに属しますが、パッケージは root としてマシン全体にインストールされるからです。

インストーラーは、入っていない任意のツールも一覧で示します。Debian と Ubuntu では:

sudo apt install nodejs npm unzip           # required
sudo apt install wireplumber                # volume, microphone and the per-app mixer
sudo apt install wmctrl xdotool x11-utils   # the open-applications widget (X11 sessions)
sudo apt install ffmpeg                     # voice input and spoken replies

デスクトップにターミナルエミュレーターがまったくない場合、アプリはインストーラーを表示できません。リリースからソースの zip をダウンロードして展開し、./INSTALL.sh を実行してください。

Linux で動く機能

項目状態
ダッシュボード、タイル、テーマ、カタログ、ウィジェット SDK動作します。Windows と同じです。
全画面のネイティブアプリ、ログイン時の起動、自動更新動作します。
CPU、メモリ、ディスク、ネットワーク動作します。
CPU と GPU の温度、GPU 使用率、ファンの回転数動作します。カーネル自身のセンサーを使います。
システムの音量、マイクのミュート、アプリごとのミキサーWirePlumber がインストールされていれば動作します。
再生中の曲とメディアキー動作します。MPRIS を使います。
ゲーム内の FPS カウンター動作します。MangoHud を使います。
Xenon AI、チャット、操作、「Hey Xenon」音声起動動作します。クラウドでもローカルでも使えます。
ネットワーク上のライティング: WLED、Hue、Nanoleaf、OpenRGB動作します。
配信、Spotify、Discord、Home Assistant動作します。
スマートフォンやタブレットをセカンドスクリーンに動作します。
デスクトップ通知と着信カード動作します。

X11 と Wayland

ダッシュボードのほとんどはどちらでも同じように動きます。違うのは、ほかのウィンドウを見る必要がある部分です。開いているアプリのウィジェット、アプリスイッチャー、AI の画面認識は X11 のツール（wmctrl、xdotool）を使うので、Wayland のセッションでは、Xenon はそれらを表示してから失敗させるのではなく、最初から隠します。必要な場合は X11 のセッションでログインしてください。

問題の報告

Linux 版がベータなのは、上の表にまだ抜けがあるからです。報告するには、ディストリビューション、デスクトップ、セッションの種類を書いてバグ報告を作成してください。先に質問したい場合は Discord に書き込んでください。
