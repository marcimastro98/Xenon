PawnIO とは

PawnIO は、開発者 namazso による Windows 用の署名付きカーネルドライバーです。 CPU の温度、マザーボードのファン制御チップ、メモリのセンサーを読むには、普通のプログラムが触れないハードウェアのレジスタとやり取りする必要があります。そのため、モニタリングアプリには代わりにそれを行う小さなドライバーが必要です。

PawnIO の特徴は、通すものがごくわずかなことです。どんなプログラムにもポートやレジスタへの直接アクセスを渡すのではなく、Pawn 言語で書かれた小さなモジュールを実行し、各モジュールは書かれた目的の操作だけを公開します。読み込むのはメンテナーの鍵で署名されたモジュールだけです。ソースコードは pawnio.eu で公開されています。

PawnIO と WinRing0

長年、多くのハードウェアモニターは WinRing0 を使ってきました。PC 上のどのプログラムにもハードウェアのポートとレジスタへの直接アクセスを与える古いドライバーです。それが問題で、悪意のあるプログラムも同じ扉を通れます。Microsoft Defender は現在これを HackTool:Win32/Winring0 として検出し隔離するため、多くのファンやセンサーのアプリで突然警告が出るようになりました。

LibreHardwareMonitor、Fan Control、OpenRGB などは PawnIO に移行しました。Xenon が WinRing0 を同梱したことは一度もありません。

Xenon が PawnIO を入れる理由

Windows では、Xenon は LibreHardwareMonitor を通して CPU とディスクの温度を読みます。LibreHardwareMonitor がセンサーに届くには PawnIO が必要です。センサーをインストール を押すと、Xenon は Microsoft のパッケージマネージャー winget から namazso.PawnIO というパッケージとして PawnIO を入手するので、ファイルは私たちではなく開発者本人から届きます。

ドライバーのインストールには管理者の確認が必要です。拒否しても Xenon は動き、温度が表示されないだけです。Xenon 自体が管理者として動くことはなく、小さなサービスがセンサーを読んでその値を渡します。古い PawnIO がすでに入っている場合は winget upgrade namazso.PawnIO で更新してください。古いバージョンでは CPU の一部の値が空になるためです。

macOS と Linux には PawnIO はありません。Mac では macmon から、Linux ではカーネル自身のセンサーから温度を読みます。

PawnIO とアンチチート

PawnIO はゲームの外にあり、ゲームのメモリを読むことはありません。それでも FACEIT のアンチチートは 2.1.0 より前の PawnIO をブロックしていました。PawnIO.sys と表示されたら、winget upgrade namazso.PawnIO でドライバーを更新してください。すべてのアンチチートを試したわけではありません。問題が出たら Discord で教えてください。

PawnIO を削除するには

Xenon をアンインストールするとき、PawnIO を削除する前に確認があり、初期設定では残します。PC 上のほかのモニタリングアプリが使っているかもしれないからです。自分で削除するには winget uninstall namazso.PawnIO を実行します。PawnIO を通して温度を読んでいたアプリは、もう一度インストールするまで温度を表示しなくなります。

質問

PawnIO はウイルスですか？

いいえ。知られた開発者による署名付きドライバーで、ソースコードは公開されており、LibreHardwareMonitor や Fan Control などのアプリがインストールします。カーネルドライバーなのでシステムに深くアクセスできますが、だからこそ署名されたモジュールしか実行しません。

PawnIO は必要ですか？

それを使うアプリで温度を見たい場合だけです。Xenon は PawnIO なしでも動き、温度の値が表示されないだけです。

PawnIO は誰が作っていますか？

独立した開発者の namazso です。Xenon、CORSAIR、Microsoft が作ったものではありません。

ダッシュボードの Xenon

Xenon は、余ったモニター、タブレット、スマートフォン、CORSAIR Xeneon Edge を PC 用のタッチ操作パネルに変えます。ウィジェットにはリアルタイムの温度もあります。無料で、アカウントは不要です。できることを見るか、Xenon が Windows で動かすものをお読みください。
