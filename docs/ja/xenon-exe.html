xenon.exe: その正体と、自分で確認する方法

PC で見慣れないプロセスを見つけて名前を検索したのなら、たいていの場合に当てはまる答えを先に書きます。それはおそらく Xenon のものではありません。

最終更新: 2026年9月26日

要点 Xenon が実際に実行するもの 手元のファイルを確認する方法 インストールした覚えがない場合 Defender に検出された場合 削除する方法

要点

Xenon は xenon.exe という名前のファイルをインストールしません。 タスク マネージャーにちょうど xenon.exe という綴りのプロセスが表示されているなら、たまたま同じ名前を持つ別のものである可能性がほぼ確実です。下の一覧で、どちらを見ているのかがわかります。

一方、xenon-native.exe や xenon-helper.exe が表示されているなら、それは Xenon のものです。それぞれが何をするのかは、このページの残りで正確に説明します。

Xenon が Windows で実際に実行するもの

Xenon 自身のものは4つです:

ファイル内容
Xenon-Setup-x64.exeインストーラーです。一度実行するだけで、プロセスとしてシステムに残ることはありません。
xenon-native.exeダッシュボードのウィンドウそのものです。選んだ画面にインターフェースを描く、小さなネイティブのシェルです。システムトレイに表示されるのはこれです。
xenon-helper.exeWeb アプリだけでは届かない Windows の部分への橋渡しです。オーディオデバイスとアプリごとの音量、メディアキー、通知、ウィンドウの一覧、グローバルホットキー、ディスクのスキャン、Bluetooth でのスマートフォン連携を担います。エンジンが起動し、標準入出力を通じてエンジンに応答します。
node.exeダッシュボードのエンジンです。Xenon はローカルの Web アプリなので、それを配信しているのは 127.0.0.1:3030 で待ち受ける普通の Node.js です。このアドレスにはこの PC からしか接続できません。設定で「スマホからのアクセス」をオンにすると、ローカルネットワークでも待ち受け、ペアリングしたスマートフォンやタブレットから接続できるようになります。

ファイルはユーザープロファイルの下にある2つのフォルダーに置かれ、Windows 本体の中に置かれることはありません: %LOCALAPPDATA%\Xenon と %LOCALAPPDATA%\Programs\Xenon です。ログオンごとのスケジュールされたタスクが、サインイン時にあなた自身のアカウントでエンジンを起動します。セットアップ時に管理者の確認を承認した場合、このタスクは管理者権限で動き、それによって温度を読み取れます。Windows サービスとしてインストールされるものはありません。

このほかに、特定の機能のために Xenon が実行するツールがあります。どれもこのプロジェクトではなく、それぞれの開発元が作ったもので、必要とする機能がオンのときだけ実行されます:

  • LibreHardwareMonitor と PawnIO は winget でインストールされ、CPU とディスクの温度を読み取ります。PawnIO は署名付きのカーネルドライバーで、WinRing0 の後継です。WinRing0 は、古いハードウェア監視ツールの誤検出の多くの原因になっているドライバーです。Xenon が WinRing0 を同梱したことはなく、今後もありません。
  • PresentMon は Intel のフレームタイム計測ツールで、ゲーム内の実際の FPS カウンターのために Xenon 自身のフォルダーにダウンロードされます。
  • FFmpeg は音声入力と読み上げのために使い、Ollama はアシスタントを無料のローカルプロバイダーに切り替えた場合だけ使います。インストーラーはどちらもダウンロードしません。必要になったときに設定から導入します。
  • Sunshine と Tailscale は、PC のリモート操作をオンにした場合だけ使います。

実際に手元にあるものを確認する方法

  1. タスク マネージャーでプロセスを右クリックし、ファイルの場所を開く を選びます。%LOCALAPPDATA%\Xenon または %LOCALAPPDATA%\Programs\Xenon の下になければ、このプロジェクトのものではありません。
  2. ファイルを右クリックして プロパティ を選び、デジタル署名 タブを開きます。バージョン 4.11.9 から Xenon-Setup-x64.exe、xenon-native.exe、xenon-helper.exe には署名があり、このタブに発行元が表示されます。古いリリースのファイルには署名がないので、その場合は次の手順のハッシュで確認します。
  3. ファイルを公開されたものと比べます。各リリースには、プロジェクトの鍵で署名された SHA256SUMS ファイルが含まれていて、署名付きのリリースでも古いリリースでも同じように使えます: 
    Get-FileHash .\Xenon-Setup-x64.exe -Algorithm SHA256
    ハッシュがそのリリースの SHA256SUMS にある行と一致すれば、そのファイルは GitHub Actions がそのタグの公開ソースコードからビルドしたものとバイト単位で同一です。
  4. ファイルを VirusTotal にアップロードします。少数のエンジンだけが反応して残りがクリーンなら、たいていはマルウェアではなく評価の問題です。ほぼすべてのエンジンが反応するなら、話は別です。

Xenon をインストールしたことがない場合

その場合、見ているものはこのプロジェクトのものではありません。上の手順でファイルの場所と発行元を確認してください。このサイトには、こちらがインストールしていないソフトウェアを削除するものはありませんし、それを消すために「クリーナー」をダウンロードするよう求めるページもありません。こうした検索のあとに続くのは、たいていそういう形の詐欺です。

Xenon のもので、Defender に検出された場合

それは今でも起こりえます。バージョン 4.11.9 からインストーラーには署名があり、Windows には確認済みの発行元が表示されます。それでも Microsoft は評価を時間をかけて付与するため、しばらくは SmartScreen が警告することがあります。詳細情報 をクリックし、実行 を押してください。また Defender は署名者だけでなくプログラムの動作も判断するため、署名付きのファイルでも検出されることがあります。

FAQ では2種類の検出について説明しています。警告の名前からどちらの検出かがわかることや、使い続けたい場合の除外の追加方法も載せています。要点を言うと、名前が !cl で終わるものは、評価に関する機械学習の判定です。そうでない名前は動作のシグネチャで、コードをダウンロードするスクリプトを含むインストーラーに反応したものです。これは、本当に望ましくないものの正確な説明でもあります。どちらもそれだけでは何の証明にもならないので、上の手順 2 と 3 があります。

完全に削除する方法

設定 → アプリ → インストールされているアプリ → Xenon → アンインストール。従来の方法でインストールした場合は、展開したフォルダーから UNINSTALL.bat を実行します。2つのフォルダー、スケジュールされたタスク、トレイのアプリが削除されます。winget でインストールした温度関連のコンポーネントは別のプログラムなので、同じアプリの一覧から個別にアンインストールします。

ダッシュボードの Xenon を探していた方へ

余っているモニター、タブレット、スマートフォン、CORSAIR Xeneon Edge を、PC のタッチ操作パネルに変えます。無料で、アカウントは不要です。何ができるかを見るか、FAQ をお読みください。
