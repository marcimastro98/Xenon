スマホを2枚目の画面にするベータ

スマホは Xenon の画面のひとつになります。スマホのブラウザで Wi-Fi 経由で開くだけで、スマホには何もインストールしません。このページはその使い方です。

Windows版をダウンロード ブラウザで試す

このページの内容

できること、できないこと 写真やファイルをやり取りする 入り方は2つ。どちらかを選んでください。 家なら30秒 どこでも、そしてアプリとして うまくいかないとき これがやらないこと

スマホに出るのはリモコンでもプレビューでもありません。レイアウトもウィジェットもテーマも同じ、あなたのダッシュボードそのものです。デッキのキーは本当に PC 側で動きます。音楽を止めれば音楽が止まります。設定を変えれば1秒後には PC でも変わっています。アカウントもクラウドも要らず、インストールするアプリもなく、家のネットワークの外へは何も出ません。

できること、できないこと

ペアリングした端末は、あなたの端末になります。PC のダッシュボードにできることは、ほぼ全部できます。できない少しのことには二つの理由があります。その PC の前に人がいないと成り立たないこと、そしてスマホが他人の手に渡ったとき、あなたが用意した以上のことをさせてしまうことです。

  • ✓ダッシュボード全部: センサー、ウィジェット、ページ、テーマ
  • ✓あなたが作ったデッキのキー。スマホではなく PC で実行されます
  • ✓メディア、音量、マイクのミュート、アプリの切り替え
  • ✓ストア: ウィジェット、アイコンパック、サウンドパック、テーマ
  • ✓Bit と、PC に保存される設定
  • ✓写真やファイルを双方向で送る
  • ✗システムの許可ダイアログ。Windows も macOS も Linux も PC の画面にだけ描くので、答えられるのは PC だけです
  • ✗Xenon の更新。更新はスマホがつないでいるサーバー自体を再起動します
  • ✗システムのインストーラー(ヘルパー、PresentMon、ドライバー)。どれもディスクにプログラムを置きます
  • ✗ペアリング済み端末の追加と削除。おかげでスマホが別の端末を登録したり、自分を締め出せる端末を消したりはできません
  • ✗プログラムやファイルを開く、スクリプトを実行する、文字を入力する、ショートカットを送る新しいキー。これらは PC で作ります。スマホからは押すことと、移動、名前の変更、削除ができます
  • ✗お気に入りへのアプリの追加。お気に入りはスマホが PC で起動できるアプリなので、PC で選びます。スマホからでも、お気に入りを外したり並べ替えたりはできます
  • ✗リモートデスクトップの設定、PC操作をオンにすること、バックアップの作成と読み込み、そして PC とペアリングしたスマホ経由の通話やメッセージ

始める前に一つ知っておいてください。 ペアリングした端末は、消すまでずっと PC への入り口のままです。スマホをなくしたり人に渡したりしたら、一覧から消してください。端末一覧はそのためにあります。1台だけ消すことも、ワンタップで全部消すこともできます。消した端末はその場で接続が切れます。90 日使っていない端末は使えなくなり、もう一度ペアリングが必要です。新しい端末がペアリングされるたびに、PC に通知が出ます。

写真やファイルをやり取りする

スマホを紐づけると、PC にファイルを送ったり PC から受け取ったりできます。スマホで Xenon を開き、「写真とビデオ」か「ほかのファイル」をタップして選ぶと、PC の Download/Xenon に元の名前のまま届きます。逆方向も同じで、エクスプローラーや Finder からタイルにファイルをドロップして、スマホでダウンロードできます。ほかの誰かのサーバーは経由しません。

iPhone では送るときに Xenon を開く必要があります。iOS はどのウェブサイトも共有ボタンに表示させないため、ウェブページ側で回避する方法はありません。iPhone でダウンロードしたファイルはカメラロールではなく「ファイル」に入ります。写真は長押しして「写真に追加」を選んでください。

入り方は2つ。どちらかを選んでください。

家で

自宅の Wi-Fi で

約30秒、インストール不要

  • オンにして QR を読むだけ
  • 同じ Wi-Fi にいる間だけ使えます
  • 暗号化なしの HTTP なので、アプリ化もマイクも通知も使えません
どこでも

安全に、家でも外でも

約5分、ボタン1つとウェブページのスイッチ1つ

  • 暗号化され、ルーターのポートを1つも開けずにどこからでも使えます
  • スマホにアプリのようにインストールされ、アイコンも付きます
  • Bit がマイクを使えるようになります
  • ルーターがアドレスを変えても、アドレスは変わりません

一度決めたら終わりではありません。2つ目は1つ目の隣に扉を増やすもので、置き換えるものではありません。家でしか使わないなら1つ目から始めてください。

家なら30秒

  1. PC で 設定、そしてスマートフォン を開きます

    必要なものは スマホからのアクセス の下、1つのパネルにまとまっています。近道: Xenon を初めて開くとどの画面に置くか聞かれます。そこで スマートフォンかタブレット を選ぶと、このパネルまで直接案内し、同じ手順がその中に開いています。パネル上部の 手順ガイド ボタンでいつでも開き直せます。

  2. 「他の端末からのアクセスを許可」をオンにします

    自分でオンにするまではオフです。オフの間、Xenon はこの PC 以外には一切応答しません。ネットワークを調べられても、この機能が無いバージョンとまったく同じ返事をするので、機能があること自体わかりません。

    他の端末からのアクセスを許可オフの間、Xenon はこの PC にしか応答しません。

  3. 「端末を追加」を押します

    PC に QR コードと、その下に8文字のコードが出ます。パスワードではなく招待状です。3分で切れ、何度か間違えるとその場で無効になります。

  4. スマホのカメラで読み取ります

    スマホのブラウザでダッシュボードが開きます。設定はこれで終わりです。何もインストールしていませんし、コードがサーバーに届いたこともありません。ブラウザが外に送らない部分に入っているからです。

2台が同じ Wi-Fi にいる必要があります。ルーターのクライアント分離が有効だったり、ゲスト用ネットワークにいたりすると、同じ Wi-Fi でもお互いが見えません。

どこでも、そしてアプリとして

暗号化なしの HTTP では、ブラウザがまとまった機能を最初から渡してくれません。設計でどうにかできるものではありません。アプリとしてインストールできず、マイクも使えず、通知も届きません。2つ目の入り方がある本当の理由はこれで、距離の話ではありません。

そのために Xenon は Tailscale を使います。PC とスマホが自分だけの小さなプライベートネットワークに入り、ダッシュボードに本物の証明書と変わらないアドレスが付きます。そして ルーターのポートは1つも開きません。このアドレスは公開 DNS に存在しないので、外から見つけられるものが何もありません。

ボタンを1つ押せば、あとは Xenon がやります

同じパネルの 安全なアクセス(外出先でも) の下にボタンがあります。Tailscale を入れ、サインインの画面を開き、終わるのを待ってから、安全な接続を自分で立ち上げます。

安全なアクセス(外出先でも)Tailscale と HTTPS を使います。アプリ化、マイク、通知が使えるようになります。
自動で設定する

一度だけ止まりますが、わざとです。 証明書はプライベートネットワーク全体の設定で、Tailscale のサイトで切り替えます。Xenon が代わりにやることもできますが、そのためには同じサイトで鍵を作ってもらう必要があり、手間はむしろ増えます。だから Xenon はそこで止まってリンクを出し、あなたが終えたら自分で気づきます。ウィンドウは開いたままで構いません。

  1. 「自動で設定する」を押します

    システムが Tailscale のインストール許可を聞いてきます。そのあとサインイン用のタブが開きます。Google でも Microsoft でも GitHub でも構いませんし、Xenon のアカウントを作るわけではありません。

  2. HTTPS 証明書をオンにします

    ここだけは Xenon が代われません。聞かれたら表示されたボタンを押してください。login.tailscale.com/admin/dns が開きます。下へスクロールして HTTPS Certificates の Enable を押します。どのプランでも無料です。Xenon に戻ると、もう次へ進んでいます。

  3. 同じアカウントでスマホにも Tailscale を入れます

    App Store か Google Play から入れて、さっきと同じアカウントでサインインし、スイッチをオンにします。ここを忘れる人が一番多く、症状ははっきりしています。スマホがアドレスを開けないと言います。壊れてはいません。そのアドレスは自分のネットワークの中にしかなく、だからこそインターネット側の誰にも届かないのです。

  4. 新しいアドレスでもう一度ペアリングします

    端末を追加 を押してもう一度読み取ってください。ブラウザはペアリングをその時のアドレスに結び付けるので、家のアドレスでペアリングしたスマホは、安全なアドレスではペアリングされていません。これ以降は新しいアドレスだけで足ります。家でも外でも使えます。

  5. ホーム画面に追加します

    Safari では共有から ホーム画面に追加 を選びます。Android では Chrome がインストールを提案します。以降 Xenon は専用アイコンで、アドレスバーなしの全画面で開きます。ここではマイクが使えるので、Bit が PC ではなくスマホで聞き取れます。通知も使えます。設定からスマートフォンへ進んでこの端末の通知をオンにしておくと、アプリを閉じていてもタイマーが終わったときに知らせてくれます。

うまくいかないとき

スマホがアドレスを開けないと言う

ほとんどの場合、スマホがまだプライベートネットワークに入っていません。スマホで Tailscale を開き、スイッチが本当に オン か確かめてください。入れただけでは足りません。iPhone ならオンのときステータスバーに VPN と出ます。PC と同じアカウントでサインインしているかも確認してください。アカウントが違うとネットワークも別になり、互いに見えません。

ウィジェットが白い箱に文字だけの状態で出る

iPhone と iPad では、バージョン 4.11 まで必ずこうなっていました。セキュリティの決まりのせいでウィジェットが自分の見た目を読み込めず、しかも Safari だけで起きるので、同じウィジェットが PC では正しく見えていました。Xenon を更新すれば直ります。更新してもまだ起きるなら、ページが PC より古いコードで動いています。更新前から開きっぱなしだったタブが、読み込み直さずにメモリから復帰したときによく起きます。引っ張って更新だけでは足りないことが多いので、タブを完全に閉じてアドレスを開き直してください。

前は使えたのに、ペアリングが外れたように見える

ルーターが PC に別のアドレスを割り当てた可能性が高いです。ペアリングはその時のアドレスに結び付いているので、アドレスが変わると外れたように見え、もう一度追加が必要になります。対処は2つあります。ルーターの設定で PC に固定アドレスを割り当てるか、アドレスが決して変わらない上の安全な方法を使うかです。

インストールしたアプリがまたペアリングを求める

iPhone ではホーム画面に追加したアプリが Safari とは別の保存領域を持つため、ブラウザでのペアリングは引き継がれません。コードをもう1つ作って、インストールしたアプリの中からペアリングしてください。端末一覧には別の項目として並ぶので、両方に名前を付けて区別できます。

Xenon が HTTPS 証明書は無効だと言う

この PC ではなく、プライベートネットワーク全体の設定です。login.tailscale.com/admin/dns を開き、HTTPS Certificates の Enable を押してください。数秒で Xenon が気づきます。

タブレットにデスクトップ版のレイアウトが出るが、積み重ね版がよかった

これは意図した動きです。タブレットは本来のグリッドを出せる大きさがあり、それがタブレットを使う理由でもあります。iPad は Xenon が切り替える基準よりずっと大きい画面です。特定の端末で積み重ね版がよければ自分で選べますし、Xenon はその選択を その端末だけ で覚えます。PC には伝わりませんし、保存したレイアウトが上書きされることもありません。

これがやらないこと

Xenon のアカウントはなく、間に入る自社サーバーもなく、ダッシュボードの中身がどこかにアップロードされることもありません。自宅の Wi-Fi で使う接続は暗号化されていません。パネルが信頼できるネットワークで使うようにと書いているのはそのためで、安全な方法はまさにそこを解決するためにあります。Tailscale はあなたが選んで足す外部の会社なので、そちらのプライバシー規約が適用されます。Xenon がそこから受け取るのは、自分のパソコンのアドレスと証明書だけです。

Xenon が何を送り、何を送らないかは、残りも プライバシーのページ にあります。
