Xeneon Edge のウィジェット: iCUE でできること、Xenon で加わること

Edge は良い画面ですが、ウィジェットの種類は多くありません。Xenon はその形に合わせて作られた無料のダッシュボードです。自分の手で並べるページ、PC を実際に操作するコントロール、ゲームのフォーカスを奪わないタッチを備え、iCUE があってもなくても動きます。

最終更新: 2026年9月26日

Edge が最初からできること

CORSAIR Xeneon Edge は 14.5 インチ、2560×720 のタッチ対応の横長ディスプレイで、デスクスタンドに載せるか、ケース内の 120 mm ファン3基分の場所に取り付けます。買ったままの状態では普通のサブモニターで、iCUE を使うとウィジェットを並べた壁になります。センサーの値、時計、メディアの操作、Web ページ、そしてほかの人が書き出して共有したウィジェットです。自分で作りたい人向けに、CORSAIR は WidgetBuilder キットも公開しています。

これは十分な出発点で、多くのオーナーにはそれで足ります。オーナーのフォーラムで何度も出てくる要望は、iCUE が応えていないものです。自分の手で並べ替えられるレイアウト、数値を表示するだけでなく PC 上で何かを実行するコントロール、ゲームのフォーカスを奪わないタッチ、そして iCUE をまったく起動せずにこのディスプレイを使う方法です。

Xenon で加わること

Xenon は、背が低くとても横長な Edge の形に合わせて作られた無料のダッシュボードで、その後どの画面でも動くようになりました。PC 上で小さなローカルサービスとして動き、Edge には2つの方法のどちらかで表示されます。iCUE をまったく必要としない専用の全画面ネイティブアプリとして、またはすべてを1か所にまとめたい場合は iCUE の中の iFrame パネルとしてです。

  • ドラッグ＆ドロップで作るページ。 サイズを変えられるタイルのグリッドで、ページは最大8枚。レイアウトは保存して、コードとして共有できます。
  • PC を操作するコントロール。 マイクのミュート、オーディオ出力の切り替え、曲のスキップ、アプリごとの音量ミックス。アプリ、OBS、ショートカット、マクロ用に Stream Deck のようなキーのグリッドも使えます。
  • ゲームを邪魔しないタッチ。 ネイティブアプリでは、Edge をタップしてもマウスがゲームから離れず、ゲームのフォーカスも奪いません。これを Windows に求められるのは、本物のネイティブウィンドウだけです。
  • Xenon AI。 ページに欲しいものを伝えると、そのページを組み立てます。Google Gemini か、Ollama 経由の無料のローカルモデルで動きます。
  • センサーと履歴。 CPU、GPU、メモリ、ディスク、ネットワーク、ゲーム内の実際の FPS に加え、24時間から30日までの履歴。温度の読み取りには署名付きのもの（PawnIO）を使い、WinRing0 は使いません。
  • ライティング。 CPU の温度、タイマー、アルバムアートに合わせて iCUE の LED を光らせます。ネットワーク上の Govee、LIFX、WLED、Hue、Nanoleaf のライトも一緒に動かせます。
  • コミュニティのカタログ。 ほかのオーナーが共有したテーマ、ウィジェットパック、ページのレイアウト一式を、コード1つでインストールできます。

ダッシュボードは PC 上で動き、アカウントはありません。設定、ファイル、センサーの値は PC に残ります。アプリはアップデートの確認、カタログの読み込み、1日1回のお知らせファイルの取得を行い、匿名のバージョン集計を送ります（設定のスイッチひとつでオフにできます）。それ以外がオンラインにつながるのは、天気や AI サービスのように自分でオンにした機能のときだけです。

Edge に表示するには

  1. Xenon-Setup-x64.exe をダウンロードして実行します。ネイティブアプリがインストールされます。
  2. アプリが開き、ダッシュボードのエンジンがまだないことを確認すると Complete setup を表示します。一度押してください。Node.js、センサーの読み取り機能、ログイン時に起動するタスクがインストールされ、その様子はウィンドウで確認できます。
  3. Xenon は初めて開いたとき、どの画面で使うかを確認します。Edge を選んでください。ディスプレイの変更やスリープのあとも、その画面に固定されたままです。
  4. iCUE を使いたい場合: iCUE で http://127.0.0.1:3030/ を指す Web ウィジェットを追加すると、そのパネルに Xenon が表示されます。

試す前に知っておくこと

注意点が2つあります。1つ目に、Windows のインストーラーには署名があるので Windows には確認済みの発行元が表示されますが、Microsoft は評価を時間をかけて付与するため、しばらくは SmartScreen が警告することがあります。詳細情報 をクリックし、実行 を押してください。ファイルを自分で確認する方法は FAQ で説明しています。2つ目に、Xenon は Windows を中心に作られています。macOS 版と Linux 版もあってベータですが、Edge 向けの部分（専用のタッチジェスチャー、仮想セカンドスクリーン、iCUE のライティング）は Windows のみです。

無料で、有料版はありません。毎日使うようになったら、追加のテーマとウィジェットがいくつか使えるサポーター枠があります。ビジネスモデルはそれだけです。

質問

Xenon は iCUE の代わりになりますか？

いいえ。CORSAIR のハードウェアとそのライティングを動かすのは引き続き iCUE です。Xenon はその横で、独自のウィンドウとして、または iCUE のパネルの中で動き、独自のブリッジを通じて iCUE にライティング効果を送れます。iCUE を開かずに Edge で Xenon を動かすこともできますが、デバイスを設定するのはあくまで iCUE です。

Xenon を使うには Edge が必要ですか？

いいえ。Edge は最初に想定した画面ですが、余っているモニター、古いタブレット、同じ Wi-Fi につないだスマートフォン、タッチスクリーンでも同じように使えます。古いタブレットやスマートフォンを PC のダッシュボードにする方法をご覧ください。

iCUE のウィジェットと Xenon を同時に使えますか？

はい。iCUE では Edge がいくつかのパネルに分かれています。Xenon はそのうち1つを Web ウィジェットとして使い、残りはそのまま残ります。好みで、ディスプレイ全体を Xenon にすることもできます。

Xenon は無料ですか？

はい。個人利用は無料で、ソースは非商用ライセンスで GitHub に公開されています。試用期間はなく、上位プランでしか使えない機能もありません。サポーターにはお礼として追加のテーマがいくつかあります。

Xenon をダウンロード

インストーラーは1つ、アカウントは不要で、設定とファイルは PC に残ります。Windows 版 Xenon をダウンロードするか、macOS 版と Linux 版を入手してください。質問は Discord へどうぞ。
