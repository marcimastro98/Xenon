古いタブレットやスマートフォンを PC のダッシュボードとして使う

使わなくなったタブレットやスマートフォンをキーボードの横に置けば、温度、メディア、マイクのミュート、オーディオの切り替え、キーのグリッドを表示できます。画面は自宅の Wi-Fi を通じて PC から配信されます。タブレットには何もインストールしません。

最終更新: 2026年9月27日

できること 仕組み 設定方法 制限 質問

できること

まだ動くのに使っていないタブレットやスマートフォンも、キーボードの横に立てかければ、PC に足りなかった画面になります。ゲーム中に CPU と GPU の温度をちらっと見る、通話中にタップしてマイクをミュートする、曲を飛ばす、音声をヘッドホンに切り替える、OBS を起動する、Alt+Tab で切り替えなければ見られなかった通知を読む。そういう画面です。

Xenon はそのためのダッシュボードです。無料で、Windows で動き（macOS と Linux はベータ）、タブレットには何もインストールしません。ダッシュボードは端末に最初から入っているブラウザで開きます。

仕組み

Xenon は PC 上で小さなローカルサービスとして動き、自宅のネットワークにダッシュボードを配信します。タブレットやスマートフォンはそれを Web ページのように開くので、iPad、Android タブレット、古い Fire タブレット、iPhone、ブラウザのあるスマートフォンならどれでも使え、端末側で更新し続けるアプリもありません。ペアリングは PC に表示される QR コードで行います。ペアリングした端末は一覧に並び、1台ずつ削除できます。自宅の Wi-Fi では、タブレットはクラウドサービスを通さず PC と直接やり取りします。ただし Xenon 自体は、アップデートの確認、カタログ、天気など一部の機能でオンラインにつながります。

表示されるのはリモコンではなく本物のダッシュボードです。モニターと同じタイル、同じテーマ、同じページが、タブレットの形に合わせて並べ直されます。タッチする部分は指で押しやすい大きさです。

設定方法

  1. PC で Xenon-Setup-x64.exe をダウンロードして実行し、アプリに聞かれたら Complete setup を押します。これは一度だけです。
  2. 設定 → リモート操作 → スマホからのアクセス を開き、他のデバイスからのアクセスを許可 をオンにして デバイスを追加 を押します。PC に QR コードが表示されます。
  3. タブレットのカメラをコードに向けます。タブレットのブラウザでダッシュボードが開きます。全画面で使いたい場合はホーム画面に追加してください。
  4. PC に余っているモニターがまったくない場合は、初回起動時に、PC には何も表示しないよう Xenon に伝えてください。タブレットが唯一の画面になります。

スマートフォンのガイドには同じ手順がスクリーンショット付きで載っていて、家の外からダッシュボードにアクセスする任意の方法も説明しています。

制限

これはセカンドモニターではありません。PC がタブレットにウィンドウを出すことはなく、表示されるのは PC を操作できるダッシュボードです。小さな画面に本物のデスクトップをもう1つ置きたいなら、Xenon の セカンドスクリーン タイルが実際のモニター上でそれを実現します（Windows のみ）。ただし、これは別の機能です。また、タブレットとスマートフォンからのアクセスは現在のリリースではベータです。自宅の Wi-Fi ではよく動きますが、まだ新しい機能です。

もう一つ: Windows のインストーラーには署名があるので、Windows には確認済みの発行元が表示されます。それでも Microsoft は評価を時間をかけて付与するため、しばらくは SmartScreen が警告することがあります。詳細情報 をクリックし、実行 を押してください。理由とファイルの確認方法は FAQ で説明しています。

質問

タブレットにアプリは必要ですか？

いいえ。ブラウザがあれば十分です。ページをホーム画面に追加すると全画面で開くアイコンができますが、必須ではありません。

古い iPad や Android タブレットでも動きますか？

ブラウザがまだ最近の Web ページを開けるなら動きます。ブラウザの更新が止まったかなり古い端末では、一部のタイルの表示が遅くなることがあります。ダッシュボードは軽いですが、常に更新され続けるページだからです。

タブレットはインターネット経由で接続しますか？

自宅の Wi-Fi ではしません。PC がタブレットにページを直接配信します。家の外からアクセスするのは別の任意の設定で、スマートフォンのガイドで説明しています。ただし Xenon 自体は、アップデートの確認、カタログ、天気など一部の機能でオンラインにつながります。

タブレットの代わりにスマートフォンを使えますか？

はい、同じ方法で使えます。レイアウトは縦向きのスマートフォンの画面に合わせて並び直します。

無料ですか？

はい。有料版も、アカウントも、広告もありません。ソースは非商用ライセンスで GitHub にあります。

Xenon をダウンロード

インストーラーは1つでアカウントは不要、設定は PC に保存されます。Windows 版 Xenon をダウンロードするか、macOS 版と Linux 版のベータを入手してください。質問は Discord へどうぞ。
