Xenon のすべてのウィジェット

Xenon は、PC の横に置く画面のための無料のタッチダッシュボードです。CORSAIR Xeneon Edge、余っているモニター、タッチスクリーンのほか、ベータとしてスマートフォンやタブレットでも使えます。内蔵ウィジェットは41種類です。ここではそれぞれの機能を紹介し、そのあとで配置の方法と、ほかのウィジェットを入手する方法を説明します。

最終更新: 2026年9月27日

生産性 メディア システム 配信 グリッド、ページ、タブ カタログのウィジェット 自分で作るウィジェット 質問

Xenon は Windows 10 と 11 で動き、macOS と Linux はベータです。一覧は3つのシステムで同じですが、セカンドスクリーンだけは Windows のみです。システムがウィジェットにデータを渡せない場合はタイルにそう表示され、プラットフォームごとの制限は一覧に記載しています。

生産性

14種類。+ パレットに並ぶ順番で紹介します。

  • 予定。 カレンダー、タスク、タイマー、メモを1つのタイルのタブにまとめます。どれかを単独のタイルとして追加すると、そのタブはタブバーから外れます。
  • カレンダー。 自分の予定とリマインダーを入れる月表示です。Google、Outlook、.ics リンクを公開しているカレンダーの予定も、読み取り専用で表示します。
  • タスク。 優先度（高、中、低）付きの ToDo リストです。毎日、毎週、数日おきに繰り返すタスクも作れます。
  • タイマー。 名前付きのカウントダウンとストップウォッチです。同時に20個まで使え、再起動しても残ります。
  • メモ。 タブに分かれたプレーンテキストのメモです。入力を止めると保存され、1つを先頭に固定できます。
  • 天気。 現在の天気、1時間ごとと日ごとの予報、大気質を表示します。Open-Meteo、MET Norway、wttr.in から取得し、アカウントは不要です。
  • 検索。 「12月の写真」や「大きな pdf」のような普段の言葉で、PC のファイルを探します。タイルに直接入力します。
  • ファイル転送。 ペアリングしたスマートフォンやタブレットと PC の間で、自宅のネットワークを通じて写真、動画、ファイルを送り、届いたものと送ったものを一覧にします。スマホからのアクセスが必要で、これはベータです。
  • 株価。 株、指数、暗号資産、通貨のウォッチリストです。その日の変動と銘柄ごとのチャートを表示します。標準では Yahoo Finance を使い、キーは不要です。
  • サッカー。 フォローしているクラブと大会の試合日程、結果、順位表です。TheSportsDB から取得し、キーは不要です。
  • ニュース。 フォローしているメディア、トピック、RSS フィードの見出しを、新しい順に1つのリストで表示します。
  • 通知。 デスクトップに表示される通知を、アプリ、送信者、本文とともに表示します。タップするまで本文を隠しておくこともできます。Windows と Linux。
  • バイタル。 水分補給、食事、運動、目の休憩のピクセルアートのメーターで、PC の前にいる間に減っていきます。1つをタップして、済ませたことを確認すると満タンに戻ります。
  • 電話。 Bluetooth で PC とペアリングした iPhone や Android スマートフォンの連絡先、通話履歴、キーパッド、メッセージです。Windows、ベータ。

メディア

4種類。

  • 再生。 PC のメディアアプリで再生中のものを、カバー、再生と一時停止、前へ、次へとともに表示します。
  • チャット。 Xenon AI のテキストチャットです。質問したり、画像、PDF、テキストファイルを添付したり、ダッシュボードの変更を頼んだりできます。
  • ブラウザ。 タブ、アドレスバー、戻る、進むを備えた、タイルの中の Web ページです。PC 上の Chromium ブラウザが動かすので、埋め込みを拒否するサイトも開けます。
  • スライドショー。 追加した写真やアニメーション GIF、または PC 上のフォルダーの画像を順番に表示します。タップで一時停止したり、手動で送ったりできます。

システム

13種類。

  • システム。 CPU、GPU、メモリ、ディスクの使用率、CPU と GPU の温度、ネットワーク速度、ping、プレイ中のゲームのフレームレートを、リアルタイムのグラフで表示します。ゲーム内のフレームレートは Windows と、Linux では MangoHud で起動したゲームで使えます。
  • ファン。 センサーが報告するすべてのファンの回転数を、マザーボード、ハブまたは AIO、グラフィックカード、電源ユニットに分けて表示します。名前は変更できます。Windows と Linux。
  • エネルギー。 CPU と GPU の消費電力をワットで表示します。電源ユニットが報告する場合は PC 全体の消費電力も表示し、横に Home Assistant の電力センサーも並べられます。PC の値は Windows のみで、Home Assistant の値はどのシステムでも使えます。
  • バッテリー。 iCUE 経由のワイヤレスの CORSAIR デバイス、Bluetooth デバイス、ノート PC のバッテリーや USB 接続の UPS の残量を表示します。Windows。
  • ディスク容量。 各ドライブを何が占めているかのマップです。大きいファイル、検証済みの重複ファイル、安全に削除できるカテゴリーの決まった一覧を表示し、削除したものはごみ箱に移ります。
  • 音量。 マスター音量とミュート、出力デバイスと入力デバイス、音を出している各アプリのスライダーです。アプリごとのスライダーは Windows と Linux で使えます。
  • マイク。 大きなボタン1つで、マイクのミュートと解除を切り替えます。入力感度のスライダーもあります。
  • セカンドスクリーン。 仮想ディスプレイドライバーで作る追加の Windows デスクトップを、タイルの中にライブで表示します。アプリをそこへドラッグして、タッチで操作できます。Windows のみ。
  • リモートコントロール。 Sunshine、Tailscale、Moonlight を使って PC をスマートフォンにストリーミングするための、状態表示と操作です。送るモニターの選択、切断、アクセスのブロック、キルスイッチによる全デバイスのペアリング解除ができます。Sunshine と Tailscale を設定すると、+ パレットに表示されます。
  • スマートホーム。 選んだ Home Assistant のデバイスを部屋ごとに表示します。照明とスイッチはトグル、シーンはボタンになり、メディアプレーヤーとセンサーの値も表示します。
  • カメラ。 UniFi Protect のカメラや、Home Assistant が公開しているカメラの、ほぼリアルタイムの映像です。タップで拡大できます。
  • ライティング。 iCUE デバイスと、WLED、Hue、Nanoleaf などのネットワーク上のライトの色、エフェクト、デバイスごとのモードを設定します。iCUE デバイスは Windows のみ。
  • Claude Code。 タイルから Claude Code を接続すると、5時間と週間の上限、実行中の各セッションとその作業内容、タイルから答えられる許可リクエストを表示します。

配信

10種類。Twitch、YouTube、Discord、Spotify は、一度だけ登録する無料の開発者アプリを通じて、設定から自分のアカウントに接続します。OBS、Streamer.bot、Wave Link は、それぞれのプログラムが起動している必要があります。

  • Twitch ライブ。 Twitch で配信する人向けです。配信の状態、OBS を通じた配信の開始と終了、マイクのミュート、クリップ、マーカー、広告、タイトルとカテゴリー、チャットを扱います。
  • Twitch。 タイルの中の Twitch プレーヤーです。フォロー中で配信中のチャンネル、人気のチャンネル、検索、表示を選べるチャットを備えています。
  • YouTube。 高く評価した動画、再生リスト、登録チャンネル、検索から再生する YouTube プレーヤーです。リストの残りはキューとして続けて再生されます。
  • YouTube ライブ。 YouTube で配信する人向けです。ライブの作成、配信の開始と終了、チャットの閲覧と投稿、視聴者数とストリームの状態の確認ができます。
  • OBS。 OBS が送っている映像のプレビュー、配信と録画のボタン、シーンの切り替え、音声入力ごとのミュートと音量スライダーです。
  • Discord。 参加中のボイスチャンネルと、話している人を表示します。ミュート、スピーカーミュート、プッシュトゥトーク、参加するチャンネルの一覧、サウンドボード、DM とメンションもあります。
  • Spotify。 再生中の曲、キュー、プレイリスト、Spotify Connect のデバイスを扱う Spotify のリモコンです。再生の操作には Premium が必要です。
  • Streamer.bot。 Streamer.bot から届くフォロー、サブスク、レイド、Cheer、特典の引き換えをリアルタイムで表示し、Streamer.bot のグローバル変数も表示します。
  • Wave Link。 Elgato Wave Link のミキサーです。各ミックスのチャンネルごとにフェーダーとミュートがあり、Wave Link 3 ではリアルタイムのレベルメーターも表示します。
  • デッキ。 プログラムできるキーのグリッドです。アプリを開く、ショートカットを送る、メディア、OBS、Discord、Home Assistant を操作する、複数の手順のマクロを実行する、といったことができます。

グリッド、ページ、タブ

ダッシュボードを編集するには、上部バーの レイアウト をタップします。タイルは24列で半分の高さの行を持つグリッドに置かれるので、ドロップした場所の近くに収まります。サイズは角から変更できます。

各ページの + でパレットが開きます。上の4つのグループに加えて、その他の中にカスタムウィジェットがあります。ダッシュボードは最大8ページで、スワイプ、矢印キー、上部バーのページドットで移動します。

あるタイルを別のタイルの中央にドラッグすると、1つのタイルのタブになります。タブを外へドラッグすると、また分かれます。最初からあるメディア、予定、システムのタイルは、この方法で作られています。

いくつかのウィジェットは複数追加できます。再生、チャット、予定、カレンダー、タスク、タイマー、メモ、システム、音量、マイクのコピーは、元のタイルと同じ内容を表示します。デッキ、ブラウザ、リモートコントロール、Discord、カスタムウィジェットのコピーは独立していて、デッキのキーやブラウザのアドレスのように、それぞれ別の内容を持ちます。

タイルやページ全体をプリセットとして保存し、ワンタップでもう一度配置できます。ページはリンクやファイルとしてほかの人と共有できます。スマートフォンでは同じダッシュボードが1列に並び直します。スマホからのアクセスはベータです。

カタログのウィジェット

コミュニティのカタログには、ほかの人が作って共有したウィジェット、テーマ、アニメーション背景、ページ、Deck プロファイル、Ambient シーン、パッケージ一式があります。すべての掲載物は審査されています。

カタログのページで掲載物のコードをコピーして 設定 → ウィジェットと共有 → インポート に貼り付けるか、同じカタログが並ぶアプリ内のストアを開きます。何かが適用される前に、コードの中身が表示されます。

カタログのウィジェットは カスタムウィジェット のタイルの中で、サンドボックスに隔離されて動きます。受け取れるのは宣言したデータ、操作、Web アドレスだけで、最初にあなたの許可を求めます。その土台のウィジェット SDK はベータです。

自分でウィジェットを作る

自分のウィジェットは、ベータのウィジェット SDK で作ります。中身は manifest.json と index.html の入ったフォルダーです。Xenon はそれをサンドボックスで動かし、1つのメッセージブリッジを通じてリアルタイムのデータと操作を渡します。

設定 → ウィジェットと共有 → 作成 から SDK ガイドに移動できます。作ったウィジェットは ウィジェットを書き出す で共有でき、取り込む人は先にその権限を確認して承認します。

作り方ガイドはゼロから始めて、テーマ、ページ、Deck プロファイル、ウィジェットを扱います。ウィジェット SDK リファレンスには、プロトコルの全体が載っています。

質問

Xenon にはウィジェットがいくつありますか？

内蔵ウィジェットは41種類で、生産性、メディア、システム、配信の4つのグループに分かれています。これに加えて、コミュニティのカタログのウィジェットや自分で作ったウィジェットが、カスタムウィジェットのタイルで動きます。

ウィジェットを使うには Xeneon Edge が必要ですか？

いいえ。同じダッシュボードが、どのモニターでも、タッチスクリーンでも、ベータとして Wi-Fi でつないだスマートフォンやタブレットでも動きます。Xeneon Edge で使う Xenonとタブレットやスマートフォンをダッシュボードにする方法をご覧ください。

1つのタイルに複数のウィジェットを入れられますか？

はい。レイアウトモードで、あるタイルを別のタイルの中央にドラッグすると、同じタイルのタブになります。タブを外へドラッグすると、また分かれます。

ダッシュボードには何ページまで作れますか？

最大8ページで、それぞれ24列のグリッドです。新しいページは空の状態から始まり、ほかのページはそのまま残ります。

自分でウィジェットを作れますか？

はい。ベータのウィジェット SDK を使って HTML ページとしてウィジェットを書くと、Xenon がそれをサンドボックスの中で動かします。使えるのは、ユーザーが承認したデータと操作だけです。

Xenon をダウンロード

個人利用は無料で、アカウントは不要です。Windows 版 Xenon をダウンロードするか、ダウンロードページで macOS 版と Linux 版を入手してください。まずブラウザのデモでダッシュボードを試すこともできます。デモはシミュレーションのデータで動きます。
