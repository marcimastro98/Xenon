セカンドスクリーンで OpenAI Codex

Xenon の Codex タイルは、プランの使用量ウィンドウ、1日ごとのトークン、PC で作業中のセッション、そしてその依頼を「許可」「拒否」「Codex で答える」とともに表示します。置き場所は PC の横の画面です。Xeneon Edge、モニター、タブレット、ペアリングしたスマートフォンなど。

最終更新：2026年10月6日

+ ボタンのシステムからタイルを追加します。PC に Codex がインストールされてサインインしていれば、プランはすぐに表示されます。セッションと承認には Codex の接続が必要で、タイルから行えます。Windows に対応し、macOS と Linux はベータ版です。

プランの使用量 セッション 承認 接続する 何がどこに送られるか よくある質問

プランの使用量

Codex はプランの使用量ウィンドウを報告します。それぞれの使用率とリセット時刻です。Xenon はそれぞれをバーで表示し、リセットまでのカウントダウンと、均等なペースなら今どこにいるかの印を付けます。数値は 70% で琥珀色、90% で赤になります。

各ウィンドウの長さは Codex が伝えるので、タイルはその長さのまま表示します。有料プランでは通常 5 時間と 1 週間、Free プランでは 30 日のウィンドウが 1 つです。

タイルの使用量側には、今日、7日間、30日間、累計のトークンと、直近 30 日の日ごとの列が表示されます。これは Codex がアカウント全体について報告する数値で、この PC だけでなくすべてのデバイスとアプリを含みます。

セッションと最近の会話

Codex を接続すると、各セッションは開始と同時に 1 行で表示されます。頼んだ内容、モデル、作業中かあなたを待っているか。その下に、Codex が保存している会話と、それを行った場所（ChatGPT アプリ、エディター、ターミナル）が並びます。

セッションは Codex のフックから届きます。Codex は codex コマンドでフックを実行します。ChatGPT アプリやエディター拡張機能でも実行されるかは、Codex のバージョンによります。プランと会話の一覧はフックに依存せず、3 つすべてを含みます。

依頼に答える

Codex のセッションがコマンドの実行やファイルの変更を求めると、その依頼がコマンド、または変更されるファイル（削除には印付き）とともにタイルに表示され、許可、拒否、Codex で答えるの 3 つのボタンが出ます。最後のボタンは質問をすぐ Codex に戻します。カードには、ネットワーク、作業の公開、プロジェクト外のファイル、セッションを超えるアクセス、元に戻せない操作など、何が普段と違うのかが書かれます。

rm -rf やファイルを削除するパッチのように元に戻せない依頼は、タップではなくボタンの長押しで許可します。25 秒間答えがない依頼は画面全体に表示され、別のページで見落とされることはありません。

あなたの代わりに承認されることはありません。依頼がタイルで待っている間、Codex は自分の確認を表示しないため、90 秒後、または Xenon が閉じているときは、依頼は Codex に戻り、いつもどおり尋ねます。待ち時間の変更や依頼のオフは設定 → Codexで行えます。

スマートフォンから答えるには、Xenon とペアリングします（ベータ）。スマートフォンには同じダッシュボードと同じボタンが表示されます。スマートフォンのペアリング方法。

Codex を接続する

  1. + ボタンのシステムから Codex タイルを追加します。
  2. タイルで Codex をタップし、接続を押します。
  3. Codex を開き、/hooks と入力して Xenon のフックを信頼します。Codex は新しいフックを信頼するまで実行しません。これは Codex 自身の安全確認なので、Xenon が代わりに行うことはありません。
  4. 新しいセッションを始めます。フックはこの手順の後に開始したセッションに届き、タイルには Codex がフックを信頼しているかどうかが表示されます。

接続で変更されるファイルは 1 つだけです。~/.codex または CODEX_HOME が指すフォルダーにある Codex の hooks.json です。Node で Xenon の小さなスクリプトを実行するフックを 5 つ追加し、そのスクリプトは 127.0.0.1（あなたの PC）の Xenon に報告します。あなたのフックは同じ順序のまま残り、Xenon は config.toml に触れません。

最初の変更の前に、Xenon はファイルのコピーを hooks.json.xenon-backup として隣に保存します。ファイルが読み取れない場合、Xenon は変更せずにそのことを伝えます。

Xenon をアンインストールすると、追加したフックが取り除かれ、バックアップも削除されます。あなたのフックはそのままです。アンインストールせずに同じことをするには、タイルの接続を解除をタップするか、Xenon のインストールフォルダーで node server/codex-link.js unlink を実行します。

何がどこに送られるか

タイルは API キーを使わず、サインイン情報を読むこともありません。プランは、ChatGPT アプリやエディター拡張機能が Codex とやり取りするのに使う codex app-server から取得します。Xenon はタイルがダッシュボードにある間だけ自前のコピーを起動し、読み取りだけを依頼し、不要になって数分後に閉じます。

フックは、Xenon が作成したキーを付けて 127.0.0.1（あなたの PC）に報告します。キーのない報告は拒否されます。キーは Xenon のデータフォルダーから読み込まれるので、コマンドラインに現れることはありません。セッションの状態はメモリにだけ保持され、Xenon の再起動で空になります。

インストールしたウィジェットは、許可すれば codex ストリームでプランの数値を読めます。割合、ウィンドウの長さ、トークン数、作業中のセッション数です。フォルダー、プロジェクト、会話、コマンド、メールアドレスは決して含まれません。

よくある質問

Codex の使用制限をセカンドスクリーンで見られますか？

はい。Codex がインストールされサインインしていれば、タイルにプランの各使用量ウィンドウと使用率、リセットまでのカウントダウンが表示されます。これに Codex の接続は不要です。

ChatGPT デスクトップアプリで使えますか？

プラン、使用量、会話の一覧は、同じアカウントとエンジンを共有するため、ChatGPT アプリ、エディター拡張機能、codex コマンドの Codex をすべて含みます。ライブのセッションと承認には Codex がフックを実行する必要があり、codex コマンドはそれを行います。

依頼に答えないとどうなりますか？

何も承認されません。90 秒後、または Xenon が閉じているときは、依頼は Codex に戻り、いつもどおり尋ねられます。

なぜ Codex でフックを信頼する必要があるのですか？

Codex は、そのフックそのものを信頼した後にしか実行しません。これは Codex 自身の安全確認なので、Xenon が代わりに行うことはありません。Xenon や Node のフォルダーが変わるとフックも変わり、Codex は再び信頼を求めます。そのときはタイルが知らせます。

API キーでも使えますか？

セッションと承認は使えます。プランのウィンドウは ChatGPT プランにしかないため、API キーでは表示するものがありません。

Xenon をダウンロード

無料で、アカウントは不要です。Windows 版 Xenon をダウンロードするか、ダウンロードページでシステムを選んでください。Claude Code も使っていますか？ タッチスクリーンで Claude Code をご覧ください。
