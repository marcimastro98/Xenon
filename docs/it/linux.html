Xenon su Linux

Xenon è una dashboard gratuita per qualsiasi schermo in più. Su Linux è in beta: la dashboard è la stessa di Windows, e questa pagina elenca cosa cambia ancora e i pacchetti che servono.

Il supporto a Linux è in beta. La dashboard, i widget, il catalogo e le integrazioni sono identici a Windows. Cambia ancora la parte che legge e comanda il computer, elencata nella tabella qui sotto. È testato su GNOME e KDE.

Primo avvio

Apri l'app. Al primo avvio ti propone di configurare la dashboard in una finestra del terminale: scarica il motore, verifica il download prima di estrarlo e registra un servizio systemd --user, così Xenon parte quando accedi. Dove manca il gestore dei servizi utente usa invece una voce di avvio automatico XDG e te lo dice, compreso il fatto che questa alternativa non riavvia Xenon dopo un crash.

Il .deb e l'.rpm non lo fanno durante l'installazione, ed è voluto: tutto quello che la configurazione crea appartiene a un solo account utente, mentre un pacchetto si installa come root per tutto il computer.

Il programma di installazione elenca anche gli strumenti facoltativi che ti mancano. Su Debian e Ubuntu:

sudo apt install nodejs npm unzip           # required
sudo apt install wireplumber                # volume, microphone and the per-app mixer
sudo apt install wmctrl xdotool x11-utils   # the open-applications widget (X11 sessions)
sudo apt install ffmpeg                     # voice input and spoken replies

Se il tuo desktop non ha proprio un emulatore di terminale, l'app non può mostrarti il programma di installazione: scarica lo zip dei sorgenti dalla pagina della versione, estrailo ed esegui ./INSTALL.sh.

X11 e Wayland

Quasi tutta la dashboard funziona allo stesso modo con entrambi. Cambiano le parti che devono vedere le altre finestre: il widget Applicazioni aperte, il cambio app e la visione dello schermo dell'AI usano strumenti X11 (wmctrl, xdotool), quindi in una sessione Wayland Xenon li nasconde invece di proporli e poi fallire. Se ti servono, accedi con una sessione X11.

Segnalare un problema

Linux è in beta perché la tabella qui sopra ha ancora dei buchi. Per segnalarne uno, apri una segnalazione di bug indicando distribuzione, desktop e tipo di sessione. Se prima vuoi chiedere, scrivi sul Discord.
